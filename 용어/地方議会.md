# 地方議会

| 항목 | 내용 |
|------|------|
| 읽기 | ちほうぎかい（지방의회） |
| 과목 | 행정법（지방자치） |
| 한줄 정의 | **憲法 93조 1항**에 근거해 지방공공단체에 설치되는 **의결기관**. 의원은 주민의 **직접선거**로 선출된다（93조 2항） |
| 통설·판례 | **町村에서는 조례로 의회를 두지 않고 選挙人의 総会를 둘 수 있다**（**地自法 94조**, 直接民主制의 예외적 채용） |
| 한국 비교 | [지방자치법](한국비교/지방자치법.md) |

## 설치와 구성

| 항목 | 내용 |
|------|------|
| **설치 근거** | 地自法 89조. 도도부현·시정촌 모두 **의회를 둔다**（원칙） |
| **예외** | **町村은 조례로 의회를 두지 않고 選挙人의 総会**를 둘 수 있다（94조） — 실례는 극히 드물다 |
| **의원 정수** | 각 지자체가 **조례로 정한다**（91조 1항, 상한 규제 폐지） |
| **임기** | **4년**（93조） |

## 議会의 권한

| 권한 | 조문 | 내용 |
|------|:----:|------|
| **議決権** | **96조** | **조례의 제정·개폐, 예산의 議定, 결산의 인정, 일정액 이상의 계약 체결** 등 15개 항목을 열거 |
| **検査権** | 98조 1항 | 사무의 집행을 검사 |
| **監査請求権** | 98조 2항 | 감사위원에게 감사를 요구 |
| **調査権**（100조 조사권） | **100조** | 이른바 **「百条調査権」** — 사무에 관한 조사를 하고 **선서한 증인의 출두·증언, 기록의 제출을 요구**할 수 있다. **정당한 이유 없이 거부하면 형벌**（禁錮 또는 罰金） |
| **意見書提出権** | 99조 | 공익에 관한 사건에 대해 의견서를 국회·관계 행정청에 제출 |
| **自律権** | — | 会議規則의 제정, 議員의 懲罰 등 |

**96조 2항** — 열거된 15개 항목 **이외의 사항도 조례로 의결사항으로 추가**할 수 있다.

## 議決事件의 예 (96조 1항 주요 항목)

- 조례의 제정·개폐
- 예산을 정하는 것
- 결산의 인정
- 일정 재산의 취득·처분
- **일정액 이상의 계약**의 체결
- 부담부 기부 또는 증여를 받는 것
- 권리를 포기하는 것
- 訴えの提起（소의 제기） 등

## 100条調査権 — 최빈출

**「百条調査権」**이라 불리는 강력한 권한.

| 항목 | 내용 |
|------|------|
| 대상 | 지방공공단체의 **사무에 관한 조사** |
| 수단 | **선서한 증인의 출두·증언·기록 제출**을 요구 |
| **불응 시** | **禁錮 또는 罰金**（형벌） — 국정조사권(憲法 62조)에 준하는 강력한 실효성 담보 |
| 한계 | **사무집행의 정치적 책임을 묻는 것**에 그쳐야 하며, **재판이 계속 중인 사건에 부당하게 개입하는 조사는 위법**이라는 판례가 있다 |

## 議長과 議会의 소집

| 항목 | 내용 |
|------|------|
| **議長·副議長** | 의원 중에서 **호선**（103조） |
| **정례회·임시회** | **정례회**는 조례로 정하는 회수를 매년 소집, **임시회**는 필요할 때 소집 |
| **소집권자** | 원칙 **長**（101조）. **의원 정수의 4분의 1 이상의 요구가 있으면 長은 소집해야** 한다（101조 2항） |
| **의회로부터의 소집 청구에 長이 응하지 않을 때** | **의장이 소집할 수 있다**（101조 5·6항, 개정으로 도입） |

## 議会와 長의 관계 — 二元代表制

**長과 議会 모두 주민의 직접선거**로 선출된다(**二元代表制**). 국회의 **議院内閣制**와 달리 **양자가 서로 견제**하는 구조다. → [議会と長の関係](용어/議会と長の関係.md)

## 💡 수험 팁

- **의원 정수는 조례로 자유롭게 정한다.** 예전에는 인구 규모별 상한이 있었으나 **폐지**되었다.
- **町村은 조례로 의회 대신 選挙人総会**를 둘 수 있다(94조). 「모든 지자체는 반드시 의회를 두어야 한다」는 지문은 **오답**.
- **96조 1항의 열거 사항 이외에도 조례로 의결사항을 추가**할 수 있다(96조 2항).
- **100조 조사권 불응에는 형벌**이 따른다. 「과료(過料)에 그친다」는 지문은 **오답** — **형벌(禁錮·罰金)**이다.
- **의회 소집은 원칙 長의 권한**이지만 **의원 정수 4분의 1 이상의 요구**나 **의장에 의한 소집**의 길도 있다.

## 🎯 요점·예시

- **요점**: 지방의회는 조례를 만들고 예산을 정하는 지자체의 「국회」 같은 존재다. 사무 집행을 캐묻는 강력한 조사권(百条調査権)도 갖고 있어, 증인이 거짓말을 하거나 출석을 거부하면 형벌까지 따른다.
- **예시**: A시 의회가 시의 보조금 지출에 의혹이 있다며 **100조 조사권**을 발동해 담당 직원을 증인으로 불렀다고 하자. 그 직원이 정당한 이유 없이 출석을 거부하면 **禁錮 또는 벌금**이라는 형사처벌의 대상이 된다.
