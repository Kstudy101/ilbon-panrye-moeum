# 国の行政組織

| 항목 | 내용 |
|------|------|
| 읽기 | くにのぎょうせいそしき（국가의 행정조직） |
| 과목 | 행정법（행정조직） |
| 한줄 정의 | 内閣을 정점으로 **内閣府 + 省 + 委員会·庁**으로 구성된다. 근거법은 **内閣法·内閣府設置法·国家行政組織法** |
| 통설·판례 | **内閣府에는 国家行政組織法이 적용되지 않는다**(内閣府設置法이 규율). 独立行政委員会의 内閣으로부터의 독립은 **합헌**으로 이해된다 |
| 한국 비교 | [행정조직과 공물](한국비교/행정조직과%20공물.md) |

## 개념

**憲法 65조** — 「行政権은 内閣에 속한다」. 내각을 정점으로 하는 계층 구조가 국가 행정조직이다.

```
内閣  (내각법)
 ├─ 内閣官房 · 内閣法制局 · 国家安全保障会議  (내각 직속)
 ├─ 内閣府  (내각부설치법)  ─ 宮内庁 · 公正取引委員会 · 国家公安委員会 · 金融庁 · 消費者庁 · 個人情報保護委員会 …
 └─ 各省  (국가행정조직법)  ─ 外局として 委員会 · 庁
```

## 국가행정조직법의 기관 분류 — 조문 번호가 그대로 출제된다

| 근거 | 명칭 | 내용 | 예 |
|------|------|------|-----|
| **3조** | **3条機関**（省·委員会·庁） | **행정사무를 담당하며 행정청이 되는** 기관. 법률로 설치 | 総務省, 公害等調整委員会, 国税庁 |
| **8조** | **8条機関**（審議会等） | **자문·조사심의**. 원칙적으로 [諮問機関](용어/行政機関.md) | 中央教育審議会, 食品安全委員会 |
| **8조의2** | **施設等機関** | 시험연구·문교연수·의료갱생 시설 | 国立公文書館, 税務大学校 |
| **8조의3** | **特別の機関** | 특별히 필요한 경우 | 検察庁, 日本学士院, 自衛隊 |

**3条機関 = 행정청이 될 수 있다 / 8条機関 = 원칙적으로 자문**이라는 대비가 핵심이다.

## 独立行政委員会

内閣의 지휘감독으로부터 **직무상 독립**해 활동하는 합의제 행정기관.

| 예 | 소속 |
|-----|------|
| **人事院** | 内閣 소관(国家公務員法) |
| **公正取引委員会** | 内閣府 |
| **国家公安委員会** | 内閣府 |
| **個人情報保護委員会** | 内閣府 |
| **公害等調整委員会** | 総務省 |
| **中央労働委員会** | 厚生労働省 |
| **原子力規制委員会** | 環境省 |

**합헌성** — 憲法 65조가 「행정권은 内閣에 속한다」고 한 것과 충돌하지 않는가가 문제된다. 통설은 **① 65조는 모든 행정을 내각이 직접 지휘하라는 취지가 아니고, ② 위원의 임명권·예산권을 통해 내각의 민주적 통제가 미치므로 합헌**이라고 본다.

**会計検査院**은 憲法 90조에 근거해 **内閣에 대해 독립**한 지위를 가진다. 독립행정위원회와는 근거의 차원이 다르다(**헌법상의 독립**).

## 💡 수험 팁

- **内閣府에는 国家行政組織法이 적용되지 않는다.** 内閣府設置法이라는 별도의 법이 규율한다. **최빈출 함정**.
- **3조 = 성·위원회·청(행정청), 8조 = 심의회(자문)**. 「심의회는 3조 기관」이라는 지문은 **오답**.
- **検察庁·自衛隊는 8조의3 「特別の機関」**이다. 「검찰청은 법무성의 외국(外局)」이라는 지문은 **오답**.
- **会計検査院의 독립은 헌법상(90조)**, 독립행정위원회의 독립은 **법률상**이다. 근거의 차이를 묻는다.
- **人事院은 内閣 소관**, **公正取引委員会·国家公安委員会·個人情報保護委員会는 内閣府**, **公害等調整委員会는 総務省**. 소속을 바꿔치기하는 지문이 자주 나온다.

## 🎯 요점·예시

- **요점**: 국가의 행정 조직은 내각을 머리로 하고 그 아래 내각부와 각 성이 늘어선 구조다. 다만 공정거래위원회처럼 **정치의 입김을 받으면 곤란한 일**을 맡는 기관은 내각의 지휘를 받지 않도록 따로 떼어 놓았다.
- **예시**: A사가 카르텔 혐의로 조사를 받는다고 하자. 조사·처분을 하는 곳은 **公正取引委員会**인데, 이 위원회는 내각부 소속이면서도 **총리의 지휘를 받지 않는다**. 정권이 특정 기업을 봐주거나 노리는 일을 막기 위한 설계다.
