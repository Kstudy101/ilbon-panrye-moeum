# 法の名称

| 항목 | 내용 |
|------|------|
| 읽기 | ほうのめいしょう（법의 명칭） |
| 과목 | 기초법학 |
| 한줄 정의 | 일본 법령의 **명칭 부여 방식과 법형식의 분류**. 「법률」「정령」「성령」 등 형식별 명칭 규칙과, 실질적 분류（公法·私法, 実体法·手続法 등）를 정리 |
| 통설·판례 | 법령의 **약칭**（六法에서 통용되는 통칭)과 **정식명칭**이 다른 경우가 많아 시험에서 자주 함정으로 쓰인다 |
| 한국 비교 | [법령의 표기와 해석기법](한국비교/법령의%20표기와%20해석기법.md) |

## 법형식별 명칭 규칙

| 법형식 | 제정 주체 | 명칭의 특징 |
|--------|-----------|-------------|
| **法律** | 국회 | 「○○法」「○○に関する法律」 |
| **政令** | 内閣 | 「○○法施行令」이 전형（법률의 시행세칙） |
| **内閣府令** | 内閣総理大臣 | 「○○法施行規則」 등 |
| **省令** | 各省大臣 | 「○○法施行規則」 등 |
| **規則** | 각종 위원회, 지자체의 長 등 | 「○○委員会規則」 |
| **条例** | 지방의회 | 「○○市△△条例」 |

**「施行令」은 정령, 「施行規則」은 성령·부령**인 경우가 많다는 관행을 알아 두면 조문 인용 문제에서 유용하다.

## 정식명칭과 통칭 — 함정 모음

| 통칭 | 정식명칭 |
|------|----------|
| **행정불복심사법** | 行政不服審査法（통칭과 정식이 일치） |
| **개인정보보호법** | 個人情報の保護に関する法律 |
| **정보공개법** | **行政機関の保有する情報の公開に関する法律** → [行政機関情報公開法](용어/行政機関情報公開法.md) |
| **공문서관리법** | **公文書等の管理に関する法律** → [公文書管理法](용어/公文書管理法.md) |
| **독점금지법** | 私的独占の禁止及び公正取引の確保に関する法律 |
| **행정서사법** | 行政書士法（정식명칭 그대로） |
| **법의 적용에 관한 통칙법** | 法の適用に関する通則法（**法適用通則法**로 약칭, 구 法例를 대체) |

**긴 정식명칭을 가진 법률일수록 시험에서 「통칭으로 물어보고 정식명칭을 고르게 하는」 형태**로 자주 출제된다.

## 법의 실질적 분류

| 분류축 | 종류 |
|--------|------|
| **성립 형식** | **成文法**（법전화된 법) / **不文法**（[慣習法](용어/慣習法.md)·판례법·[条理](용어/条理.md)) |
| **규율 대상** | **公法**（국가·공권력에 관한 법 — 헌법·행정법·형법) / **私法**（사인 간의 법률관계 — 민법·상법) / **社会法**（노동법·사회보장법 등, 공법·사법의 중간영역） |
| **규정 내용** | **実体法**（권리의무의 발생·소멸 등 내용을 규율 — 민법·형법) / **手続法**（실체법을 실현하는 절차를 규율 — 민사소송법·형사소송법） |
| **적용 범위** | **一般法**（널리 적용) / **特別法**（특정 분야·대상에 한정) → [一般法と特別法の関係](용어/一般法と特別法の関係.md) |

## 法例에서 法適用通則法으로 — 연혁

**옛 「法例」（1898년 제정)**가 국제사법·법의 시제 등을 규율해 왔으나, **2006년(平成18년) 「法の適用に関する通則法」으로 전면 개정**되어 **法例는 폐지**되었다. **[法律の公布・施行](용어/法律の公布・施行.md)** 항목에서 다룬 **「시행일 정함이 없으면 20일 경과 후」**라는 규정(2조)도 이 법에 있다.

## 💡 수험 팁

- **「정보공개법」「공문서관리법」 같은 통칭과 정식명칭의 대응**을 정확히 외운다. 정식명칭을 고르는 문제가 자주 나온다.
- **公法·私法·社会法**의 3분류에서 **노동법 등은 「사회법」**으로 분류된다는 것에 주의.
- **実体法과 手続法의 구별**은 「내용을 정하는가, 절차를 정하는가」로 판단한다.
- **法例는 2006년에 「법의 적용에 관한 통칙법」으로 전면 개정**되었다는 연혁을 기억한다.
- 관련: [一般法と特別法の関係](용어/一般法と特別法の関係.md) · [法源](용어/法源.md) · [法律の公布・施行](용어/法律の公布・施行.md)

## 🎯 요점·예시

- **요점**: 법령의 이름에는 「법률」「정령」「성령」처럼 형식에 따른 규칙이 있고, 실무에서 흔히 부르는 「통칭」과 정식 명칭이 다른 경우가 많다.
- **예시**: 흔히 「정보공개법」이라 부르는 법의 정식 명칭은 **「행정기관이 보유하는 정보의 공개에 관한 법률」**이다. 시험에서는 이런 정식 명칭을 정확히 고르게 하는 문제가 자주 나온다.
