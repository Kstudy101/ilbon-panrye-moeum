# その他の用益物権

| 항목 | 내용 |
|------|------|
| 읽기 | そのたのようえきぶっけん（그 밖의 용익물권） |
| 과목 | 민법（물권） |
| 한줄 정의 | 민법상의 용익물권 중 [地役権](용어/地役権.md) 이외의 것 — **地上権**과 **永小作権**. 타인의 토지를 **직접 사용·수익**하는 물권 |
| 통설·판례 | **地上権은 임차권과 유사한 기능**을 하지만 **물권**이므로 **등기하면 누구에게나 대항 가능**하다는 점에서 임차권보다 강력 |

## 용익물권 4종 전체 지도

| 물권 | 내용 |
|------|------|
| **地上権**（265조） | 타인의 토지에서 **공작물 또는 竹木을 소유**하기 위해 그 토지를 사용하는 권리 |
| **永小作権**（270조） | **경작 또는 목축**을 위해 소작료를 지불하고 타인의 토지를 사용하는 권리 |
| **[地役権](용어/地役権.md)**（280조） | 자기 토지의 편익을 위해 타인의 토지를 이용 |
| **入会権**（263조, 294조） | 일정 지역의 주민이 **관습에 기해** 산림·원야 등을 공동으로 이용하는 권리（**관습법적 성격**이 강함） |

## 地上権 — 최빈출

| 항목 | 내용 |
|------|------|
| **목적** | **공작물**（건물·터널·전주 등) 또는 **竹木**의 소유 |
| **대가** | **원칙 무상 가능**（**地代는 요소가 아님** — 임차권과의 결정적 차이） |
| **존속기간** | **당사자가 자유롭게 정할 수 있음**（법률상 상한·하한 제한이 없음 — **借地借家法상의 「借地権」과는 다름**에 주의） |
| **양도성** | **자유롭게 양도·전대 가능**（소유자의 승낙 불요） — **임차권은 양도·전대에 임대인의 승낙이 필요**한 것과 대비 |
| **대항력** | **등기**로 제3자에게 대항（177조） |

**「지상권은 임대인의 승낙 없이도 자유롭게 양도할 수 있다」**는 점이 **임차권(민법 612조 — 무단양도는 해제사유)과의 가장 큰 차이**로 최빈출이다.

## 借地借家法上의 「借地権」과의 관계

**借地借家法**은 **건물 소유를 목적으로 하는 地上権 또는 土地賃借権**을 「**借地権**」으로 통칭해 **존속기간·갱신·대항력**에 관한 특칙을 둔다. 실무상 **차지권의 대부분은 「임차권(채권)」형태**로 이용되고, **지상권(물권)형은 드물다** — 그러나 시험에서는 **물권으로서의 지상권 자체의 성질**（무상 가능, 자유양도성 등)이 먼저 출제된다.

## 永小作権

| 항목 | 내용 |
|------|------|
| **목적** | **경작 또는 목축** |
| **소작료** | **요소**（무상의 영소작권은 인정되지 않음 — 지상권과의 차이） |
| **존속기간** | **20년 이상 50년 이하**（278조, 설정행위로 이를 넘게 정해도 50년으로 단축） |
| **현대적 의의** | **현재는 거의 이용되지 않는 제도**（농지의 이용관계는 農地法·農業経営基盤強化促進法 등이 별도로 규율） |

## 入会権 — 관습법적 성격

**入会権**은 민법에 **직접적인 정의 규정이 없고**, **263조·294조가 「관습에 따른다」**고 정하는 데 그친다 — **공유의 성질을 가지는 입회권（263조)과 공유의 성질을 가지지 않는 입회권（294조）**으로 나뉜다. **최고재판소는 입회권을 「총유(総有)」적 성질**을 가지는 것으로 이해해 왔다.

## 💡 수험 팁

- **지상권은 무상도 가능, 영소작권은 소작료가 요소**（유상 필수). 대가의 요부가 갈린다.
- **지상권은 소유자의 승낙 없이 자유롭게 양도 가능** — 임차권과의 최대 차이. 최빈출.
- **借地借家法상의 「借地権」은 지상권과 (토지)임차권을 함께 묶은 개념**이라는 점에 주의 — 물권인 지상권 자체의 성질과 혼동하지 않는다.
- **영소작권의 존속기간은 20년 이상 50년 이하.**
- **입회권은 「관습」에 따르는 특수한 물권**으로, 판례상 「총유」적 성질로 이해된다.

## 🎯 요점·예시

- **요점**: 지상권은 「남의 땅에 건물이나 나무를 갖기 위해 그 땅을 쓰는 물권」으로, 임차권과 비슷한 기능을 하지만 **물권이라서 훨씬 강력하다** — 땅 주인의 허락 없이도 자유롭게 팔거나 세를 놓을 수 있다.
- **예시**: A가 B의 토지에 지상권을 설정받아 건물을 지었다고 하자. A는 **B의 승낙 없이도** 그 지상권을 C에게 양도할 수 있다. 만약 A가 지상권이 아니라 단순 임차권만 가지고 있었다면, 양도에는 **B의 승낙**이 필요했을 것이다.
