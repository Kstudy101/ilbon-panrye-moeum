# 行政行為の瑕疵

| 항목 | 내용 |
|------|------|
| 읽기 | ぎょうせいこういのかし（행정행위의 하자） |
| 과목 | 행정법（행정작용） |
| 한줄 정의 | 행정행위가 적법 요건을 갖추지 못한 상태. 하자의 정도에 따라 **무효**와 **취소할 수 있는 행위**로 갈린다 |
| 통설·판례 | **重大かつ明白説** — 하자가 **중대하고 또한 명백**할 때 무효. 다만 과세처분처럼 **제3자 보호의 필요가 없는 특별한 사정**이 있으면 명백성 없이도 무효(**明白性補充要件説**, 最判昭48.4.26) |

## 무효 vs 취소할 수 있는 행위

| | **無効** | **取り消しうべき行為** |
|---|---|---|
| 하자의 정도 | **중대 + 명백** | 그 이외 |
| [公定力](용어/公定力.md) | **없음** | 있음 |
| [不可争力](용어/不可争力.md) | **없음**（제소기간 제한 없음） | 있음 |
| 다투는 방법 | **無効等確認訴訟**（行訴法 3조 4항）, **争点訴訟**, 민사소송에서의 주장 | **取消訴訟**, 審査請求 |
| 심사청구 전치 | 불요 | 개별법에 정함이 있으면 필요 |

**「명백」이란** 처분의 성립 당시부터 **누가 보아도 하자의 존재가 외형상 객관적으로 명백**하다는 뜻이다. 행정청이 조사를 다했는지 여부는 묻지 않는다(**외형상 일견 명백설**).

**最判昭48.4.26** — 다른 사람 명의로 이루어진 과세처분에 대해, 「과세처분에는 **제3자의 신뢰를 보호할 필요가 없다**」는 특수성을 들어 **명백성 요건을 완화**하고 무효를 인정했다. 이를 **명백성보충요건설**이라 부른다.

## 하자의 종류

| 종류 | 내용 | 예 |
|------|------|-----|
| **주체의 하자** | 권한 없는 자의 행위 | 무권한 기관, 적법한 합의 없는 합의제 기관의 의결 |
| **절차의 하자** | 요구되는 절차의 흠결 | 이유제시 결여, [聴聞](용어/不利益処分.md) 미실시, 자문 생략 |
| **형식의 하자** | 요구되는 형식의 흠결 | 서면 요구 위반, 기명날인 결여 |
| **내용의 하자** | 내용의 위법·불명확·실현 불가능 | 사실오인, [裁量権の逸脱・濫用](용어/行政裁量.md), 사자에 대한 처분 |

**절차의 하자만으로도 처분은 취소된다**는 것이 판례다(最判昭60.1.22 — 이유제시의 흠결; 個人タクシー事件 最判昭46.10.28 — 청문 절차의 흠결).

## 하자의 치유 · 위법행위의 전환

| | **하자의 치유** | **위법행위의 전환** |
|---|---|---|
| 내용 | 사후에 요건이 갖추어져 **처음부터 적법**했던 것으로 취급 | 위법한 행위를 **다른 행위로서 적법**하다고 봄 |
| 태도 | **엄격**（원칙 부정） | 예외적으로 인정 |
| 판례 | **最判昭47.12.5** — 更正処分의 **이유제시 흠결은 사후 追完으로 치유되지 않는다** | **最大判昭29.7.19** — **사망자**에 대한 農地買収計画을 **상속인**에 대한 것으로 전환해 적법 |

**이유제시의 하자는 치유되지 않는다**(最判昭47.12.5)가 핵심이다. 이유제시는 **행정청의 자의 억제 + 상대방의 불복 편의**라는 두 기능을 하는데, 나중에 이유를 붙여도 이 기능이 회복되지 않기 때문이다.

## 하자의 승계 — 최빈출

선행행위에 하자가 있을 때, **선행행위를 다투지 못하게 된 뒤에 후행행위를 다투면서 선행행위의 하자를 주장할 수 있는가**의 문제. **원칙은 부정**이다(그렇지 않으면 [不可争力](용어/不可争力.md)이 무의미해진다).

**예외적으로 긍정되는 기준** — 선행·후행이 **결합해 하나의 법효과를 목표로 하는 경우**.

| | 사례 | 판례 |
|:---:|------|------|
| **승계 ○** | **代執行 절차 내부**（戒告 → 代執行令書 → 실행） | — |
| **승계 ○** | **農地買収計画 → 農地買収処分** | 最判昭25.9.15 |
| **승계 ○** | **安全認定 → 建築確認**（東京都建築安全条例） | **最判平21.12.17（たぬきの森事件）** |
| **승계 ✕** | **課税処分 → 滞納処分** | — |
| **승계 ✕** | **事業認定 → 収用裁決** | — |
| **승계 ✕** | **建築確認 → 除却命令** | — |

**最判平21.12.17** — 안전인정과 건축확인은 별개의 처분이지만, ① **결합해 하나의 효과를 목표**로 하고, ② 안전인정이 있었음을 **인근 주민이 알 기회가 실질적으로 보장되지 않았다**는 절차적 사정을 들어 하자의 승계를 **긍정**했다. **절차보장의 관점을 더한 새로운 판단틀**로 중요하다.

## 💡 수험 팁

- **무효의 기준은 「중대 + 명백」.** 「중대하기만 하면 무효」라는 지문은 **오답**.
- **과세처분에서는 명백성이 완화**된다(最判昭48.4.26). 이유는 **제3자 보호의 필요가 없어서**다.
- **이유제시의 하자는 치유되지 않는다**(最判昭47.12.5). **가장 잘 나오는 치유 부정 사례**.
- **절차의 하자만으로 취소 사유가 된다.** 「내용이 적법하면 절차 위반은 취소 사유가 되지 않는다」는 지문은 **오답**.
- **하자의 승계는 원칙 부정, 예외 긍정.** 예외의 3점 세트 — **代執行 절차 / 農地買収 / 安全認定→建築確認**을 외운다.
- **課税処分 → 滞納処分은 승계 부정**이다. 「세금 부과가 위법했다」를 압류 단계에서 주장할 수 없다.
- 관련: [公定力](용어/公定力.md) · [不可争力](용어/不可争力.md) · [行政裁量](용어/行政裁量.md) · [行政行為の効果](용어/行政行為の効果.md)

## 🎯 요점·예시

- **요점**: 행정처분에 잘못이 있어도 대부분은 「취소해 달라고 다퉈야 하는 것」에 그치고, 잘못이 아주 크고 누가 봐도 뻔한 경우에만 「처음부터 없던 것」이 된다. 후자라면 기간 제한 없이 언제든 다툴 수 있다.
- **예시**: 세무서가 이미 사망한 A 앞으로 과세처분을 했다고 하자. 이것은 하자가 중대하고 명백해 **무효**이므로, 상속인 B는 제소기간이 지났더라도 무효확인소송으로 다툴 수 있다. 반대로 단순히 이유를 제대로 적지 않은 처분이라면 **취소 사유**에 그쳐, 정해진 기간 안에 취소소송을 내야 한다.
