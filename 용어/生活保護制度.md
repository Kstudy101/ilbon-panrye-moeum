# 生活保護制度

| 항목 | 내용 |
|------|------|
| 읽기 | せいかつほごせいど（생활보호제도） |
| 과목 | 일반지식（사회보장） |
| 한줄 정의 | **憲法 25조**의 생존권을 구체화하는 **최후의 안전망**（生活保護法, 1950년 제정). **8종의 부조**로 구성되며 **자산조사(ミーンズテスト)**를 거쳐 급부 |
| 통설·판례 | **朝日訴訟**（最大判昭42.5.24）— 생활보호기준의 설정에 **후생대신(현 후생노동대신)의 광범한 재량**을 인정 → [プログラム規定説](용어/プログラム規定説.md)의 대표 판례 |
| 한국 비교 | [사회보장제도](한국비교/사회보장제도.md) |

## 생활보호법의 4대 원리

| 원리 | 내용 |
|------|------|
| **国家責任의 原理** | 국가가 최저생활 보장의 책임을 짐（1조） |
| **無差別平等의 原理** | 곤궁에 이른 원인·신조·성별을 불문하고 평등하게 보호（2조） |
| **最低生活의 保障** | **건강하고 문화적인 최저한도의 생활**을 유지할 수 있는 것이어야 함（3조, **憲法 25조**의 반영） |
| **補足性의 原理** | 자산·능력·타 제도의 활용을 **먼저** 다한 후에 보충적으로 보호（4조） — **가족의 부양의무가 보호에 우선** |

**보족성의 원리**가 핵심 — 예금·부동산이 있으면 이를 먼저 처분해야 하고, **부양의무자(친족)의 부양이 우선**된다.

## 8종의 扶助

| 부조 | 내용 |
|------|------|
| **生活扶助** | 의식주 등 일상생활비 |
| **教育扶助** | 의무교육에 필요한 학용품비 등 |
| **住宅扶助** | 집세 등 |
| **医療扶助** | 의료비（원칙 **현물급부**） |
| **介護扶助** | 개호서비스비（원칙 현물급부） |
| **出産扶助** | 출산비용 |
| **生業扶助** | 취업을 위한 기능 습득비 등 |
| **葬祭扶助** | 장례비용 |

**의료부조·개호부조는 「현물급부」**가 원칙이라는 점이 다른 부조(금전급부)와 다르다.

## 관련 판례 — 헌법 25조와 연결

| 판례 | 인용 | 요지 |
|------|------|------|
| **朝日訴訟** | 最大判昭42.5.24 | 생활보호기준의 설정은 **후생대신의 광범한 재량**에 맡겨져 있어, **현저히 낮아 위법이라 할 정도가 아닌 한** 사법심사가 미치지 않음（본인 사망으로 소송은 종료했으나 방론에서 판단 제시） |
| **堀木訴訟** | 最大判昭57.7.7 | 併給調整（중복 급부의 조정)에 관해서도 **입법재량**을 폭넓게 인정 |

두 판례 모두 **[プログラム規定説](용어/プログラム規定説.md)**의 입장에 서서 **행정·입법의 재량을 넓게 인정**하는 경향을 보였다.

## 보호의 실시 기관과 절차

| 항목 | 내용 |
|------|------|
| **실시 기관** | **福祉事務所**를 설치한 시정촌（또는 도도부현） |
| **신청주의** | 원칙적으로 **본인 등의 신청**에 의함（**申請保護의 原則**, 7조) — 다만 **급박한 경우 직권보호**도 가능 |
| **불복** | **[行政不服審査法](용어/審査請求の概要.md)**에 의한 심사청구 |

## 💡 수험 팁

- **보족성의 원리 — 자산·능력·부양의무의 활용이 보호에 우선**한다. 「생활보호는 자산과 무관하게 받을 수 있다」는 지문은 **오답**.
- **의료부조·개호부조는 현물급부가 원칙.** 다른 부조는 금전급부.
- **朝日訴訟은 프로그램규정설의 대표 판례**로, **후생대신의 광범한 재량**을 인정했다.
- **신청주의가 원칙**이지만 **급박한 경우 직권보호**도 가능하다.
- 관련: [社会保障制度](용어/社会保障制度.md) · [プログラム規定説](용어/プログラム規定説.md) · [具体的権利説](용어/具体的権利説.md)

## 🎯 요점·예시

- **요점**: 생활보호는 다른 모든 수단을 다 써도 최저생활을 유지할 수 없을 때 국가가 마지막으로 보장해 주는 제도다. 자산이 있으면 먼저 그것을 쓰고, 부양해 줄 가족이 있으면 먼저 그쪽에 도움을 구해야 한다.
- **예시**: A가 생활이 어려워 생활보호를 신청했는데 예금 500만 엔이 있다면, 원칙적으로 그 예금을 먼저 써야 하고 그것이 바닥난 후에야 보호를 받을 수 있다(보족성의 원리). 병원비는 A가 직접 받는 것이 아니라 **의료부조로 현물급부**된다.
