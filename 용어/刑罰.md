# 刑罰

| 항목 | 내용 |
|------|------|
| 읽기 | けいばつ（형벌） |
| 과목 | 기초법학（형법 총론 개요） |
| 한줄 정의 | **刑法 9조**가 정하는 형의 종류 — **死刑, 懲役, 禁錮, 罰金, 拘留, 科料**의 **主刑**과 **没収**의 **付加刑** |
| 통설·판례 | **2022년(令和4년) 형법 개정으로 懲役과 禁錮가 「拘禁刑」으로 통합**（2025년 6월 시행) — 최신 개정 포인트 |
| 한국 비교 | [분쟁해결절차와 형벌](한국비교/분쟁해결절차와%20형벌.md) |

## 刑法 9조 — 형의 종류

| 구분 | 형명 | 내용 |
|------|------|------|
| **主刑** | **死刑** | 생명형 |
| | **懲役**（→ **拘禁刑**으로 통합, 2025.6 시행) | 자유형, 종전에는 **정역(강제노동)이 부과** |
| | **禁錮**（→ **拘禁刑**으로 통합） | 자유형, 종전에는 **정역이 없음**（청원작업은 가능） |
| | **罰金** | 재산형, **1만 엔 이상**（원칙, 감경 시 1만 엔 미만 가능) |
| | **拘留** | 자유형, **1일 이상 30일 미만**（단기 구금） |
| | **科料** | 재산형, **1000엔 이상 1만 엔 미만** |
| **付加刑** | **没収** | 主刑에 **부가**하여만 부과（단독으로는 부과 불가) |

**경중의 순서**（10조) — **死刑 > 懲役 > 禁錮 > 罰金 > 拘留 > 科料**（没収는 부가형이라 별도).

## 拘禁刑으로의 통합 — 최신 개정

**2022년(令和4년) 6월 형법 등 일부 개정법 성립, 2025년(令和7년) 6월 시행** — **懲役과 禁錮를 「拘禁刑」으로 일원화**했다.

| 개정 전 | 개정 후 |
|---------|---------|
| **懲役**（정역 강제) / **禁錮**（정역 없음, 청원작업만) 구별 | **拘禁刑**으로 통합 — **정역을 부과할지는 개별 수형자의 특성에 따라 유연하게 결정**（갱생·재범방지 중시） |

**개정 취지** — 종래 금고형 수형자는 정역이 강제되지 않아 **오히려 갱생 프로그램 참가 기회가 제한**된다는 지적이 있어, **획일적 구별을 폐지하고 개별 처우를 가능하게** 했다.

**「금고형에는 정역이 부과되지 않는다」라는 지식은 拘禁刑 시행 후에는 낡은 지식**이 된다는 점에 주의한다.

## 科料와 過料 — 재확인

| | **科料**（형벌） | **過料**（행정상의 질서벌） |
|---|---|---|
| 성질 | **刑法 9조의 형벌** | **형벌이 아님** |
| 금액 | **1000엔 이상 1만 엔 미만** | 개별 법령·조례가 정함 |
| 절차 | 형사소송 | 비송사건절차 등 |

→ [行政罰](용어/行政罰.md)에서 상세히 다룬 내용과 연결된다.

## 没収의 성질 (19조)

- **범죄행위를 조성한 물건, 범죄행위에 제공했거나 제공하려 한 물건, 범죄행위로 생겼거나 취득한 물건, 그 대가로 취득한 물건** 등을 대상으로 한다.
- **부가형**이므로 **주형에 부수해서만** 선고할 수 있다（단, **몰수만을 위한 절차**인 「몰수의 특례」가 있는 경우는 별개 논점）.

## 형의 시효·집행

**법 개정으로 형의 시효 제도가 조정**되어 왔으나, 행정서사 시험에서는 **형벌의 종류·경중 순서·구금형 통합**이 핵심 출제 포인트다.

## 💡 수험 팁

- **9조의 형 종류 6개（사형·징역·금고·벌금·구류·과료) + 몰수**를 정확히 외운다.
- **경중의 순서 — 사형 > 징역 > 금고 > 벌금 > 구류 > 과료.**
- **2025년 6월 시행으로 징역·금고가 「구금형」으로 통합**된다는 최신 개정을 반드시 기억한다.
- **科料(형벌, 1000엔~1만 엔 미만)와 過料(행정벌, 형벌 아님)를 혼동하지 않는다.**
- **몰수는 부가형**이라 단독으로 부과할 수 없다.
- 관련: [行政罰](용어/行政罰.md) · [法の適用・解釈](용어/法の適用・解釈.md)

## 🎯 요점·예시

- **요점**: 형법이 정하는 형벌은 생명을 빼앗는 사형부터 가벼운 벌금·구류까지 순서가 정해져 있다. 최근 개정으로 「징역」과 「금고」의 구별이 없어지고 「구금형」으로 통합되었다.
- **예시**: 종전에는 같은 자유형이라도 징역은 강제로 작업을 시키고 금고는 시키지 않았지만, 2025년 6월 이후에는 **「구금형」이라는 하나의 형**으로 통합되어, 정역을 부과할지는 각 수형자의 상황에 맞춰 유연하게 정해진다.
