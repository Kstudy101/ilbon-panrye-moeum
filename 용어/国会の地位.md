# 国会の地位

| 항목 | 내용 |
|------|------|
| 읽기 | こっかいのちい（국회의 지위） |
| 과목 | 헌법（통치） |
| 한줄 정의 | 국회가 **국권의 최고기관**이자 **국가의 유일한 입법기관**이라는 헌법 41조상의 지위 |
| 통설·판례 | 「최고기관」은 법적 의미가 없는 **政治的美称説（정치적 미칭설）**이 통설. 「유일한 입법기관」은 [国会中心立法の原則](용어/国会中心立法の原則.md)과 [国会単独立法の原則](용어/国会単独立法の原則.md)의 두 원칙을 의미 |

## 개념

**41조** — 「国会は、**国権の最高機関**であつて、国の**唯一の立法機関**である」. 짧은 조문이지만 여기에 국회의 지위가 모두 압축되어 있고, 시험에서는 이 두 문구의 의미를 각각 나누어 묻는다.

**① 국권의 최고기관**. 통설인 **政治的美称説**은 이를 **법적 의미가 없는 정치적 수식**으로 본다. 즉 국회가 주권자인 국민에 의해 직접 선출되고 국정의 중심적 지위를 차지한다는 사실을 정치적으로 강조한 표현일 뿐, 국회가 내각이나 재판소보다 법적으로 상위에 서서 이들을 지휘·통괄한다는 뜻이 아니다. 만약 법적 의미를 인정하면 **권력분립(내각의 행정권 65조, 재판소의 사법권 76조 1항)**과 충돌하기 때문이다.

**② 유일한 입법기관**. 여기서 「입법」은 **실질적 의미의 입법**, 즉 **법규(法規) — 국민의 권리를 제한하고 의무를 부과하는 일반적·추상적 법규범**의 정립을 말한다. 「유일한」은 두 원칙으로 분해된다. **[国会中心立法の原則](용어/国会中心立法の原則.md)**은 국회 이외의 기관에 의한 입법을 헌법에 특별한 정함이 있는 경우를 제외하고 인정하지 않는다는 원칙이며, 예외는 **의원규칙(58조 2항)·최고재판소규칙(77조)·조례(94조)**다. **[国会単独立法の原則](용어/国会単独立法の原則.md)**은 국회의 입법이 국회 이외의 기관의 관여 없이 국회의 의결만으로 성립한다는 원칙이며, 예외는 **지방자치특별법의 주민투표(95조)**다.

**③ 전국민의 대표**. **43조 1항** — 「両議院は、**全国民を代表する**選挙された議員でこれを組織する」. 여기서 「대표」는 선거구민이나 소속 정당의 지시에 법적으로 구속되지 않는다는 **自由委任（자유위임）**을 뜻하며, **命令委任（명령적 위임）은 부정**된다. 의원은 선거구의 대리인이 아니라 전국민의 대표이므로, 선거구민이 의원을 소환(리콜)하는 제도는 인정되지 않는다. 다만 정당 국가화가 진행된 현실에서는 정당의 구속력을 어디까지 인정할지가 문제되며, 정당의 제명과 의석 상실의 관계가 실천적 쟁점이 된다.

## 학설

| 학설 | 내용 | 비고 |
|------|------|------|
| **政治的美称説（정치적 미칭설）** | 「최고기관」은 **법적 의미가 없는** 정치적 수식. 국회가 국민에 의해 직접 선출되어 국정의 중심에 있음을 강조한 것에 불과 | 👉 **통설** |
| 統括機関説（통괄기관설） | 국회가 국정 전반을 통괄하는 최고의 결정권을 가진 기관이라는 법적 의미가 있음 | 권력분립·국민주권에 반한다는 비판 |
| 最高責任地位説（종합조정기능설） | 국정 전반이 원활히 운영되도록 조정할 **최고의 지위·책임**을 진다는 한도에서 법적 의미가 있음 | 유력설 |

## 💡 수험 팁

- **「국권의 최고기관이므로 국회는 내각·재판소보다 법적으로 우월하고 이들을 감독할 수 있다」는 오답.** 통설은 정치적 미칭설이며, 법적 의미를 부정한다.
- **「유일한 입법기관」 = 国会中心立法 + 国会単独立法**의 2단 구조로 외운다. 예외를 바꿔치기하는 함정이 잦다 — **의원규칙·최고재규칙·조례는 「中心」의 예외**, **지방자치특별법의 주민투표는 「単独」의 예외**.
- 대비: **내각의 법률안 제출권(내각법 5조)은 国会単独立法の原則의 예외가 아니다**(국회가 자유로이 수정·부결할 수 있으므로). 「예외에 해당한다」는 지문은 오답.
- 「입법」은 **형식적 의미의 입법(=법률의 제정)이 아니라 실질적 의미의 입법(=법규의 정립)**을 뜻한다. 이 구별 자체가 단독 지문으로 나온다.
- **43조의 「대표」는 자유위임**. 「의원은 선거구민의 지시에 법적으로 구속된다」·「선거구민은 의원을 소환할 수 있다」는 **오답**.
