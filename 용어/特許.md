# 特許

| 항목 | 내용 |
|------|------|
| 읽기 | とっきょ（특허） |
| 과목 | 행정법（행정행위의 분류·형성적 행위） |
| 한줄 정의 | 특정인에게 **본래 가지고 있지 않던 새로운 권리·능력·법적 지위를 설정**해 주는 형성적 행정행위（강학상 개념） |
| 통설·판례 | **형성적 행위**이며 원칙 **재량행위**. 특허법(特許法)의 「특허」와는 전혀 별개의 개념 |

## 개념

特許는 강학상(講学上) 개념으로, 상대방에게 **원래 없던 권리·능력을 새로 만들어 주는(設定)** 행정행위다. [許可](許可.md)가 이미 가지고 있던 자연적 자유의 **회복**에 그치는 것과 결정적으로 다르다. 공기업 특허(전기·가스 사업), 도로점용허가(도로법 32조), 공유수면매립면허(공유수면매립법 2조), 하천점용허가(하천법 24조), 광업권 설정, **귀화 허가(국적법 4조)**가 대표 예다.

여기서 말하는 特許는 **특허법상의 「특허」(발명에 대한 특허권 부여)와 전혀 다르다**. 오히려 특허법상의 특허는 강학상으로는 「확인(確認)」에 가깝다고 설명된다. 시험에서는 이 명칭 혼동을 노린 지문이 나온다.

특허는 「누구에게 얼마만큼의 권리를 줄 것인가」를 행정청이 공익적 관점에서 정책적으로 판단하는 것이므로, 성질상 **원칙 재량행위**다. 신청자가 요건을 갖추었더라도 행정청이 반드시 특허해야 하는 것은 아니다. 다만 재량이라 하여 무제한은 아니고, 다수 신청자 중 소수를 골라내는 경우에는 **구체적 심사기준의 설정과 공정한 적용, 신청인에게 주장·입증의 기회 부여**가 요구된다(個人タクシー事件, 最判昭46.10.28). 재량의 한계를 넘으면 [裁量権の逸脱・濫用](裁量権の逸脱・濫用.md)으로 위법이 된다.

법령상의 명칭과 강학상 성질이 어긋나는 대표 사례가 특허에 몰려 있다. 도로점용「허가」·하천점용「허가」는 이름은 許可지만 강학상 特許이고, 수도법상 수도사업「인가」는 이름은 認可지만 강학상 特許다. 반대로 농지법 3조「허가」는 강학상 [認可](認可.md)다.

**행정행위 3분류 비교표 (최빈출)**

| 구분 | [許可](許可.md) | **特許** | [認可](認可.md) |
|------|------|----------|------|
| 성질 | 명령적 행위 | **형성적 행위** | 형성적 행위(보충행위) |
| 내용 | 일반적 금지의 해제 → 자연적 자유 **회복** | 새로운 권리·능력·법적 지위의 **설정** | 제3자의 법률행위를 **보충**하여 효력 완성 |
| 재량 | 원칙 기속행위 | 원칙 **재량행위** | 원칙 기속(공익 판단 여지 있음) |
| 상대방 | 자연적 자유를 되찾음 | **없던 권리를 새로 취득** | 자신은 당사자가 아니고, 사인 간 행위를 보충 |
| 무허가·무특허·무인가 행위의 효력 | 원칙 **유효**（처벌 대상） | **효과 자체가 발생하지 않음** | **무효** |
| 대표 예 | 운전면허, 음식점 영업허가, 의사면허 | 공기업 특허(전기·가스), 도로점용허가, 공유수면매립면허, **귀화 허가**, 광업권 설정 | 농지법 3조 허가, 공공요금(운임) 인가, 공공조합 설립인가 |

## 관련 판례

| 판례 | 인용 | 사안 | 결론 |
|------|------|------|------|
| 個人タクシー事件（개인택시 사건） | 最判昭46.10.28 / 民集25巻7号1037頁 | 도로운송법상 개인택시 면허(강학상 특허)에서, 다수 신청자 중 소수를 선별하며 공표되지 않은 17개 내부 심사기준으로 거부한 처분의 적법성 | **처분 위법**. 법이 추상적 면허기준만 둔 경우 행정청은 **구체적 심사기준을 설정하고 공정·합리적으로 적용**해야 하며, 미묘·고도의 판단을 요하는 항목에 대해서는 신청인에게 **주장·입증의 기회**를 주어야 한다 |

## 💡 수험 팁

- **「특허법의 특허」와 헷갈리게 만드는 지문이 단골.** 강학상 特許 ≠ 발명특허. 발명특허는 오히려 강학상 「확인」으로 분류된다.
- 「特許 = **설정**」 vs 「許可 = **회복**」. 귀화 허가는 「일본 국민이라는 지위를 새로 만들어 준다」 → 명칭은 허가지만 **특허**.
- 재량 짝짓기: **특허는 재량행위 / 허가는 기속행위**가 원칙. 「특허는 요건을 갖추면 반드시 해야 한다」는 오답.
- 명칭 함정 리스트를 통째로 외울 것 — 도로점용「허가」·하천점용「허가」·수도사업「인가」 = **특허** / 농지법 3조「허가」 = **인가**.
- 個人タクシー事件은 「특허의 재량 통제」와 「행정절차법상 심사기준(5조)의 선구 판례」 양쪽으로 인용된다. [裁量権の逸脱・濫用](裁量権の逸脱・濫用.md)과 세트로 정리해 둘 것.
