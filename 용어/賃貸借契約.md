# 賃貸借契約

| 항목 | 내용 |
|------|------|
| 읽기 | ちんたいしゃくけいやく（임대차계약） |
| 과목 | 민법（계약각론） |
| 한줄 정의 | 당사자 일방이 상대방에게 목적물을 사용·수익시키고, 상대방이 이에 대해 **차임**을 지급할 것을 약정하는 낙성·유상·쌍무계약（601조). **借地借家法**이 특칙으로 대항력을 강화 |
| 통설·판례 | 임차권은 원래 **채권**（채무자 이외에는 대항 불가)이지만, **借地借家法**이 **건물의 인도·등기 등으로 제3자 대항력**을 부여해 **물권에 준하는 보호**를 실현 — 「**임차권의 물권화**」 |
| 한국 비교 | [그 밖의 전형계약](한국비교/그%20밖의%20전형계약.md) |

## 民法 605조 vs 借地借家法

| | **民法 605조**（원칙） | **借地借家法**（특칙） |
|---|---|---|
| 대항요건 | **임차권의 등기**（실무상 거의 이용되지 않음 — 임대인의 등기협력의무 없음） | **建物의 引渡し**（借家, 借地借家法 31조）, **借地上의 건물 등기**（借地, 10조） |
| 존속기간 | 최장 **50년**（民法 604조） | **借地権**（건물소유목적)은 원칙 **30년 이상**（借地借家法 3조), **借家権**은 제한 없음 |

**「임차권도 등기하면 대항력이 생기지만, 실무상 등기협력의무가 없어 거의 이용되지 않는다」**는 점과, **「借地借家法이 건물의 인도·등기라는 훨씬 간편한 방법으로 대항력을 인정」**한다는 점의 대비가 최빈출이다.

## 임대인·임차인의 의무

| 의무 | 조문 | 내용 |
|------|:----:|------|
| **사용·수익시킬 의무** | 601조 | 목적물을 사용할 수 있는 상태로 둘 의무 |
| **修繕義務**（임대인） | 606조 1항 | 임대인은 원칙 **수선의무**를 짐（본문); **임차인의 귀책사유로 인한 것은 예외**（단서, 2017년 개정으로 명확화） |
| **필요비상환의무**（임대인） | 608조 1항 | 임차인이 지출한 필요비는 **즉시 상환** |
| **유익비상환의무**（임대인） | 608조 2항 | 임차인이 지출한 유익비는 **임대차 종료 시**（가액증가가 현존하는 한도에서） |
| **원상회복의무**（임차인） | **621조**（2017년 신설） | 통상손모·경년변화를 **제외**하고 원상회복. **통상의 사용에 의한 손모·경년변화는 임차인이 원상회복할 필요가 없다**는 것이 명문화됨 |

**「통상손모（通常損耗）는 원상회복의무의 대상이 아니다」**（621조)는 2017년 개정의 명문화 포인트로 최빈출이다.

## 임차권의 양도·전대 (612조)

「임차인은 임대인의 승낙이 없으면 그 권리를 양도하거나 전대할 수 없다」（1항). **무단양도·전대는 임대인이 해제할 수 있다**（2항）.

**信頼関係破壊의 法理** — 판례는 **무단양도·전대가 있어도, 임대인과의 신뢰관계를 배신했다고 인정하기에 부족한 특단의 사정**이 있으면 **해제권 행사가 제한**된다고 본다（**最判昭28.9.25** 등） — **背信性이 없으면 해제 불가**.

## 敷金 (622조의2, 2017년 신설)

| 항목 | 내용 |
|------|------|
| **정의** | 명목을 불문하고 **임대차에 기해 생기는 임차인의 채무를 담보**할 목적으로 임차인이 임대인에게 교부하는 금전 |
| **반환시기** | **임대차 종료 + 목적물 반환 시**（또는 임차인 지위의 적법한 이전 시） — **인도와 敷金返還은 동시이행관계가 아니다**（목적물 반환이 先履行) |
| **충당** | 임대인은 채무불이행이 있으면 **부담 채무액을 공제하고 잔액을 반환** |

**「敷金返還은 目的物返還 후」**라는 순서（**선이행**）가 최빈출이다 — 임차인이 「돈부터 돌려달라」고 동시이행을 주장할 수 없다.

## 借地借家法의 존속보호 — 개관

| | **借地権**（3조 이하） | **借家権**（26조 이하） |
|---|---|---|
| 최단기간 | **30년 이상**（계약으로 이보다 길게 정할 수 있음） | 제한 없음（단, **1년 미만은 「기간의 정함이 없는 것」으로 간주**, 29조 1항） |
| 갱신 거절 | **정당사유가 없으면 갱신 거절 불가**（법정갱신） | **정당사유가 없으면 갱신 거절 불가**（법정갱신） |
| **정기차지권·정기건물임대차** | **갱신 없는 특약형**（**서면**이 필요, 정기건물임대차는 사전 설명 의무도) | — |

## 💡 수험 팁

- **통상손모·경년변화는 원상회복 대상이 아니다**（621조, 2017년 명문화). 최빈출.
- **무단양도·전대는 해제 사유이나, 신뢰관계 파괴에 이르지 않으면 해제 제한**（신뢰관계파괴법리).
- **부동산임대차는 등기가 원칙적 대항요건이지만, 실무상 차지차가법의 「인도」「건물등기」로 대체**된다.
- **敷金은 목적물 반환 후에 반환**（선이행) — 동시이행이 아니다.
- **借地権의 최단기간은 30년.**

## 🎯 요점·예시

- **요점**: 임대차는 돈을 받고 물건을 빌려주는 계약으로, 임차인 보호를 위해 차지차가법이 여러 특칙을 둔다. 특히 임차인이 정상적으로 쓰다가 생긴 낡음(통상손모)까지 원상복구할 필요는 없다.
- **예시**: A가 B의 아파트를 3년간 임차하고 퇴거할 때, 벽지가 자연스럽게 색이 바랜 정도라면 **원상회복 대상이 아니다**(621조). 반면 A의 부주의로 생긴 파손은 A가 원상회복해야 한다. 보증금(敷金)은 **A가 방을 완전히 비운 후**에야 정산되어 반환된다.
