# 取消訴訟の判決

| 항목 | 내용 |
|------|------|
| 읽기 | とりけしそしょうのはんけつ（취소소송의 판결） |
| 과목 | 행정법（행정구제） |
| 한줄 정의 | **却下·棄却·認容**의 3종에 **[事情判決](용어/事情判決.md)**(31조)이 더해진다. 취소판결에는 **[대세효](용어/取消訴訟の判決.md)(32조)**와 **[구속력](용어/取消訴訟の判決.md)(33조)**이라는 특별한 효력이 붙는다 |
| 통설·판례 | 취소판결의 **형성력은 제3자에게도 미친다**(32조 1항, **대세효**). **구속력은 관계 행정청 전부를 구속**한다(33조 1항) |
| 한국 비교 | [취소소송의 심리와 판결](한국비교/취소소송의%20심리와%20판결.md) |

## 판결의 종류

| 종류 | 내용 |
|------|------|
| **却下判決** | **소송요건**을 갖추지 못함 → 본안을 보지 않음 → [要件審理](용어/要件審理.md) |
| **棄却判決** | 본안 심리 결과 **처분이 적법** |
| **[事情判決](용어/事情判決.md)**（31조） | 처분이 **위법**하지만 취소가 **공공의 복지에 현저히 적합하지 않을** 때 → **기각**하되 **주문에서 처분이 위법함을 선언**하고 **소송비용은 피고 부담** |
| **認容判決** | 처분이 위법 → **처분의 전부 또는 일부를 취소** |

## 취소판결의 3대 효력

| 효력 | 조문 | 내용 | 미치는 범위 |
|------|:----:|------|-------------|
| **既判力** | 명문 없음（民訴 준용） | 같은 사항을 다시 다툴 수 없다 | **당사자**（원고·피고） |
| **形成力（対世効）** | **32조 1항** | 처분이 **소급해 효력을 잃는다**. 그 효과가 **제3자에게도 미친다** | **제3자 포함** |
| **拘束力** | **33조 1항** | **처분을 한 행정청 그 밖의 관계 행정청을 구속** | **관계 행정청 전부** |

## 32조 — 대세효(第三者効)

「처분 또는 재결을 취소하는 판결은 **제3자에 대해서도 효력을 가진다**」.

취소판결로 처분이 없어지면 **그 처분을 전제로 형성된 제3자의 지위도 함께 무너진다.** 그래서 **[제3자의 소송참가](용어/訴えの併合・移送・変更.md)(22조)**와 **제3자의 재심의 소(34조)**가 짝으로 마련되어 있다.

**34조 제3자의 재심의 소** — 자기에게 책임 없는 이유로 소송에 참가하지 못해 판결에 영향을 미칠 공격방어방법을 제출하지 못한 제3자는, **확정판결을 안 날부터 30일 이내·판결 확정일부터 1년 이내**에 재심의 소를 제기할 수 있다.

## 33조 — 구속력

| 항 | 내용 |
|:--:|------|
| **1항** | 취소판결은 **그 사건에 대해 처분·재결을 한 행정청 그 밖의 관계 행정청을 구속**한다 |
| **2항** | **신청을 각하·기각한 처분·재결이 취소**된 때는, **판결의 취지에 따라 다시 신청에 대한 처분·재결을 하여야 한다** |
| 3항 | 신청에 기한 처분이 절차 위법을 이유로 취소된 경우에도 2항을 준용 |
| 4항 | 12조·13조 등의 준용 |

**구속력의 3가지 내용**

| 내용 | 설명 |
|------|------|
| **반복금지효** | 같은 이유로 **같은 처분을 다시 할 수 없다**. 다만 **다른 이유**로 같은 결론의 처분을 하는 것은 가능 |
| **적극적 처분의무**（33조 2항） | 거부처분이 취소되면 **판결의 취지에 따라 다시 처분**해야 한다 |
| **원상회복의무** | 처분에 의해 생긴 위법 상태를 제거해야 한다 |

**「판결의 취지에 따라」이지 「원고가 원하는 대로」가 아니다.** 절차 위법으로 취소되었다면 **절차를 다시 밟아 같은 거부처분을 할 수도 있다.** 이것이 [의무부여소송](용어/義務付け訴訟.md)이 필요한 이유다.

## 事情判決 (31조)

| 요건 | 내용 |
|------|------|
| ① | 처분·재결이 **위법**할 것 |
| ② | 처분·재결을 취소함으로써 **공공의 이익에 현저한 장해를 생기게 할** 것 |
| ③ | 원고가 입는 손해의 정도, 그 배상·방지의 정도·방법 그 밖의 **일체의 사정을 고려**해 취소가 **공공의 복지에 적합하지 않다**고 인정될 것 |

| 효과 | 내용 |
|------|------|
| 주문 | **청구 기각** + **처분이 위법함을 선언** |
| **소송비용** | **피고 부담**（31조 1항 후단） |
| 관련 청구 | 원고는 별도로 **손해배상**을 청구할 수 있다 |

**대표 사례** — **最大判昭51.4.14（衆議院議員定数訴訟）**. 정수 배분 규정을 **위헌**으로 판단하면서도 선거를 무효로 하면 혼란이 크다며 **사정판결의 법리를 원용**해 선거 자체는 유효로 했다.

## 💡 수험 팁

- **대세효(32조)는 「취소판결」에만** 있다. **기각판결에는 없다**. 「기각판결도 제3자에게 효력이 미친다」는 지문은 **오답**.
- **구속력(33조)은 「관계 행정청」 전부**에 미친다. 처분청만이 아니다.
- **반복금지효는 「같은 이유로」에 한정**된다. **다른 이유로 같은 처분을 하는 것은 가능**하다.
- **사정판결에서도 소송비용은 피고 부담**이다. 기각인데 비용은 피고가 낸다는 어긋남이 출제 포인트.
- **사정판결의 주문에는 위법 선언이 들어간다.** 이유가 아니라 **주문**이다.
- **제3자의 재심의 소는 30일 / 1년**이다.
- **[사정재결](용어/審査請求の裁決.md)(行審法 45조 3항)과 세트**로 외운다. 사정재결은 **「위법 또는 부당」**을 선언한다는 점이 다르다.

## 🎯 요점·예시

- **요점**: 취소판결이 나오면 처분은 처음부터 없었던 것이 되고, 그 효과는 소송에 참가하지 않은 제3자에게도 미친다. 그리고 행정은 **판결의 취지에 따라 다시 판단**해야 한다.
- **예시**: A가 허가 신청을 거부당해 취소소송에서 이겼다고 하자. 이것으로 A가 곧바로 허가를 받는 것은 아니다. 행정청은 **판결이 지적한 잘못을 고쳐 다시 심사**해야 하며, **다른 정당한 이유가 있다면 또 거부할 수도 있다**. 확실히 허가를 받고 싶다면 처음부터 **의무부여소송을 함께** 냈어야 한다.
