# 論理解釈

| 항목 | 내용 |
|------|------|
| 읽기 | ろんりかいしゃく（논리해석） |
| 과목 | 기초법학 |
| 한줄 정의 | [文理解釈](용어/文理解釈.md)만으로는 타당한 결론을 얻을 수 없을 때, 그 규정의 **취지·목적과 법체계 전체와의 정합성**에서 논리적으로 의미를 확정하는 해석 방법의 **총칭** |
| 통설·판례 | 문리해석의 **보충**으로 작동하며, 拡張·縮小·類推·反対·勿論·変更(補正) 해석을 모두 포섭하는 **상위 개념**. 형벌법규에서는 **문언의 가능한 의미**가 넘을 수 없는 한계선이 된다 |

## 개념

조문을 문자 그대로만 읽으면 입법자가 전혀 의도하지 않은 결론이 나오는 일이 있다. 법령의 낱말은 필연적으로 추상적이고, 입법 당시에 예상하지 못한 사태가 뒤늦게 나타나기 때문이다. 이때 해석자는 「이 규정은 **무엇을 위해** 만들어졌는가」, 「다른 조문들과 나란히 놓았을 때 **어떻게 읽어야 모순이 없는가**」를 묻게 되는데, 이런 접근을 통틀어 **논리해석**이라고 한다. 문리해석에 대비되는 개념이므로 **論理解釈 = 文理解釈 이외의 학리해석 전부**라고 이해하면 정확하다.

논리해석은 그 방향에 따라 여섯 갈래로 나뉜다. ① 문언의 뜻을 넓히는 [拡張解釈](용어/拡張解釈.md), ② 좁히는 [縮小解釈](용어/縮小解釈.md), ③ 규정이 없는 사항에 유사 규정을 끌어다 쓰는 [類推解釈](용어/類推解釈.md), ④ 규정되지 않은 것은 반대라고 보는 [反対解釈](용어/反対解釈.md), ⑤ 당연히 포함된다고 보는 [勿論解釈](용어/勿論解釈.md), ⑥ 문언에 명백한 오류가 있을 때 고쳐 읽는 **変更解釈(変更解釈·補正解釈)**이다. 여기에 조문 상호간의 자리매김을 중시하는 **체계적 해석(体系的解釈)**, 입법 목적에서 거슬러 올라가는 **목적론적 해석(目的論的解釈)**, 입법 자료·연혁을 참조하는 **연혁 해석(沿革解釈)**이 방법론으로 덧붙는다.

구체적으로 「이 나무에 **말**을 매지 마시오」라는 표지판을 보자. 문리해석으로는 말만 금지된다. 그런데 이 표지판의 **취지**가 「나무가 상하는 것을 막기 위함」이라면 소를 매도 나무는 똑같이 상하므로 **소도 금지**된다고 읽는 것이 합리적이다([類推解釈](용어/類推解釈.md)). 반대로 취지가 「말이 자주 발길질을 해 사람이 다치기 때문」이라면 소는 해당되지 않으므로 **소는 매도 된다**([反対解釈](용어/反対解釈.md)). **똑같은 조문에서 정반대의 결론이 나오며, 어느 쪽을 택할지는 오직 「규정의 취지」가 결정한다** — 이것이 논리해석의 본질이자 시험의 핵심이다.

다만 논리해석에는 넘을 수 없는 한계가 있다. 법의 예측가능성을 파괴해서는 안 되므로, 해석은 **문언이 가질 수 있는 의미의 범위(文言の可能な意味)** 안에 머물러야 한다. 특히 형벌법규에서는 죄형법정주의의 요청상 그 한계가 엄격해, 이 범위를 벗어나는 [類推解釈](용어/類推解釈.md)은 **피고인에게 불리한 방향으로는 원칙적으로 금지**된다.

## 해석 방법 비교표

| 대분류 | 종류 | 방향 | 「이 다리, **車馬** 통행금지」에 적용하면 |
|--------|------|------|------|
| [文理解釈](용어/文理解釈.md) | — | 문언 그대로 | 마차·말은 통행 불가 |
| **論理解釈** | [拡張解釈](용어/拡張解釈.md) | 문언 안에서 **넓힘** | 「車」에 자동차·자전거 포함 |
| | [縮小解釈](용어/縮小解釈.md) | 문언 안에서 **좁힘** | 「車」에서 유모차·휠체어 제외 |
| | [類推解釈](용어/類推解釈.md) | 문언 **밖**으로 확대 | 규정에 없는 **소**도 금지（**형벌은 원칙 금지**） |
| | [反対解釈](용어/反対解釈.md) | 문언 밖은 **반대** 결론 | 「車馬」가 아닌 **소는 통행 가능** |
| | [勿論解釈](용어/勿論解釈.md) | **당연히** 포함 | 車馬가 안 되면 트럭은 **당연히** 금지 |
| | 変更(補正)解釈 | 문언의 명백한 오류를 **고쳐 읽음** | 「車馬」가 명백한 오기임이 확인되면 바로잡아 읽음 |

## 💡 수험 팁

- **論理解釈은 상위 개념.** 「확장해석과 논리해석은 별개의 해석 방법이다」 → **오답**. 확장·축소·유추·반대·물론은 모두 **논리해석의 하위 유형**이다.
- **순서 함정: 문리 → 논리.** 「먼저 취지를 살핀 뒤 문언을 본다」는 지문은 오답. **문리해석이 출발점**이고 논리해석은 그것이 부당할 때의 보충이다.
- **핵심: [類推解釈](용어/類推解釈.md)과 [反対解釈](용어/反対解釈.md)은 같은 조문에서 정반대 결론을 낳는 대개념(対概念)이다.** 어느 쪽을 취할지의 기준은 **규정의 취지·목적**이며, 논리적으로 어느 한쪽이 항상 옳은 것은 아니다.
- **논리해석의 한계 = 「문언의 가능한 의미」.** 이 선을 넘으면 해석이 아니라 입법이 되고, 형벌법규에서는 죄형법정주의 위반이 된다.
- 「논리해석은 법원만 할 수 있다」 → 오답. 논리해석은 **학리해석(무권해석)**의 한 종류이며 누구나 할 수 있다. 구속력 있는 해석은 [文理解釈](용어/文理解釈.md)의 유권해석 표를 참조.
