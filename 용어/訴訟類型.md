# 訴訟類型

| 항목 | 내용 |
|------|------|
| 읽기 | そしょうるいけい（소송 유형） |
| 과목 | 행정법（행정구제） |
| 한줄 정의 | 行政事件訴訟法이 정하는 **4류형 + 항고소송의 6종**. **주관소송(항고·당사자)**과 **[객관소송](용어/客観訴訟.md)(민중·기관)**으로 크게 갈린다 |
| 통설·판례 | 어느 유형을 고를지가 실무의 첫 관문이다. **처분성이 있으면 항고소송, 없으면 [당사자소송](용어/当事者訴訟.md)·민사소송**이 기본 갈림길 |
| 한국 비교 | [행정소송의 유형과 소송요건](한국비교/행정소송의%20유형과%20소송요건.md) |

## 전체 지도

```
行政事件訴訟
├─ 主観訴訟（자기의 권리·이익을 위해）
│   ├─ 抗告訴訟（3조）— 공권력 행사에 대한 불복
│   │   ├─ 取消訴訟（처분의 취소 / 재결의 취소）
│   │   ├─ 無効等確認訴訟
│   │   ├─ 不作為の違法確認訴訟
│   │   ├─ 義務付け訴訟（申請型 / 非申請型）
│   │   └─ 差止め訴訟
│   └─ 当事者訴訟（4조）
│       ├─ 形式的当事者訴訟
│       └─ 実質的当事者訴訟（확인소송 포함）
└─ 客観訴訟（법의 적정한 운영을 위해 — 42조에 따라 법률에 정함이 있을 때만）
    ├─ 民衆訴訟（5조）— 선거소송, 주민소송
    └─ 機関訴訟（6조）— 기관 상호 간의 권한 분쟁
```

## 항고소송 6종의 선택 기준

| 상황 | 소송 유형 |
|------|-----------|
| **이미 받은 처분**을 없애고 싶다 | **[取消訴訟](용어/取消訴訟.md)**（출소기간 내） |
| 처분의 하자가 **중대·명백**하고 출소기간이 지났다 | **無効等確認訴訟**（기간 제한 없음） |
| **신청했는데 답이 없다** | **[不作為の違法確認訴訟](용어/不作為の違法確認訴訟.md)** |
| **신청했는데 거부당했고, 허가를 받아내고 싶다** | **申請型[義務付け訴訟](용어/義務付け訴訟.md)** + 취소소송(또는 무효확인)을 **병합** |
| **신청권은 없지만 행정이 규제에 나서게 하고 싶다** | **非申請型（直接型）[義務付け訴訟](용어/義務付け訴訟.md)** |
| **앞으로 내려질 처분을 막고 싶다** | **[差止め訴訟](용어/差止め訴訟.md)** |

## 当事者訴訟 두 종류

| | **形式的当事者訴訟** | **実質的当事者訴訟** |
|---|---|---|
| 근거 | 4조 전단 | 4조 후단 |
| 내용 | **처분·재결에 관한 불복**이지만 법령이 **법률관계의 당사자 일방을 피고로** 하도록 정한 것 | **공법상의 법률관계에 관한 소송** |
| 예 | **土地収用法의 손실보상액에 관한 소송**（기업자 ↔ 토지소유자） | 공무원의 지위확인, 공법상의 급부청구, ****재외국민 선거권 확인**（最大判平17.9.14）** |
| 특징 | 처분의 효력은 다투지 않고 **금액만** 다툰다 | **2004년 개정으로 「확인의 소」가 명시**됨 |

**형식적 당사자소송은 [행정불복심사법의 적용 제외](용어/行政不服審査法の適用除外.md)(7조 1항 5호)에 대응**한다는 점도 함께 확인한다.

## 처분성이 없으면?

| 다투는 대상 | 소송 |
|-------------|------|
| **[처분성](용어/処分性.md) ○** | **항고소송** |
| 처분성 ✕ + **공법상의 법률관계** | **[실질적 당사자소송](용어/当事者訴訟.md)** |
| 처분성 ✕ + **사법상의 법률관계** | **민사소송** |

**在外日本人選挙権訴訟(最大判平17.9.14)**은 **공법상의 확인소송(실질적 당사자소송)**으로 **다음 선거에서 투표할 수 있는 지위의 확인**을 인정한 대표 판례다. 처분성이 없는 영역에서 확인소송이 활용된 예로 반드시 나온다.

## 💡 수험 팁

- **주관소송 = 항고 + 당사자 / 객관소송 = 민중 + 기관.** 가장 먼저 세우는 축이다.
- **무효등확인소송에는 출소기간이 없다.** [公定力](용어/公定力.md)·[不可争力](용어/不可争力.md)이 없기 때문이다.
- **신청형 의무부여소송은 반드시 다른 소송과 병합**해야 한다(37조의3 3항) — 거부처분에는 **취소소송 또는 무효등확인소송**을, 부작위에는 **부작위위법확인소송**을.
- **형식적 당사자소송의 대표는 토지수용의 손실보상액 소송**이다.
- **확인소송은 2004년 개정으로 당사자소송의 예로 명시**되었다. 「확인소송은 행정사건소송법에 규정이 없다」는 지문은 **오답**.
- 관련: [行政事件訴訟法の概要](용어/行政事件訴訟法の概要.md) · [取消訴訟](용어/取消訴訟.md) · [当事者訴訟](용어/当事者訴訟.md) · [客観訴訟](용어/客観訴訟.md) · [処分性](용어/処分性.md)

## 🎯 요점·예시

- **요점**: 행정소송은 「어떤 상자에 넣느냐」가 절반이다. 이미 받은 처분을 없애려면 취소소송, 답이 없으면 부작위위법확인, 앞으로 올 처분을 막으려면 차지소송처럼 **상황마다 정해진 통로**가 있다.
- **예시**: A가 생활보호 신청을 했는데 반년이 지나도 답이 없다고 하자. A는 **부작위위법확인소송**만 내면 「답을 안 준 것은 위법」이라는 판결만 받고 다시 기다려야 한다. 그래서 실무에서는 **신청형 의무부여소송을 함께 내어 「보호를 개시하라」는 판결까지** 받아 낸다.
