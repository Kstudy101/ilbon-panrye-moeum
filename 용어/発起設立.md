# 発起設立

| 항목 | 내용 |
|------|------|
| 읽기 | ほっきせつりつ（발기설립） |
| 과목 | 회사법（설립） |
| 한줄 정의 | **발기인이 설립 시 발행하는 주식의 전부를 인수**하는 방법에 의한 주식회사 설립(25조 1항 1호) |
| 통설·판례 | 설립 중의 회사의 실질적 소유자＝발기인이므로 **창립총회가 불요**하고 절차가 간이하다. 실무상 압도적 다수가 발기설립 |

## 개념

**회사법 25조 1항**은 주식회사의 설립 방법을 두 가지로 나눈다.

- **1호 = 발기설립(発起設立)**: 「발기인이 설립 시 발행하는 주식의 **전부**를 인수하는 방법」
- **2호 = [모집설립(募集設立)](募集設立.md)**: 「발기인이 설립 시 발행하는 주식을 인수하는 것 외에, 설립 시 발행하는 주식을 인수하는 자의 **모집**을 하는 방법」

또한 **25조 2항**은 「각 발기인은 주식회사의 설립 시 **설립 시 발행하는 주식을 1주 이상 인수**하지 않으면 안 된다」고 정한다. 이는 발기설립·모집설립 모두에 적용되는 공통 요건이다. 발기인의 인원수에는 제한이 없어 **1인만으로도 설립이 가능**하다.

발기설립의 절차 흐름은 다음과 같다.

1. **정관 작성** — 발기인 전원이 서명 또는 기명날인(26조 1항). **공증인의 인증을 받아야 효력이 생긴다**(30조 1항). ※ 지분회사(합명·합자·합동)는 공증인 인증 불요 — 대비 포인트.
2. **설립 시 발행주식에 관한 사항의 결정** — 정관에 정함이 없으면 **발기인 전원의 동의**로 정한다(32조 1항).
3. **변태설립사항이 있으면 검사인 선임 청구** — 정관 인증 후 지체 없이 **법원**에 청구(33조 1항). → [変態設立事項](変態設立事項.md)
4. **출자의 이행** — 발기인은 인수 후 **지체 없이 전액 납입**(34조 1항). 현물출자는 전부 급부. 납입은 **발기인이 정한 은행 등 납입취급장소**에서(34조 2항). **납입금 보관증명서는 불요**(잔고증명서 등으로 족함).
5. **설립 시 임원의 선임** — **발기인의 의결권(인수한 설립 시 발행주식 1주 1의결권)의 과반수**로 결정(38조, 40조 1항). ※ 「발기인의 두수(頭数) 과반수」가 아님에 주의.
6. **설립경과의 조사** — 설립 시 이사·설립 시 감사가 출자 이행의 완료, 변태설립사항의 상당성 등을 조사(46조 1항). 법령·정관 위반이나 부당한 사항이 있으면 **발기인에게 통지**(46조 2항). ※ 모집설립처럼 **창립총회에 보고할 필요가 없다**.
7. **설립등기** — 본점 소재지에서 등기함으로써 **회사가 성립**한다(49조, 911조).

## 発起設立 vs 募集設立 — 절차 비교표

| 논점 | **발기설립**(25조 1항 1호) | **모집설립**(25조 1항 2호) |
|------|---------------------------|---------------------------|
| 주식 인수인 | 발기인만. 발기인이 **전부** 인수 | 발기인 + 외부 인수인(모집) |
| 창립총회(創立総会) | **불요** | **필요**(65조 1항) |
| 설립 시 임원의 선임 | 발기인의 **의결권 과반수**(40조 1항) | **창립총회 결의**(88조 1항) |
| 출자 이행을 게을리한 경우 | 발기인에게 **기일을 정해 통지 → 실권**(36조) ※ 실권절차 필요 | 인수인은 통지 없이 **당연히 실권**(63조 3항) |
| 납입금 보관증명서(払込金保管証明書) | **불요** (잔고증명서로 족함) | **필요**(64조 1항, 은행 등이 발행) |
| 설립경과 조사의 보고처 | 발기인에게 통지(46조 2항) | **창립총회에 보고**(93조 2항) |
| 변태설립사항이 부당할 때 정관 변경 | 법원이 변경 결정(33조 7항) | 법원 변경 결정 + **창립총회의 정관 변경 권한**(96조) |
| 절차의 성격 | 간이·신속 | 엄격(외부 인수인 보호 필요) |
| 실무상 이용 | **압도적 다수** | 드묾 |

## 💡 수험 팁

- **25조 1항 1호 = 발기설립 / 2호 = 모집설립**. 호수까지 묻는 지문이 나온다.
- **「각 발기인은 1주 이상 인수」(25조 2항)는 양쪽 공통.** 「모집설립에서는 발기인이 주식을 인수하지 않아도 된다」는 지문은 **오답**.
- **창립총회는 모집설립에만.** 발기설립에서 창립총회를 여는 지문은 오답 함정 1순위.
- **납입금 보관증명서(64조)도 모집설립에만.** 발기설립은 통장 사본·잔고증명서로 족하다는 점이 실무상 발기설립이 선호되는 이유다.
- 설립 시 이사 선임은 발기설립에서 **「발기인의 의결권 과반수」** — **두수 과반수가 아니다**(40조 1항). 1주 1의결권으로 센다.
- **정관은 공증인의 인증이 필요**(30조 1항). 단, **지분회사의 정관은 인증 불요**. 또 회사 성립 후에는 정관 변경에 인증이 필요 없다.
- 실권 절차의 차이: **발기인은 최고(催告) 후 실권 / 인수인은 즉시 실권**. 방향을 헷갈리게 하는 지문이 자주 나온다.

## 🎯 요점·예시

- **요점**: 주식회사를 만들 때 발기인들이 설립 시 발행하는 주식 전부를 스스로 인수하는 설립 방식이다. 외부에서 주주를 모집하지 않으므로 창립총회가 필요 없고 납입금 보관증명서도 불요하는 등 절차가 간단해, 실무에서는 압도적 다수가 이 방식을 쓴다.
- **예시**: A가 혼자 발기인이 되어 정관을 만들어 공증인의 인증을 받고, 설립 시 발행주식 전부를 인수해 은행에 납입한 뒤 설립등기를 하면 1인 회사도 설립할 수 있다. 창립총회 없이 발기인인 A의 의결권으로 설립 시 이사를 정하면 된다.
