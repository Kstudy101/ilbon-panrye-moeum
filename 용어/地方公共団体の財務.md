| 항목 | 내용 |
|------|------|
| 읽기 | ちほうこうきょうだんたいのざいむ（지방공공단체의 재무） |
| 과목 | 행정법（지방자치） |
| 한줄 정의 | **예산·회계·계약·재산 관리**에 관한 지방자치법 제9장(208조~)의 규율. **주민소송·주민감사청구**의 대상이 되는 「재무회계상의 행위」가 바로 여기서 나온다 |
| 통설·판례 | 계약은 **一般競争入札이 원칙**이고, **随意契約**은 정령이 정하는 경우에 한해 예외적으로 허용된다（234조） |
| 한국 비교 | [지방자치법](한국비교/지방자치법.md) |

## 예산

| 항목 | 내용 |
|------|------|
| **編成権** | **長에게 전속**（149조 2호） — 의회는 예산을 **수정 의결**할 수 있으나 **편성 자체를 발의할 수는 없다** |
| **会計年度** | **4월 1일부터 다음 해 3월 31일까지**（208조 1항） |
| **会計年度独立の原則** | 각 회계연도의 경비는 그 해의 세입으로 충당한다（208조 2항） — 예외로 **繰越明許費·継続費** 등 |
| **予算の議決** | 의회의 **議決事件**（96조 1호） |

## 会計의 구분

| 구분 | 내용 |
|------|------|
| **一般会計** | 지자체의 기본적인 세입세출 |
| **特別会計** | 특정 사업·특정 세입을 구분 경리（조례로 설치） |

## 契約 — 최빈출

**地自法 234조 2항** — 「일반경쟁입찰, 지명경쟁입찰, 수의계약 또는 せり売り는 **정령이 정하는 경우에 해당할 때에 한해**, 지명경쟁입찰, 수의계약 또는 せり売り에 의할 수 있다」.

| 방식 | 위치 |
|------|------|
| **一般競争入札** | **원칙** |
| **指名競争入札** | 정령이 정하는 경우의 예외 |
| **随意契約** | 정령이 정하는 경우의 예외（소액 계약, 성질상 경쟁에 적합하지 않은 경우 등） |
| **せり売り** | 동산의 매각 등에 한정 |

**최判昭62.5.19** — 지방자치법령이 정한 요건을 충족하지 않는 수의계약이라도 **곧바로 사법상 무효가 되는 것은 아니다**. **법령 위반이 객관적으로 명백**하고 계약 상대방이 **그 사정을 알았거나 알 수 있었을** 경우 등에 한해 **무효**가 된다.

## 재산

| 종류 | 내용 |
|------|------|
| **公有財産** | **行政財産**（직접 공용·공공용에 제공） + **普通財産**（그 이외） |
| **行政財産** | 원칙적으로 **사권 설정 불가**（238조의4 1항）. 예외로 **目的外使用許可**（238조의4 7항） |
| **普通財産** | **매각·대여 등 자유롭게 처분 가능** — 民法·私法 규정이 적용됨 |
| **基金** | 특정 목적을 위해 재산을 적립·운용（241조） |

**行政財産의 目的外使用許可** — 학교 시설을 일시적으로 지역 행사에 쓰게 하는 것처럼, **본래 목적을 해치지 않는 범위**에서 예외적으로 사용을 허가할 수 있다. 이 허가는 **강학상 특허**이며 **[처분성](용어/処分性.md)**이 인정된다.

## 支出負担行為·支出命令

지출은 **①予算執行（支出負担行為）→ ②会計管理者에 의한 支出命令의 확인 → ③支払**의 단계를 거친다. **会計管理者는 長과는 별개의 기관**으로서 **지출의 적법성을 심사**하는 역할을 한다（149조·170조）.

## 監査와 決算

| 항목 | 내용 |
|------|------|
| **監査委員** | 재무 사무의 집행을 상시 감사（199조） |
| **決算** | 매 회계연도 종료 후 **監査委員의 심사**를 거쳐 **의회의 인정**에 부친다（233조） |
| **決算不認定의 효과** | **결산 자체의 법적 효력에는 영향이 없다**（통설）. 다만 長은 필요한 조치를 취해 의회에 보고해야 한다 |

## 주민감사청구·주민소송과의 연결

이 장(재무)에 규정된 **위법·부당한 공금 지출, 재산 관리, 계약 체결, 채무 부담 등**이 바로 **[住民監査請求](용어/住民監査請求.md)·[住民訴訟](용어/住民訴訟.md)(242조·242조의2)**의 대상인 **「재무회계상의 행위」**다.

## 💡 수험 팁

- **예산 편성권은 長 전속**이다. 의회는 수정 의결만 가능.
- **계약은 일반경쟁입찰이 원칙, 수의계약은 정령이 정하는 예외**다. 「수의계약이 원칙」이라는 지문은 **오답**.
- **요건을 결여한 수의계약이 곧바로 무효가 되는 것은 아니다**(最判昭62.5.19). **명백한 위반 + 상대방의 악의(또는 알 수 있었음)**가 필요.
- **행정재산은 원칙적으로 사권 설정 불가**, 예외가 **목적외사용허가**다. **보통재산은 자유롭게 처분** 가능. → [公物](용어/公物.md)
- **결산 불인정도 결산 자체의 효력에는 영향을 주지 않는다.**
- **재무회계상의 행위가 주민감사청구·주민소송의 대상**이 된다는 연결을 반드시 기억한다.
- 관련: [公物](용어/公物.md) · [住民監査請求](용어/住民監査請求.md) · [住民訴訟](용어/住民訴訟.md) · [行政契約](용어/行政契約.md)

## 🎯 요점·예시

- **요점**: 지자체가 돈을 쓰고 재산을 관리하는 데도 엄격한 규칙이 있다. 계약은 원칙적으로 **공개 입찰**로 해야 하고, 예산은 시장이 짜지만 **최종 승인은 의회**가 한다.
- **예시**: A시가 특정 업자와 아무런 경쟁 없이 대규모 공사 계약을 맺었다고 하자. 정령이 정한 예외에 해당하지 않는다면 이는 위법한 수의계약이며, 주민은 **주민감사청구**를 거쳐 **주민소송**으로 그 위법을 다툴 수 있다.
