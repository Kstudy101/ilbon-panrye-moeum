# 民事訴訟と刑事訴訟

| 항목 | 내용 |
|------|------|
| 읽기 | みんじそしょうとけいじそしょう（민사소송과 형사소송） |
| 과목 | 기초법학（재판소） |
| 한줄 정의 | **民事訴訟**은 사인 간의 권리의무 분쟁을, **刑事訴訟**은 국가의 형벌권 행사를 다루는 절차. **당사자 구조·증명의 정도·판단 기관의 역할**이 근본적으로 다르다 |
| 통설·판례 | 형사소송에서는 **「합리적 의심을 넘는 증명」**이 필요하고, 민사소송에서는 **「고도의 개연성」**（証拠の優越보다 엄격, 통상은 이보다 높은 확신)으로 족하다는 것이 판례상의 이해（最判昭50.10.24 — 루미노르 반응 사건 등에서 증명도 논의） |

## 당사자 구조의 대비

| | **民事訴訟** | **刑事訴訟** |
|---|---|---|
| 당사자 | **原告 対 被告**（사인 대 사인, 또는 사인 대 국가) | **検察官 対 被告人** |
| 개시 | **원고의 소 제기**（처분권주의) | **검찰관의 공소 제기**（起訴独占主義, 検察官同一体의 原則） |
| 심리의 원칙 | **弁論主義**（당사자가 제출한 사실·증거만으로 판단) | **職権主義的 요소도 있으나 당사자주의가 기본**（証拠裁判主義） |
| 화해·취하 | **당사자의 처분 가능**（화해·청구 포기·인낙 등） | **원칙적으로 검찰관·피고인이 임의로 종결시킬 수 없음**（기소유예 등은 검찰관의 재량이나 소송 개시 후에는 처분권이 제한적） |

## 증명책임·증명도

| | **民事訴訟** | **刑事訴訟** |
|---|---|---|
| 증명책임 | **주장하는 자**（원칙적으로 원고가 청구원인, 피고가 항변） | **검찰관**（무죄추정의 원칙, **憲法 31조·38조**） |
| 증명의 정도 | **고도의 개연성**（증거의 우월보다 높은 확신을 요구) | **합리적 의심을 넘는 증명**（더 엄격） |
| 자백의 취급 | **재판상의 자백은 원칙적으로 법원을 구속**（**弁論主義**의 귀결） | **자백만으로는 유죄로 할 수 없음**（**憲法 38조 3항** — 보강증거 필요） |

**형사소송의 증명 기준이 민사소송보다 훨씬 엄격**하다 — 무고한 사람을 처벌하는 것을 막기 위해서다.

## 판결의 효력

| | **民事訴訟** | **刑事訴訟** |
|---|---|---|
| 결과 | 청구 인용·기각 | 유죄·무죄 |
| 기판력이 미치는 범위 | **원칙적으로 당사자에 한정**（대세효가 예외적으로 인정되는 경우도 있음 — 예: 회사관계소송) | 유죄판결의 효력은 **피고인에게만**（一事不再理, 憲法 39조） |
| 상소 | **控訴 → 上告**（3심제） | **控訴 → 上告**（3심제, 구조는 유사） |

## 민사와 형사가 별개로 진행되는 이유 — 一事不再理와의 관계

**같은 사실관계에서 민사소송과 형사소송이 별개로 진행**될 수 있다. **형사에서 무죄가 나와도 민사에서 손해배상책임이 인정될 수 있다** — **증명의 정도와 판단 대상이 다르기 때문**이다.

**예** — 형사에서 「합리적 의심을 넘는 증명」에 이르지 못해 무죄가 선고되어도, 민사에서는 **「고도의 개연성」**이 인정되면 불법행위에 기한 손해배상책임이 성립할 수 있다.

## 행정사건소송과의 위치 관계

**行政事件訴訟法 7조**가 「정함이 없으면 민사소송의 예에 의한다」고 정하듯, **[행정사건소송은 「민사소송의 특별형」**으로 이해된다. → [行政事件訴訟法の概要](용어/行政事件訴訟法の概要.md)

## 💡 수험 팁

- **형사소송의 증명은 「합리적 의심을 넘는 증명」, 민사소송은 「고도의 개연성」**으로 형사 쪽이 훨씬 엄격하다.
- **憲法 38조 3항 — 자백만으로는 유죄로 할 수 없다**（보강법칙). 민사소송의 자백(재판상 자백)과는 취급이 크게 다르다.
- **같은 사건에서 형사 무죄 + 민사 배상책임 인정이 모순되지 않는다** — 증명도가 다르기 때문.
- **기소는 검찰관의 전권**（기소독점주의). 사인이 직접 형사소추할 수 없다는 점이 민사소송(누구나 제소 가능)과 다르다.

## 🎯 요점·예시

- **요점**: 민사소송은 개인 간의 권리 다툼을, 형사소송은 국가가 범죄자를 처벌하는 절차를 다룬다. 사람을 처벌하는 일은 잘못되면 되돌릴 수 없으므로, 형사에서는 훨씬 엄격한 증명이 요구된다.
- **예시**: A가 B를 상해 혐의로 고소했지만 형사재판에서 증거 부족으로 무죄가 선고되었다고 하자. 그렇다고 A가 민사상 손해배상을 받지 못하는 것은 아니다. 민사소송에서는 형사보다 낮은 증명의 정도로도 **B의 불법행위 책임을 인정**받을 수 있다.
