# 戦後の日本の経済史

| 항목 | 내용 |
|------|------|
| 읽기 | せんごのにほんのけいざいし（전후 일본의 경제사） |
| 과목 | 일반지식（경제） |
| 한줄 정의 | 패전 후부터 현재까지 일본 경제의 흐름 — **전후 부흥기 → 고도경제성장기 → 안정성장기 → 버블경제 → 잃어버린 20/30년**의 5단계 |

## 시대 구분

| 시기 | 명칭 | 핵심 사건 |
|------|------|-----------|
| **1945~1950년대 초** | **戦後復興期** | **GHQ 점령**, **財閥解体·農地改革·労働改革**（이른바 **戦後三大改革**）, **1949년 도지라인**（긴축재정으로 인플레 수습） |
| **1950년대 중반~1973년** | **高度経済成長期** | 연평균 **약 10%대 성장**. **1955년~**（이른바 「神武景気」등 각종 경기 명칭). **1964년 도쿄올림픽·1968년 GNP 자유주의진영 2위** |
| **1973·1979년** | **石油危機**（오일쇼크） | **제1차(1973)**·**제2차(1979)** 오일쇼크로 고도성장 종료 → **狂乱物価** |
| **1970년대 후반~1980년대** | **安定成長期** | 연 **4~5%대**의 성장으로 감속, 감량경영·수출 주도형 성장 지속 |
| **1985년** | **プラザ合意** | 선진 5개국(G5)이 **달러 강세 시정**에 합의 → **급격한 엔고** 진행 |
| **1980년대 후반** | **バブル経済** | 저금리 정책 하에서 **주가·지가가 실체 경제를 넘어 폭등** |
| **1991년~** | **バブル崩壊** | 자산 가격 급락 → **「失われた10年」**（이후 **失われた20年·30年**으로 장기화） |
| **1997·2008년** | **金融危機** | **1997년 아시아통화위기·山一証券 등 파산**, **2008년 리먼쇼크**로 세계금융위기 |
| **2013년~** | **アベノミクス** | **「3개의 화살」**（**대담한 금융완화 + 기동적 재정정책 + 성장전략**）로 디플레 탈각 시도 |
| **2020년~** | **코로나19 팬데믹** | 대규모 재정출동, 그 후 **엔저·인플레 국면**으로 전환 |

## 戦後三大改革 — 최빈출

| 개혁 | 내용 |
|------|------|
| **財閥解体** | **미쓰이·미쓰비시 등 재벌**을 해체해 경제력 집중을 배제 → **독점금지법 제정**（1947년)으로 뒷받침 |
| **農地改革** | 지주의 소작지를 국가가 매수해 **소작농에게 저렴하게 매도** → **자작농 창설** |
| **労働改革** | **노동조합법·노동기준법 제정**（1947년 전후) → 노동자의 단결권·단체교섭권 보장 |

## プラザ合意（1985년) — 최빈출

**1985년 뉴욕 플라자호텔에서 G5**（미·일·영·독·프)가 **달러 강세를 시정**하기 위한 **협조 개입**에 합의. 이후 **엔이 급격히 절상**（**엔고 불황**)되어, 일본은행이 **금융완화**로 대응한 것이 이후 **버블경제 형성의 한 원인**으로 지적된다.

## バブル崩壊와 그 후

**1989~1990년 일본은행의 금융긴축(공정보합 인상)과 부동산 총량규제** 등을 계기로 **주가·지가가 급락** → **1991년경부터 버블 붕괴**. 이후 **불량채권 문제**가 장기화되며 **「잃어버린 10년」**이 「20년」, 「30년」으로 늘어났다.

## アベノミクス — 3개의 화살

| 화살 | 내용 |
|------|------|
| **① 大胆な金融政策** | 일본은행의 **대규모 금융완화**（**물가안정목표 2%**） |
| **② 機動的な財政政策** | 공공투자 확대 등 재정 출동 |
| **③ 成長戦略**（민간투자 촉진) | 규제개혁 등 구조개혁 |

## 💡 수험 팁

- **전후 3대 개혁 — 재벌해체·농지개혁·노동개혁**을 세트로 외운다.
- **고도경제성장기는 오일쇼크(1973년)로 종료**되었다는 전환점을 기억한다.
- **플라자 합의(1985년)로 급격한 엔고**가 진행되었고, **이것이 저금리 정책→버블경제로 이어졌다**는 인과관계를 이해한다.
- **버블 붕괴는 1991년경**부터 시작되어 「잃어버린 O년」으로 불린다.
- **아베노믹스의 「3개의 화살」**을 정확히 구별한다.

## 🎯 요점·예시

- **요점**: 전후 일본 경제는 개혁으로 기틀을 다지고(전후개혁), 눈부시게 성장했다가(고도성장), 오일쇼크로 속도가 줄고, 거품이 꼈다가 터지면서(버블 붕괴) 긴 침체를 겪었다.
- **예시**: 1985년 플라자 합의로 엔화 가치가 급등하자 수출기업이 타격을 입었고, 일본은행은 경기를 부양하려고 금리를 크게 낮췄다. 이 저금리 자금이 주식과 부동산으로 몰리면서 결국 **버블경제**가 형성되었다.
