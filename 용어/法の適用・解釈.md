# 法の適用・解釈

| 항목 | 내용 |
|------|------|
| 읽기 | ほうのてきよう・かいしゃく（법의 적용·해석） |
| 과목 | 기초법학 |
| 한줄 정의 | 구체적 사건에 법을 적용하기 위해, 조문의 의미를 밝히는 작업（**해석**）과 이를 사실관계에 대입하는 작업（**적용**）을 총칭 |
| 통설·판례 | 해석 기법은 **文理解釈**을 출발점으로 하되, 그것만으로 타당하지 않을 때 **論理解釈**（확장·축소·유추·반대·물론해석 등）으로 보충한다 |

## 해석 방법의 전체 지도

| 대분류 | 종류 | 관련 파일 |
|--------|------|-----------|
| **文理解釈** | 문언·문법상의 통상 의미에 따름 | [文理解釈](용어/文理解釈.md) |
| **論理解釈** | 취지·체계에 비추어 문리를 수정 | [論理解釈](용어/論理解釈.md) |
| ├ **拡張解釈** | 문언을 통상보다 넓혀 해석 | [拡張解釈](용어/拡張解釈.md) |
| ├ **縮小解釈** | 문언을 통상보다 좁혀 해석 | [縮小解釈](용어/縮小解釈.md) |
| ├ **類推解釈** | 규정 없는 사항에 유사 규정을 유추 적용 | [類推解釈](용어/類推解釈.md) |
| ├ **反対解釈** | 규정된 것 이외에는 반대 결론 | [反対解釈](용어/反対解釈.md) |
| └ **勿論解釈** | 가벼운 것이 금지되면 무거운 것도 당연 금지 | [勿論解釈](용어/勿論解釈.md) |

## 문리해석과 논리해석의 관계

**문리해석이 원칙적 출발점**이다 — 법적 안정성·예측가능성을 위해서다. 다만 **문리만으로는 부당한 결론이 나오거나 흠결이 있을 때**, 법의 **목적(입법취지)**을 고려해 논리해석으로 보충한다.

**형벌법규에서는 특히 문리해석이 중시**된다 — [죄형법정주의](용어/明確性の原則.md)의 요청상, **유추해석에 의한 처벌 범위 확장은 원칙적으로 금지**된다（**類推解釈의 禁止**, 죄형법정주의의 파생 원칙）.

## 유추와 반대해석 — 정반대의 결론

같은 「규정에 없는 사항을 어떻게 처리할까」라는 물음에 대해 **정반대의 접근**을 취한다.

| | **類推解釈** | **反対解釈** |
|---|---|---|
| 전제 | 규정 없는 사항이 **규정된 사항과 유사**함 | 규정 없는 사항이 **규정된 사항과 무관·대조적** |
| 결론 | **같은 취급**을 함（규정을 유추 적용） | **다른 취급**을 함（규정과 반대의 결론） |
| 형사법에서 | **원칙 금지**（죄형법정주의） | 특별히 금지되지 않음 |

**어느 쪽을 택할지는 「입법 취지에 비추어 그 사항을 같게 볼 것인가 다르게 볼 것인가」**라는 실질적 판단에 달려 있다 — 기계적으로 정해지는 것이 아니다.

## 확장해석과 유추해석의 구별

| | **拡張解釈** | **類推解釈** |
|---|---|---|
| 대상 | **문언이 커버할 수 있는 범위 내**（의미의 신축） | **문언의 가능한 의미를 넘어서는 사항**에 별개 규정을 유추 |
| 예 | 「車馬」에 자동차를 포함시킴（문언의 의미 확장） | 「개」에 관한 규정을 「고양이」에 유추 적용（전혀 다른 대상에 규정을 끌어옴） |

**확장해석은 「문언 안에서의 넓힘」, 유추해석은 「문언 밖으로의 확대 적용」**이라는 경계선이 핵심이다.

## 물론해석의 논리 구조

「A조차 금지된다면, 그보다 더 무거운 B는 당연히 금지된다」（또는 그 반대로 허용의 방향)는 **당연한 논리적 귀결**을 이끌어내는 해석. → [勿論解釈](용어/勿論解釈.md)에서 상세.

## 💡 수험 팁

- **문리해석이 원칙, 논리해석이 보충**이라는 순서를 먼저 세운다.
- **형벌법규에서는 유추해석이 원칙적으로 금지**된다（죄형법정주의). 「형법에서도 유추해석이 자유롭게 허용된다」는 지문은 **오답**.
- **확장해석과 유추해석을 구별**하는 문제가 자주 나온다 — **문언 안 vs 문언 밖**.
- **유추해석과 반대해석은 정반대의 결론**을 낸다는 것을 기억한다.

## 🎯 요점·예시

- **요점**: 법 조문을 실제 사건에 적용하려면 그 의미를 먼저 정확히 새겨야 한다. 글자 그대로 읽는 것이 기본이지만, 그것만으로 안 될 때는 취지를 살려 넓히거나 좁히거나, 비슷한 규정을 끌어오거나, 반대로 해석하는 등 여러 방법을 쓴다.
- **예시**: 「공원에 차량 진입 금지」라는 규정이 있을 때, 오토바이도 금지되는지가 문제된다고 하자. 오토바이가 「차량」이라는 문언 안에 자연스럽게 포함된다고 보면 **확장해석**이고, 전혀 다른 「자전거 금지」 규정을 끌어와 적용한다면 **유추해석**이 되어 형사처벌의 맥락에서는 원칙적으로 허용되지 않는다.
