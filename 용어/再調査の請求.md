# 再調査の請求

| 항목 | 내용 |
|------|------|
| 읽기 | さいちょうさのせいきゅう（재조사의 청구） |
| 과목 | 행정법（행정불복심사） |
| 한줄 정의 | **5조** — **개별 법률에 정함이 있는 경우에 한해**, **처분청 자신**에게 간이·신속하게 재검토를 구하는 절차. **2014년 개정으로 구 「異議申立て」를 대체**해 신설 |
| 통설·판례 | **심사청구와의 관계는 자유선택**이다. 다만 **심사청구를 한 후에는 재조사의 청구를 할 수 없다**(5조 1항 단서) |
| 한국 비교 | [행정불복심사(행정심판)](한국비교/행정불복심사(행정심판).md) |

## 요건

**5조 1항** — 「행정청의 처분에 불복이 있는 자는, **처분청 이외의 행정청에 심사청구를 할 수 있는 경우**에 있어, **법률에 재조사의 청구를 할 수 있다는 취지의 정함이 있을 때**는, **처분청에 대하여** 재조사의 청구를 할 수 있다. 다만 **해당 처분에 대해 심사청구를 한 때**는 그러하지 아니하다」.

| 요건 | 내용 |
|------|------|
| ① | 처분청 **이외**의 행정청에 심사청구를 할 수 있을 것 |
| ② | **법률**에 재조사의 청구에 관한 정함이 있을 것（**조례로는 창설할 수 없다**） |
| ③ | 아직 **심사청구를 하지 않았을** 것 |

**대상이 되는 대표 분야** — **국세·지방세, 관세, 公害健康被害補償法** 등 **대량·정형적으로 처분이 이루어지는 분야**다.

## 재조사의 청구와 심사청구의 관계

| 상황 | 결론 |
|------|------|
| 재조사의 청구를 할 수 있는 경우 | **곧바로 심사청구를 해도 된다**（자유선택） |
| **재조사의 청구를 한 경우** | 원칙적으로 **그 결정을 거친 후**가 아니면 심사청구를 할 수 없다（**5조 2항**） |
| 예외（5조 2항 각호） | ① 재조사의 청구를 한 날의 다음 날부터 **3개월을 경과해도 결정이 없을** 때 ② 그 밖에 결정을 거치지 않는 데 **정당한 이유**가 있을 때 |

**한 번 재조사를 택하면 그 결과를 기다려야 한다**는 것이 요점이다.

## 기간과 절차

| 항목 | 내용 |
|------|------|
| **기간**（54조） | 처분이 있었음을 **안 날의 다음 날부터 3개월** / 처분이 **있은 날의 다음 날부터 1년** |
| **형식**（61조 → 19조 준용） | **서면**（再調査の請求書） |
| **[審理員](용어/審査請求の審理.md)** | **없음** |
| **[行政不服審査会](용어/審査請求の裁決.md)에의 자문** | **없음** |
| **구두의견진술** | 신청이 있으면 **의무**（61조 → 31조 준용） |
| **판단의 명칭** | **決定**（재결이 아니다） |
| **불이익변경 금지** | **있음**（59조 3항） |
| **집행정지** | **가능**（61조 → 25조 준용. 처분청이므로 **직권 가능**） |

**심리원 절차도 심사회 자문도 없다**는 점이 심사청구와의 최대 차이다. 그만큼 **간이·신속**하다.

## 대상 — 처분만

**부작위에 대해서는 재조사의 청구를 할 수 없다.** 처분청이 아직 아무것도 하지 않은 상태를 처분청 자신에게 「다시 조사해 달라」고 하는 것은 의미가 없기 때문이다.

## 심사청구 기간의 특칙

재조사의 청구를 거친 후 심사청구를 하는 경우, 기간은 **재조사 청구의 결정이 있었음을 안 날의 다음 날부터 1개월**이다(18조 1항 괄호). **통상의 3개월이 아니라 1개월**이라는 점에 주의한다.

## 💡 수험 팁

- **재조사의 청구는 「법률」에 정함이 있을 때만** 할 수 있다. **조례로는 만들 수 없다.**
- **처분청 이외의 행정청에 심사청구를 할 수 있는 경우**가 전제다. 처분청 자신이 심사청인 경우에는 재조사의 청구가 성립할 여지가 없다.
- **곧바로 심사청구를 해도 된다**(자유선택). 「반드시 재조사의 청구를 먼저 해야 한다」는 지문은 **오답**.
- **3개월 경과해도 결정이 없으면 심사청구로 넘어갈 수 있다.**
- **재조사를 거친 뒤의 심사청구 기간은 1개월**이다. 3개월과 헷갈리게 하는 지문이 나온다.
- **부작위는 대상이 아니다.**
- **심리원·심사회 절차가 없다**는 것이 핵심 특징. 「재조사의 청구에도 심리원이 지명된다」는 지문은 **오답**.

## 🎯 요점·예시

- **요점**: 세금 부과처럼 건수가 많고 사실관계 확인만 하면 끝나는 처분은, 상급기관까지 올라가지 않고 **처분한 곳에서 바로 다시 봐 주는 편이 빠르다.** 그런 간이 절차가 재조사의 청구다.
- **예시**: A가 세무서장의 경정처분에 불복한다고 하자. A는 ① **세무서장에게 재조사를 청구**하거나 ② 곧바로 **국세불복심판소장에게 심사청구**를 하거나 자유롭게 고를 수 있다. 다만 ①을 택했다면 그 결정이 나올 때까지(또는 3개월이 지날 때까지) ②로 넘어갈 수 없다.
