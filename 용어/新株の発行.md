# 新株の発行

| 항목 | 내용 |
|------|------|
| 읽기 | しんかぶのはっこう（신주의 발행） |
| 과목 | 회사법（주식） |
| 한줄 정의 | 회사가 자금 조달 등을 위해 새로 주식을 발행하는 것. **募集株式의 발행등**（199조 이하）으로 규율되며, **[公開会社](용어/公開会社.md)와 비공개회사에서 결정기관이 다르다** |
| 통설·판례 | **주주에게 특히 유리한 발행가액**（유리발행)에는 **주주총회의 특별결의**가 필요(199조 3항, 201조 1항). **著しく不公正한 발행**은 **[差止め](용어/取消訴訟の執行停止.md)** 대상（210조） |
| 한국 비교 | [주식과 주주](한국비교/주식과%20주주.md) |

## 결정기관 — 공개회사와 비공개회사

| | **公開会社** | **비공개회사**（양도제한회사） |
|---|---|---|
| 원칙 | **이사회 결의**（201조 1항） | **주주총회의 특별결의**（199조 2항） |
| 이유 | 자금조달의 기동성을 중시 | 주주 구성의 폐쇄성을 보호（지분 희석 방지） |
| **위임** | — | 주주총회가 이사회에 결정을 위임할 수 있음（200조） |

## 유리발행 — 최빈출

「**주주에게 특히 유리한 금액**」으로 모집주식을 발행하는 경우에는, **공개회사라도 주주총회의 특별결의**가 필요하다(199조 3항, 201조 1항 단서).

**「특히 유리한 금액」의 판단** — **시가보다 현저히 낮은 발행가액**을 말한다. **最判昭50.4.8** 등은 **공정한 발행가액이란 「신주 발행 전의 시가와 발행 후의 이론적 시가를 종합적으로 고려한 가격」**이라는 취지로 이해되어 왔다.

## 株主割当과 제3자 할당

| 방식 | 내용 |
|------|------|
| **株主割当**（202조） | 기존 **주주에게 지분 비율대로** 신주인수권을 부여. **희석화가 생기지 않음** |
| **제3자 할당**（第三者割当） | 특정 제3자에게 배정. **기존 주주의 지분 비율이 희석**될 수 있음 |
| **公募** | 불특정 다수를 대상으로 모집 |

## 差止め — 210조

주주는 다음 경우 **신주발행의 유지(差止め)를 청구**할 수 있다.

| 사유 | 내용 |
|------|------|
| **법령·정관 위반**（210조 1호） | — |
| **著しく不公正한 방법**（210조 2호） | **지배권 유지 목적**의 발행 등 |

**主要目的ルール（주요목적룰）** — 신주발행이 **자금조달을 주된 목적**으로 하는지, **경영권 방어·특정 주주의 지분 유지를 주된 목적**으로 하는지를 종합적으로 판단해 후자라면 **불공정발행**으로 유지 대상이 된다.

**忠実屋事件（東京地決平1.7.25）**, **秀和事件** 등 하급심에서 형성된 법리이며, **敵対的買収 방어책 관련 신주발행**의 적법성 판단에 널리 원용된다.

## 신주발행의 무효 — 新株発行無効의 訴え

| 항목 | 내용 |
|------|------|
| **주장 방법** | **소송으로만**（828조 1항 2호） |
| **제소기간** | **공개회사는 효력발생일부터 6개월**, **비공개회사는 1년**（828조 1항 2호） |
| **무효 사유** | **매우 좁게 해석**（통설·판례） — 발행 후 다수의 이해관계가 형성되므로 **중대한 절차 위반에 한정** |
| **판결의 효력** | **대세효**（838조）, **장래효**（839조） |

**최判平5.12.16 등** — 신주발행의 무효 사유는 **거래의 안전을 고려해 엄격히 제한**한다는 것이 판례의 태도다. 예컨대 **이사회 결의를 결여한 신주발행이라도 대표이사의 권한 범위 내라면 원칙적으로 유효**하다고 본 예도 있다.

## 差止め와 無効의 訴え의 관계

| | **差止め**（210조） | **無効의 訴え**（828조） |
|---|---|---|
| 시기 | **발행 전**（효력 발생 전） | **발행 후**（효력 발생 후） |
| 목적 | 사전에 막음 | 사후에 무효화 |
| 요건의 엄격함 | 상대적으로 완화 | **매우 엄격** |

**발행 전에는 막기 쉽지만, 일단 발행되면 무효로 하기는 매우 어렵다**는 비대칭 구조가 핵심이다.

## 💡 수험 팁

- **공개회사 = 이사회 결의 원칙 / 비공개회사 = 주주총회 특별결의 원칙.** 뒤바뀐 지문에 주의.
- **유리발행은 공개회사라도 주주총회 특별결의가 필요**하다. 최빈출.
- **主要目的ルール**은 경영권 방어 목적의 신주발행을 불공정발행으로 다투는 대표 법리다.
- **신주발행 무효는 반드시 소송으로만**, **제소기간은 공개회사 6개월 / 비공개회사 1년**이다.
- **무효판결도 장래효**（소급하지 않음）다.

## 🎯 요점·예시

- **요점**: 회사가 새 주식을 발행할 때, 공개회사는 이사회가 빠르게 결정할 수 있지만 **기존 주주에게 손해가 가는 헐값 발행**이라면 주주총회의 특별한 승인이 필요하다. 경영권을 지키려는 목적이 뻔한 발행은 사전에 막을 수 있다.
- **예시**: 경영권 다툼 중인 회사가 적대적 인수자에게 대항하려고 우호적인 제3자에게만 대량의 신주를 헐값에 발행하려 한다고 하자. 기존 주주는 이것이 **자금조달이 아니라 경영권 방어가 주된 목적**이라고 주장하며 **신주발행 유지 가처분**을 신청할 수 있다(主要目的ルール).
