# 再審査請求

| 항목 | 내용 |
|------|------|
| 읽기 | さいしんさせいきゅう（재심사청구） |
| 과목 | 행정법（행정불복심사） |
| 한줄 정의 | **6조** — **개별 법률에 정함이 있는 경우에 한해**, 심사청구의 재결에 불복해 **다시 다른 행정청에** 불복을 신청하는 절차 |
| 통설·판례 | 대상은 **원처분 또는 재결**이다(6조 2항). **원처분주의가 아니라 어느 쪽이든 고를 수 있다**는 점이 [取消訴訟](용어/原処分主義.md)과 다르다 |

## 요건

**6조 1항** — 「행정청의 처분에 대한 심사청구의 **재결에 불복이 있는 자**는, **법률에 재심사청구를 할 수 있다는 취지의 정함이 있을 때**는 재심사청구를 할 수 있다」.

**6조 2항** — 「재심사청구는 **원처분** 또는 **심사청구의 재결**을 대상으로 하여 …… 한다」.

| 요건 | 내용 |
|------|------|
| ① | **심사청구의 재결**이 있었을 것 |
| ② | **법률**에 재심사청구에 관한 정함이 있을 것（**조례로는 창설 불가**） |

## 대상 분야

**사회보험·노동보험 분야**가 중심이다.

| 법률 | 심사청구 | 재심사청구 |
|------|----------|-----------|
| **労働者災害補償保険法** | 労働者災害補償保険審査官 | **労働保険審査会** |
| **雇用保険法** | 雇用保険審査官 | **労働保険審査会** |
| **国民年金法·厚生年金保険法** | 社会保険審査官 | **社会保険審査会** |

## 기간과 절차

| 항목 | 내용 |
|------|------|
| **기간**（62조） | **재결이 있었음을 안 날의 다음 날부터 1개월** / **재결이 있은 날의 다음 날부터 1년** |
| **[審理員](용어/審査請求の審理.md)** | **없음**（심리원 규정은 준용되지 않는다） |
| **[行政不服審査会](용어/審査請求の裁決.md)에의 자문** | **없음** |
| **판단의 명칭** | **裁決** |
| **불이익변경 금지** | **있음**（64조 4항 → 48조 준용） |
| **집행정지** | **가능**（66조 → 25조 준용） |

**심사청구보다 기간이 짧다**(3개월 → **1개월**)는 점이 최빈출이다.

## 재결의 특칙 (64조)

| 상황 | 재결 |
|------|------|
| 재심사청구가 **부적법** | **각하** |
| 재심사청구에 **이유 없음** | **기각** |
| **재결은 위법·부당하지만 원처분은 위법·부당하지 않은** 경우 | **기각**（64조 3항） — 재결만 고쳐도 결론이 달라지지 않으므로 |
| 재심사청구에 **이유 있음** | **인용** — 재결 또는 원처분을 **취소**（65조） |

**64조 3항**이 특징적이다. 원처분 자체에 문제가 없다면 재결에 흠이 있어도 **기각**된다.

## 기간의 비교 — 세 절차 정리

| 절차 | 주관적 기간 | 객관적 기간 |
|------|:-----------:|:-----------:|
| **[再調査の請求](용어/再調査の請求.md)** | 처분을 안 날부터 **3개월** | 처분이 있은 날부터 **1년** |
| **[審査請求](용어/審査請求の概要.md)** | 처분을 안 날부터 **3개월**（재조사를 거쳤으면 결정을 안 날부터 **1개월**） | **1년** |
| **再審査請求** | 재결을 안 날부터 **1개월** | 재결이 있은 날부터 **1년** |
| **[取消訴訟](용어/取消訴訟.md)** | 처분·재결을 안 날부터 **6개월** | **1년** |

**「3 → 3 → 1 / 소송은 6」**으로 리듬을 잡아 외운다.

## 💡 수험 팁

- **재심사청구는 「법률」에 정함이 있을 때만** 가능하다. 「재결에 불복하면 언제나 재심사청구를 할 수 있다」는 지문은 **오답**.
- **기간은 1개월**이다. 심사청구의 3개월과 헷갈리게 하는 문제가 반드시 나온다.
- **대상은 원처분 또는 재결 어느 쪽이든 가능**하다(6조 2항). 취소소송의 **[원처분주의](용어/原処分主義.md)**와 다르다.
- **심리원도 심사회 자문도 없다.** [재조사의 청구](용어/再調査の請求.md)와 같다.
- **재결이 위법이어도 원처분에 문제가 없으면 기각**된다(64조 3항).
- **노동보험·사회보험 분야가 대표 예**다. 국세에는 재심사청구가 없다(재조사 → 심사청구까지).
- 관련: [審査請求の概要](용어/審査請求の概要.md) · [再調査の請求](용어/再調査の請求.md) · [原処分主義](용어/原処分主義.md)

## 🎯 요점·예시

- **요점**: 심사청구의 결과에도 승복할 수 없을 때 **한 번 더** 다른 기관에 불복하는 제도다. 다만 아무 데나 쓸 수 있는 것이 아니라 **법률이 특별히 마련해 둔 분야**에만 있다.
- **예시**: A가 업무상 재해로 요양급여를 신청했다가 거부당했다고 하자. A는 **노동자재해보상보험심사관**에게 심사청구를 하고, 그 결과에도 불복하면 **노동보험심사회**에 재심사청구를 할 수 있다. 이때 기간은 재결을 안 날로부터 **1개월**뿐이므로 주의해야 한다.
