# 社会保障制度

| 항목 | 내용 |
|------|------|
| 읽기 | しゃかいほしょうせいど（사회보장제도） |
| 과목 | 일반지식（사회보장） |
| 한줄 정의 | **憲法 25조**（생존권)를 이념적 기초로 하는 일본의 사회보장 체계. **社会保険·公的扶助·社会福祉·公衆衛生**의 4부문으로 구성 |
| 통설·판례 | 25조의 법적 성격에 관해 **[프로그램規定説](용어/プログラム規定説.md)**이 판례의 기본 입장（**堀木訴訟** 最大判昭57.7.7 등） → 헌법 분야와 연결 |
| 한국 비교 | [사회보장제도](한국비교/사회보장제도.md) |

## 4부문 체계

| 부문 | 내용 | 예 |
|------|------|-----|
| **社会保険** | 사전에 보험료를 갹출해 사고 발생 시 급부 | [公的年金制度](용어/公的年金制度.md), [介護保険制度](용어/介護保険制度.md), 의료보험, 고용보험, 노재보험 |
| **公的扶助** | 자산조사(**ミーンズテスト**)를 거쳐 최저생활을 보장 | [生活保護制度](용어/生活保護制度.md) |
| **社会福祉** | 장애인·아동·고령자 등 특별한 지원이 필요한 자에 대한 서비스 | 아동복지, 장애인복지 |
| **公衆衛生**（및 医療） | 국민 전체의 건강 증진·질병 예방 | 예방접종, 보건소 |

**「사회보험은 사전 갹출형, 공적부조는 자산조사형」**이라는 대비가 4부문 구별의 핵심 축이다.

## 医療保険制度 — 皆保険体制

**1961년 「国民皆保険·皆年金」체제 확립** — 모든 국민이 반드시 어떤 공적 의료보험·연금제도에 가입하도록 한 체제.

| 제도 | 대상 |
|------|------|
| **健康保険**（협회건보·조합건보） | 회사원 등 피고용자 |
| **国民健康保険** | 자영업자, 무직자 등 |
| **後期高齢者医療制度**（2008년 시행） | **75세 이상**（독립된 광역연합 운영 — [広域連合](용어/地方公共団体.md)의 대표 예） |
| **共済組合** | 공무원 등 |

**旭川市国民健康保険条例事件**（最大判平18.3.1)에서 **국민건강보험료의 조세법률주의(84조) 준용 여부**가 다투어졌다. → [国の財政](용어/国の財政.md)에서 상세.

## 헌법 25조와의 관계

**堀木訴訟(最大判昭57.7.7)** — 장애복지연금과 아동부양수당의 併給禁止 규정에 대해, 25조는 **프로그램규정**이며 **급부의 구체적 내용은 입법재량**에 위임되어 있어 **현저히 합리성을 결여하지 않는 한 위헌이 아니다**라고 판단했다. → [プログラム規定説](용어/プログラム規定説.md)에서 상세.

## 少子高齢化와 사회보장 개혁

| 논점 | 내용 |
|------|------|
| **少子高齢化** | 생산연령인구 감소 + 고령인구 증가 → **부양비율의 악화**로 제도의 지속가능성이 과제 |
| **社会保障と税の一体改革**（2012년~） | **소비세 인상분을 사회보장 재원으로 충당**하는 개혁 — **소비세율 5%→8%(2014)→10%(2019)** 인상과 연동 |
| **全世代型社会保障** | 고령자뿐 아니라 **전세대를 대상**으로 급부·부담을 재검토하는 최근의 방향성 |

## 💡 수험 팁

- **4부문(사회보험·공적부조·사회복지·공중위생)의 구별**을 먼저 세운다 — **사전 갹출인가, 자산조사형 급부인가**가 핵심 기준.
- **국민개보험·개연금 체제는 1961년 확립**되었다는 연도를 기억한다.
- **후기고령자의료제도는 75세 이상**을 대상으로 하고, **운영주체는 광역연합**이다.
- **堀木訴訟은 프로그램규정설**을 취한 대표 판례로 헌법 파트와 교차 출제된다.
- **소비세 인상은 사회보장 재원 확보와 연동**되어 왔다는 정책 배경도 기억해 둔다.

## 🎯 요점·예시

- **요점**: 사회보장은 「미리 보험료를 내고 사고가 나면 받는 것(사회보험)」과 「가난한 사람에게 최소한의 생활을 보장하는 것(공적부조)」이 큰 두 축이다. 일본은 국민 모두가 어떤 형태로든 의료보험·연금에 가입하는 「개보험·개연금」 체제를 갖추고 있다.
- **예시**: A는 회사원이라 건강보험에 가입되어 있고, 75세가 되면 자동으로 **후기고령자의료제도**로 옮겨간다. 만약 A가 생활이 어려워지면 보험료 납부 여부와 무관하게 자산조사를 거쳐 **생활보호**를 받을 수도 있다 — 이는 사회보험이 아니라 공적부조의 영역이다.
