# 行政書士会

| 항목 | 내용 |
|------|------|
| 읽기 | ぎょうせいしょしかい（행정서사회） |
| 과목 | 행정서사법 |
| 한줄 정의 | **都道府県마다 설립**되는 행정서사의 자율적 단체（15조). 전국 조직으로 **日本行政書士会連合会**（연합회)가 있다 |
| 통설·판례 | 행정서사는 **등록과 동시에 사무소 소재지의 도도부현 행정서사회에 강제로 입회**한다（**強制入会制**） |
| 한국 비교 | [행정서사법과 행정사법](한국비교/행정서사법과%20행정사법.md) |

## 都道府県行政書士会

| 항목 | 내용 |
|------|------|
| **설립** | **도도부현마다 1개**（15조） — 회칙을 정해 설립 |
| **입회** | **행정서사의 등록과 동시에 자동 입회**（강제입회제) — 사무소 소재지의 행정서사회에 소속 |
| **목적** | 행정서사 업무의 개선진보를 도모하기 위해 **회원의 지도·연락·감독**에 관한 사무를 행함（15조의2） |
| **회칙 기재사항** | 명칭·사무소 소재지, 회의에 관한 사항, 회원의 지도·연락·감독에 관한 사항 등 |

## 日本行政書士会連合会

| 항목 | 내용 |
|------|------|
| **구성** | **각 都道府県行政書士会를 회원**으로 하는 전국 조직（18조） |
| **역할** | **행정서사명부의 등록 사무**를 관장（→ [行政書士の登録](용어/行政書士の登録.md)), 각 행정서사회 상호 간의 연락·조정, **행정서사試験의 실시 사무**를 국가로부터 위탁받아 담당 |
| **綱紀委員会** | 회원의 품위 유지·징계 관련 조사·심의를 담당 |
| **법인격** | **법인**（19조）— 특수한 공익법인적 성격을 가진 단체 |

**「등록 사무는 연합회, 감독·징계 처분권은 도도부현지사」**라는 역할 분담이 최빈출이다 — 연합회는 행정서사에 대한 **공적인 징계 권한을 갖지 않는다.**

## 강제입회제 — 사법서사회·변호사회와의 비교

| | **행정서사회** | **변호사회**（참고） |
|---|---|---|
| 입회 | **강제**（등록과 동시） | **강제**（변호사회에의 입회가 자격의 요건） |
| 성격 | 유사한 **자율적 단체 강제가입** 방식이 여러 사업(사)에서 공통 |

**「강제입회제」는 전문직 자율규제의 전형적 구조**로, 행정서사·사법서사·변호사·세리사 등 여러 사(士)업에서 공통적으로 채택된다.

## 会則의 인가

**도도부현 행정서사회의 회칙은 도도부현지사의 인가**를 받아야 효력이 발생한다는 것이 통설적 이해다（15조 관련) — **자율단체이면서도 행정의 감독을 받는 이중적 성격**을 보여 준다.

## 💡 수험 팁

- **등록 사무는 「연합회」가 관장**한다. → [行政書士の登録](용어/行政書士の登録.md)
- **징계·감독 권한은 「도도부현지사」**에게 있다. 행정서사회·연합회에는 이 권한이 없다. → [行政書士の業務](용어/行政書士の業務.md)의 최빈출과 세트로 기억.
- **입회는 강제입회제**다 — 등록하면 자동으로 소속 행정서사회의 회원이 된다.
- **연합회는 각 도도부현회를 회원으로 하는 전국 조직**이라는 구조를 기억한다.
- 관련: [行政書士の登録](용어/行政書士の登録.md) · [行政書士の業務](용어/行政書士の業務.md) · [行政書士法の総則](용어/行政書士法の総則.md)

## 🎯 요점·예시

- **요점**: 각 도도부현마다 행정서사들의 단체(행정서사회)가 있고, 그 전국 연합체가 연합회다. 행정서사로 등록하면 자동으로 자기 지역 행정서사회의 회원이 되지만, 실제로 규율을 어겼을 때 벌을 내리는 것은 이 단체가 아니라 도도부현지사다.
- **예시**: A가 도쿄에서 행정서사로 등록하면 자동으로 **도쿄도행정서사회**의 회원이 된다. 만약 A가 업무상 위반을 저질렀다면, 도쿄도행정서사회가 아니라 **도쿄도지사**가 계고·업무정지 등의 처분을 내린다.
