# 国家賠償請求

| 항목 | 내용 |
|------|------|
| 읽기 | こっかばいしょうせいきゅう（국가배상청구） |
| 과목 | 행정법（행정구제） |
| 한줄 정의 | 위법한 행정활동으로 입은 손해의 배상을 국가·공공단체에 구하는 것. 근거는 **憲法 17조 + [国家賠償法](용어/国家賠償法の概要.md)** |
| 통설·판례 | **처분을 취소하지 않고도 청구할 수 있다**(最判昭36.4.21). 실무상 **민사소송**으로 다투며 **시효는 民法 724조** |

## 청구의 두 갈래

| 근거 | 요건의 축 | 관련 파일 |
|------|-----------|-----------|
| **1조** | **공권력 행사에 해당하는 공무원**이 **직무를 행함에 대해** **고의·과실**로 **위법**하게 손해를 가할 것 | [公務員の不法行為](용어/公務員の不法行為.md) |
| **2조** | **公の営造物의 설치·관리에 하자**가 있어 손해가 생길 것 | [公の営造物の設置・管理の瑕疵](용어/公の営造物の設置・管理の瑕疵.md) |

**어느 쪽으로 구성할지가 첫 관문**이다. 예컨대 **도로 공사의 잘못**은 2조, **경찰관의 발포**는 1조다. 양쪽 다 성립하는 경우 원고는 **선택적으로 주장**할 수 있다.

## 손실보상과의 대비 — 최빈출

| | **国家賠償** | **[損失補償](용어/損失補償制度.md)** |
|---|---|---|
| 원인 행위 | **위법**한 행위 | **적법**한 행위 |
| 근거 | **憲法 17조** + 国家賠償法 | **憲法 29조 3항** |
| 요건 | 고의·과실(1조) 또는 하자(2조) | **특별한 희생** |
| 대상 | **생명·신체·재산 전부** | 원칙적으로 **재산권** |
| 일반법 | **있음**（国家賠償法） | **없음**（개별법 + 헌법 직접） |

**「위법 → 배상 / 적법 → 보상」**이라는 대비가 출발점이다.

**그 사이에 낀 영역** — 예방접종 피해, 원인이 특정되지 않는 손해 등은 어느 쪽으로도 잡기 어렵다(**국가보상의 谷間**). 판례는 **예방접종 피해에서 과실을 사실상 추정**해 **국가배상**으로 구제하는 방향을 취했다(最判平3.4.19 등).

## 憲法 17조와 입법재량

**郵便法違憲判決(最大判平14.9.11)** —

| 대상 | 판단 |
|------|------|
| **書留郵便物**에 대해 **고의·중과실**로 손해가 생긴 경우까지 면책·제한 | **憲法 17조 위반**（위헌） |
| **特別送達郵便物**에 대해 **경과실**로 손해가 생긴 경우까지 면책·제한 | **憲法 17조 위반**（위헌） |
| 통상 우편에 대한 면책·제한 | **합헌** |

**「법률이 정하는 바에 따라」라고 해도 입법부가 자유롭게 책임을 없앨 수는 없다**는 것을 확인한 판결이다. **特別送達은 재판 서류의 송달이라 확실성이 특히 요구된다**는 점이 결론을 갈랐다.

## 절차

| 항목 | 내용 |
|------|------|
| **소송의 형태** | **민사소송**（실무·판례） |
| **피고** | **국가 또는 공공단체**（[행정주체](용어/行政主体.md)）. **공무원 개인은 피고가 되지 않는다**（最判昭30.4.19） |
| **시효** | **民法 724조** — 손해 및 가해자를 안 때부터 **3년**（**생명·신체의 침해는 5년**, 724조의2） / 불법행위 시부터 **20년** |
| **[취소소송과의 관계](용어/国家賠償と取消訴訟との関係.md)** | **취소 불요**（最判昭36.4.21）. 취소소송의 **관련청구**로 병합 가능（行訴法 13조 1호·16조） |
| **과실상계·공동불법행위** | **民法의 규정이 적용**（4조） |

## 배상의 범위

**民法 709조 이하가 적용**되므로 **재산적 손해 + 정신적 손해(위자료)**가 모두 대상이 된다. **[公の営造物](용어/公の営造物.md)의 소음 피해**에서 위자료가 인정된 예가 대표적이다(大阪空港訴訟, 国道43号線訴訟).

## 💡 수험 팁

- **위법 → 배상 / 적법 → 보상.** 가장 먼저 세우는 축.
- **처분을 취소하지 않고도 국가배상을 청구할 수 있다**(最判昭36.4.21). 최빈출.
- **시효는 民法 724조**다. 「국가배상법에 3년의 시효 규정이 있다」는 지문은 **오답**.
- **공무원 개인은 피고가 되지 않는다**(最判昭30.4.19).
- **郵便法違憲判決의 위헌 부분은 「書留의 고의·중과실」과 「特別送達의 경과실」**이다. 「통상 우편의 면책 규정도 위헌」이라는 지문은 **오답**.
- **국가배상청구는 민사소송**으로 다툰다. 「공법상의 당사자소송으로 제기해야 한다」는 지문은 **오답**.

## 🎯 요점·예시

- **요점**: 행정이 **잘못해서** 손해를 입히면 배상, 행정이 **정당하게 했는데도** 특정인만 희생을 떠안게 되면 보상이다. 배상은 국가배상법이라는 일반법이 있지만, 보상은 개별법과 헌법에 직접 기대야 한다.
- **예시**: 시가 A의 땅을 도로 확장을 위해 정당한 절차로 수용하면 **손실보상**의 문제다. 반면 시 담당자가 착오로 A의 담을 헐어 버렸다면 **국가배상**의 문제가 된다. 같은 「땅을 잃었다」도 원인이 적법한지 위법한지에 따라 길이 갈린다.
