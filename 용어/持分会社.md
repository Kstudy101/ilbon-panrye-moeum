# 持分会社

| 항목 | 내용 |
|------|------|
| 읽기 | もちぶんかいしゃ（지분회사） |
| 과목 | 회사법（지분회사） |
| 한줄 정의 | **合名会社·合資会社·合同会社**의 총칭（575조 이하). 주식회사와 달리 **정관자치의 폭이 넓고**, **사원 = 원칙적으로 업무집행자**라는 **인적 회사**의 성격이 강하다 |
| 통설·판례 | **合同会社는 사원 전원이 유한책임이면서도 지분회사의 인적·자치적 구조**를 갖는, **2005년 신설**된 일본판 **LLC**（Limited Liability Company）다 |
| 한국 비교 | [회사의 종류와 설립](한국비교/회사의%20종류와%20설립.md) |

## 3종의 대비 — 사원의 책임

| | **合名会社** | **合資会社** | **合同会社** |
|---|---|---|---|
| 사원 구성 | **무한책임사원만** | **무한책임사원 + 유한책임사원** | **유한책임사원만** |
| 사원 수 | 1인 이상 | **2인 이상**（각 1인씩 최소） | 1인 이상 |
| 설립 시기 | 오래된 형태 | 오래된 형태 | **2005년 신설**（**LLC** 모델） |

## 주식회사와의 구조적 차이 — 최빈출

| | **株式会社** | **持分会社** |
|---|---|---|
| 기관설계 | 법정（주주총회·이사 등） | **정관자치**（법정 기관이 없음） |
| 업무집행 | 원칙 **이사(회)** | 원칙 **각 사원**（정관으로 業務執行社員을 특정 가능, 590조) |
| 지분의 양도 | 원칙 자유 | **원칙 다른 사원 전원의 동의**가 필요（585조 1항) — **인적 결합**을 반영 |
| 이익 분배 | **출자비율**（원칙, 주주평등원칙） | **정관에서 자유롭게 정할 수 있음**（621조 2항） — **손익분배 비율을 출자비율과 다르게 설정 가능** |
| 의사결정 | 다수결（지분비율） | 원칙 **총사원의 동의**（정관으로 완화 가능） |

**지분회사는 「법이 정한 틀」이 아니라 「정관으로 자유롭게 설계하는 계약적 조직」**이라는 것이 핵심 사상이다.

## 合同会社（LLC）의 특징 — 최근 시험 빈출

| 항목 | 내용 |
|------|------|
| **책임** | 사원 **전원 유한책임**（주식회사와 같음） |
| **내부 관계** | **지분회사의 자치적 구조**（주식회사와 다름） — 이익분배 비율을 자유롭게 설정, 기관설계도 자유 |
| **설립비용** | 주식회사보다 **저렴**（정관 인증 불요, 등록면허세도 저렴） |
| **정관 인증** | **불요** — 주식회사는 공증인 인증이 필요하지만 지분회사는 불요 |
| **결산 공고 의무** | **없음** — 주식회사는 원칙 필요（440조), 지분회사는 불요 |
| **활용 예** | 스타트업, 자회사, **외국 LLC의 일본 진출 자회사**（예: 애플재팬 합동회사, 아마존재팬 합동회사 등이 유명） |

## 정관 변경·사원의 가입·퇴사

| 항목 | 내용 |
|------|------|
| **정관 변경** | 원칙 **총사원의 동의**（637조) — 주식회사의 「특별결의」보다 엄격 |
| **사원의 가입** | 정관 변경이 필요（604조) → 원칙 총사원의 동의 |
| **사원의 퇴사**（606조 이하） | **임의퇴사**（존속기간을 정하지 않은 경우, 6개월 전 예고로 퇴사 가능) + **법정퇴사事由**（사망, 파산 등） |
| **持分의 払戻し** | 퇴사한 사원은 **지분의 환급**을 청구할 수 있음（611조） |

**「퇴사」와 「지분 환급」은 주식회사에는 없는 지분회사 특유의 제도**다. 주식회사의 주주는 「퇴사」하지 않고 **주식을 양도**함으로써 투하자본을 회수한다.

## 무한책임사원의 책임

**합명회사의 사원·합자회사의 무한책임사원**은 **회사의 채무를 완제할 수 없는 때** 또는 **회사재산에 대한 강제집행이 주효하지 않은 때**에 **연대해 변제할 책임**을 진다(580조 1항) — **회사 재산으로 부족한 부분에 대한 보충적·인적 책임**이다.

## 会社の解散判決 — 833조

**「부득이한 사유」**가 있을 때 **총사원의 의결권(주식회사는 총주주 의결권)의 10분의 1 이상**을 가진 사원(주주)은 **회사의 해산을 법원에 청구**할 수 있다. → [株主](용어/株主.md)의 소수주주권 표에서도 확인.

## 💡 수험 팁

- **합명회사 = 전원 무한책임 / 합자회사 = 무한+유한 혼합 / 합동회사 = 전원 유한책임.**
- **합동회사는 「유한책임」이지만 「지분회사의 자치적 구조」**를 가진다는 이중적 성격이 최빈출 — **「유한책임=주식회사와 같음」, 「내부관계=지분회사」**로 정리한다.
- **지분양도는 원칙 다른 사원 전원의 동의**가 필요하다. 「주식처럼 자유롭게 양도할 수 있다」는 지문은 **오답**.
- **이익분배 비율은 정관으로 출자비율과 다르게 정할 수 있다.** 주식회사의 주주평등원칙과 대비된다.
- **정관 인증 불요, 결산 공고 의무 없음**이 합동회사의 실무상 장점이다.
- **정관 변경은 원칙 총사원의 동의**（주식회사의 특별결의보다 엄격）.

## 🎯 요점·예시

- **요점**: 지분회사는 주식회사처럼 법이 짜 놓은 틀을 따르지 않고, 사원들끼리 정관으로 회사의 운영 방식을 자유롭게 설계할 수 있는 「계약적인」 회사 형태다. 그중 합동회사는 책임은 주식회사처럼 유한이면서 운영은 지분회사처럼 자유롭다.
- **예시**: A와 B가 각각 90%, 10%를 출자해 합동회사를 세우면서도, 「이익은 반반씩 나눈다」고 정관에 정할 수 있다. 주식회사였다면 원칙적으로 출자비율대로만 배당해야 하지만, **지분회사는 정관자치로 이런 자유로운 설계가 가능**하다.
