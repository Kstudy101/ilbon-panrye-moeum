# 各国の政治体制

| 항목 | 내용 |
|------|------|
| 읽기 | かっこくのせいじたいせい（각국의 정치체제） |
| 과목 | 일반지식（정치） |
| 한줄 정의 | 주요국의 통치구조를 **議院内閣制·大統領制·半大統領制**로 분류해 비교. 일본의 통치구조(議院内閣制)와의 대비가 출제의 핵심 |
| 통설·판례 | 일본은 **議院内閣制**（憲法 66조 3항 — 내각은 국회에 연대책임)를 채택 |

## 3대 유형

| 유형 | 특징 | 대표국 |
|------|------|--------|
| **議院内閣制** | 행정부(내각)가 **입법부(의회)의 신임에 기초**해 성립·존속. 의회는 내각불신임, 내각은 의회해산으로 대항 | **영국, 일본, 독일**（단 독일은 대통령 존재） |
| **大統領制** | **행정부 수반(대통령)이 국민의 직접·간접 선거로 선출**되어 의회로부터 독립. **엄격한 권력분립**（의회는 대통령을 불신임할 수 없고, 대통령도 의회를 해산할 수 없음) | **미국** |
| **半大統領制**（이원정부제） | 국민이 선출한 대통령과 의회 신임에 기초한 총리가 **행정권을 분점** | **프랑스** |

## 議院内閣制의 특징 — 영국·일본

| | **영국** | **일본** |
|---|---|---|
| 원수 | **国王**（상징적) | **天皇**（상징적, 憲法 1조） |
| 행정 수반 | **首相**（하원 다수당 당수） | **内閣総理大臣**（국회의원 중에서 국회가 지명, 憲法 67조） |
| 의회 구조 | **양원제**（庶民院·貴族院） | **양원제**（衆議院·参議院） |
| 하원 우월 | **○** | **○**（[両院制](용어/両院制.md) 참조） |
| 내각의 책임 | 하원에 대한 **연대책임** | **국회에 대한 연대책임**（憲法 66조 3항） |

## 大統領制의 특징 — 미국

| 항목 | 내용 |
|------|------|
| **대통령의 선출** | **간접선거**（**選挙人団**을 통한 선출, 형식상 간접이나 실질적으로는 국민의 의사 반영） |
| **임기** | **4년**（**3선 금지** — 수정헌법 22조） |
| **의회와의 관계** | 대통령은 **의회에 법안 제출권이 없음**（교서를 통한 권고에 그침), **의회는 대통령을 불신임할 수 없음** |
| **탄핵**（Impeachment） | 하원이 소추, **상원이 재판**（출석의원 3분의 2 이상의 찬성으로 파면） |
| **위헌심사** | **연방최고재판소**가 담당（**付随的違憲審査制**, 마베리 대 매디슨 판결로 확립된 판례법리） |

**대통령제는 「권력의 분립이 엄격」**하다는 것이 의원내각제와의 근본적 차이다 — **행정부와 입법부가 서로의 존립을 좌우할 수 없다.**

## 半大統領制 — 프랑스

**대통령**（국민 직접선거, 외교·국방 등 담당)과 **首相**（의회의 신임에 기초, 내정 담당)이 **행정권을 나누어 갖는다**（**「同居政府(コアビタシオン)」**라 불리는, 대통령과 총리가 다른 정당 출신인 상황이 발생할 수 있음).

## 議会의 형태 — 一院制와 両院制

| | 대표국 |
|---|---|
| **一院制** | 한국, 중국, 스웨덴 등 |
| **両院制** | 일본, 영국, 미국, 독일, 프랑스 |

→ [両院制](용어/両院制.md)에서 상세히 다룬 일본의 양원제와 비교하며 정리한다.

## 💡 수험 팁

- **의원내각제 = 행정부가 의회에 종속(신임 기초) / 대통령제 = 행정부·입법부가 서로 독립.** 이 축을 먼저 세운다.
- **미국 대통령은 간접선거(선거인단)**로 뽑힌다. 「직접선거로 뽑힌다」는 지문은 엄밀히는 **오답**（실질은 국민의사 반영이지만 형식은 간접).
- **미국 대통령에게는 법안제출권이 없다.** 「대통령이 직접 법안을 제출할 수 있다」는 지문은 **오답**.
- **탄핵은 하원이 소추, 상원이 재판**한다.
- **프랑스는 半大統領制**로, 대통령과 총리가 행정권을 나눠 갖는 독특한 구조다.

## 🎯 요점·예시

- **요점**: 나라마다 「누가 정부를 이끄는가」의 구조가 다르다. 일본·영국은 의회가 신뢰하는 사람이 총리가 되고(의원내각제), 미국은 국민이 뽑은 대통령이 의회와 별개로 행정을 이끈다(대통령제).
- **예시**: 일본에서 내각이 국회의 신임을 잃으면 총리는 사임하거나 중의원을 해산해야 한다. 반면 미국에서는 의회가 대통령 정책에 반대해도 대통령을 사임시킬 수 없다 — 오직 **탄핵**이라는 특별한 절차로만 파면할 수 있다.
