# 行政改革

| 항목 | 내용 |
|------|------|
| 읽기 | ぎょうせいかいかく（행정개혁） |
| 과목 | 일반지식（정치·행정） |
| 한줄 정의 | 행정조직·인원·제도의 효율화·간소화를 도모하는 개혁의 총칭. **2001년 중앙성청 재편**과 **独立行政法人制度의 도입**이 대표적 |

## 2001年 中央省庁再編

**「1府22省庁」체제를 「1府12省庁」로 재편**（2001년 1월 1일 시행)한 대규모 행정개혁.

| 개혁 전 | 개혁 후 |
|---------|---------|
| 総理府 등 여러 부처가 분산 | **内閣府**로 통합·강화, 총리의 리더십 강화 |
| 예: 厚生省 + 労働省 | **厚生労働省**로 통합 |
| 예: 建設省 + 運輸省 + 国土庁 + 北海道開発庁 | **国土交通省**로 통합 |
| 예: 大蔵省 | **財務省**（금융행정은 金融庁로 분리） |

**内閣府의 신설**과 **内閣官房의 기능 강화**로 **총리(내각)의 종합조정 기능을 강화**한 것이 핵심 취지다.

## 独立行政法人制度

**2001년 独立行政法人通則法 시행**으로 도입 — 국가가 직접 실시할 필요는 없지만 **민간에 맡기면 실시되지 않을 우려가 있는 사무·사업**을 담당시키기 위해, **국가 행정조직으로부터 분리**해 **독립된 법인격**을 부여한 제도.

| 항목 | 내용 |
|------|------|
| **목적** | 효율성·자율성 향상（**PDCA**에 기한 업무 운영, 中期目標管理） |
| **예** | 国立公文書館, 造幣局, 都市再生機構, 国民生活センター 등 |
| **国立大学法人** | 별도의 **国立大学法人法**（2004년)에 의해 **国立大学法人**으로 법인화（독립행정법인과는 근거법이 다름) |

→ [行政主体](용어/行政主体.md)·[国の行政組織](용어/国の行政組織.md)에서 이미 다룬 「독립행정법인」과 연결된다.

## 규제개혁·행정 슬림화

| 시책 | 내용 |
|------|------|
| **規制緩和·規制改革** | 인허가 등 행정규제를 완화해 **민간의 활력**을 도모（1990년대 이후 지속적 추진） |
| **PFI**（Private Finance Initiative） | **PFI法**（1999년)에 근거해 공공시설의 정비·운영에 **민간자금·경영노하우를 활용** |
| **市場化テスト** | 官民競争入札 등을 통해 **공공서비스의 담당 주체를 민간과 경쟁**시킴（公共サービス改革法, 2006년） |
| **国家戦略特区** | 특정 구역에서 규제를 특례적으로 완화하는 제도 |

## 공무원제도 개혁

**国家公務員制度改革基本法**（2008년) 등을 거쳐 **内閣人事局**（2014년 설치)이 **간부직 공무원의 인사를 일원적으로 관리**하는 체제가 구축되었다 — **내각의 인사 통제를 강화**하는 방향의 개혁이다.

## 💡 수험 팁

- **2001년 중앙성청재편으로 「1府22省庁 → 1府12省庁」**로 축소되었다는 숫자를 기억한다.
- **후생성+노동성 = 후생노동성, 건설성+운수성+국토청+홋카이도개발청 = 국토교통성**이라는 통합 조합이 자주 출제된다.
- **독립행정법인은 2001년 도입**되었고, **国立大学法人은 별도의 법(2004년)에 의한 것**으로 근거법이 다르다는 점에 주의.
- **内閣人事局(2014년 설치)이 간부 공무원 인사를 일원 관리**한다는 최근 개혁도 챙긴다.

## 🎯 요점·예시

- **요점**: 일본의 행정개혁은 크게 「부처를 통폐합해 정리하는 것」과 「국가가 직접 하지 않아도 되는 일을 독립된 법인에 맡기는 것」 두 방향으로 진행되어 왔다.
- **예시**: 예전에는 후생성과 노동성이 따로 있었지만, 2001년 개혁으로 두 부처가 합쳐져 지금의 **厚生労働省**가 되었다. 또한 조폐국처럼 국가가 직접 운영하지 않아도 되는 사업은 **독립행정법인**으로 분리되어 효율적으로 운영되게 되었다.
