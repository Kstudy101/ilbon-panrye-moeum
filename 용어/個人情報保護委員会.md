# 個人情報保護委員会

| 항목 | 내용 |
|------|------|
| 읽기 | こじんじょうほうほごいいんかい（개인정보보호위원회） |
| 과목 | 제법령（개인정보보호） |
| 한줄 정의 | **2015년 개인정보보호법 개정으로 신설**된, 개인정보 보호 정책을 **일원적으로 감독**하는 **내각부의 외국**（3조기관). **마이넘버제도의 감독**도 함께 담당 |
| 통설·판례 | **国家行政組織法상의 위원회가 아니라 内閣府設置法에 근거**한 위원회 — [国の行政組織](용어/国の行政組織.md)의 「내각부」 소속 |
| 한국 비교 | [개인정보보호법](한국비교/개인정보보호법.md) |

## 설치와 지위

| 항목 | 내용 |
|------|------|
| **설치 근거** | **個人情報保護法 제6장** + **内閣府設置法**（**内閣府의 外局**） |
| **성격** | **合議制**의 행정위원회（이른바 **独立行政委員会**）— [国の行政組織](용어/国の行政組織.md)에서 다룬 「独立行政委員会」의 대표 예 |
| **위원 구성** | 위원장 1인 + 위원 8인（**両議院의 동의**를 얻어 총리대신이 임명） |
| **독립성** | 내각의 지휘감독으로부터 **직무상 독립**하여 직권 행사 |

## 소관 사무

| 사무 | 내용 |
|------|------|
| **감독** | **민간사업자 + 행정기관등**（2021년 개정으로 관민 통합 감독） |
| **마이넘버제도의 감독** | **番号法**（마이넘버법)상의 특정개인정보（마이넘버 포함 정보)의 취급 감독도 담당 |
| **가이드라인 책정** | 각 분야별 개인정보 취급 가이드라인 |
| **국제협력** | 외국의 개인정보보호 당국과의 협력（GDPR과의 상호인증 등） |

## 권한 — 사업자에 대한 감독

| 권한 | 조문 | 내용 |
|------|:----:|------|
| **보고 요구·현장검사**（立入検査) | 146조 | — |
| **지도·조언** | 147조 | — |
| **권고** | 148조 1항 | 법 위반이 있을 때 시정을 권고 |
| **명령** | 148조 2·3항 | **권고에 따르지 않는 경우 또는 개인의 중대한 권리이익 침해가 급박한 경우**에 시정을 명함 |
| **벌칙** | — | **명령 위반에는 형사벌**（1년 이하의 구금 또는 100만 엔 이하의 벌금 등） |

**「권고 → 명령 → 벌칙」의 단계적 구조**를 기억한다 — **곧바로 명령·처벌로 가지 않고 권고 단계를 원칙적으로 거친다**（다만 급박한 경우는 권고 없이 곧바로 명령 가능).

## 연혁 — 왜 신설되었나

| 연도 | 사건 |
|:----:|------|
| **2003년** | 개인정보보호법 제정（당초는 **각 소관대신이 분산 감독**하는 구조） |
| **2013년** | **番号法**（마이넘버법) 제정에 맞춰 **特定個人情報保護委員会** 설치 |
| **2015년** | 개인정보보호법 개정으로 **特定個人情報保護委員会를 「個人情報保護委員会」로 개편·확대**, **민간부문 전체의 개인정보 감독을 일원화** |
| **2021년** | 관민일원화 개정으로 **행정기관등까지 감독 범위 확대** |

**「特定個人情報保護委員会(마이넘버 전용) → 個人情報保護委員会(전체 통합)」로 확대 개편**되었다는 흐름이 최빈출이다.

## [国の行政組織](용어/国の行政組織.md)와의 위치 관계

| 3조기관인 위원회 | 소속 |
|------------------|------|
| **個人情報保護委員会** | **内閣府** |
| **公正取引委員会** | 内閣府 |
| **国家公安委員会** | 内閣府 |
| **公害等調整委員会** | 総務省 |

**내각부 소속의 위원회끼리 묶어서 기억**하면 효율적이다.

## 💡 수험 팁

- **2015년 신설**（特定個人情報保護委員会를 개편·확대)이라는 연혁이 최빈출.
- **내각부의 외국(3조기관)**이다 — [国の行政組織](용어/国の行政組織.md)의 위원회 분류와 연결해 이해한다.
- **감독의 단계는 「보고요구·검사 → 지도·조언 → 권고 → 명령 → 벌칙」**의 순서.
- **명령 위반에는 형사벌**이 따른다.
- **2021년 개정으로 행정기관등까지 감독 범위가 확대**되었다.
- 관련: [国の行政組織](용어/国の行政組織.md) · [個人情報保護法の総則](용어/個人情報保護法の総則.md) · [行政機関等の義務](용어/行政機関等の義務.md)

## 🎯 요점·예시

- **요점**: 개인정보보호위원회는 민간기업과 행정기관 양쪽의 개인정보 취급을 모두 감독하는 독립된 위원회다. 위반이 있으면 곧바로 처벌하지 않고 먼저 권고를 하고, 그래도 고쳐지지 않으면 명령을 내리는 단계적 방식을 쓴다.
- **예시**: A사가 개인정보를 부적절하게 취급했다는 사실이 드러나면, 개인정보보호위원회는 먼저 **시정을 권고**한다. A사가 이를 무시하면 위원회는 **명령**을 내릴 수 있고, 그마저 어기면 A사는 **형사처벌**의 대상이 된다.
