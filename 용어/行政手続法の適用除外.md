# 行政手続法の適用除外

| 항목 | 내용 |
|------|------|
| 읽기 | ぎょうせいてつづきほうのてきようじょがい（행정절차법의 적용 제외） |
| 과목 | 행정법（행정절차） |
| 한줄 정의 | **行政手続法 3조·4조**가 정하는 적용 제외. 성질상 절차를 요구하기 부적당하거나 다른 절차법이 있는 분야를 뺀다 |
| 통설·판례 | **지방공공단체가 하는 행정지도는 근거가 무엇이든 전부 적용 제외**（3조 3항）. 반면 **법률에 근거한 처분은 지자체가 해도 적용**된다 |

## 3조 1항 — 성질상의 제외 (전 16호)

| 분야 | 대표 예 | 처분 | 행정지도 |
|------|---------|:----:|:--------:|
| **국회·재판소** | 양원의 의결에 의한 처분, 재판·재판의 집행으로서의 처분 | 제외 | — |
| **회계검사** | 検査官会議에서 결정할 처분, 회계검사 시의 행정지도 | 제외 | 제외 |
| **형사** | 검찰관·검찰사무관·사법경찰직원이 하는 처분·행정지도 | 제외 | 제외 |
| **犯則事件** | 국세·지방세, 금상법·독점금지법 등의 범칙사건 | 제외 | 제외 |
| **학교·연수** | 학생·생도·연수생 등에 대해 **교육 목적 달성을 위해** 하는 처분·행정지도 | 제외 | 제외 |
| **수용시설** | 형무소·소년원·유치시설 등에서 **수용 목적 달성을 위해** 하는 처분·행정지도 | 제외 | 제외 |
| **공무원** | 공무원·공무원이었던 자에 대해 **직무·신분에 관해** 하는 처분·행정지도 | 제외 | 제외 |
| **출입국·귀화** | **외국인의 출입국, 난민 인정, 귀화**에 관한 처분·행정지도 | 제외 | 제외 |
| **시험·검정** | 오로지 **사람의 학식기능**에 관한 시험·검정의 결과에 대한 처분 | 제외 | — |
| **裁定** | 상반되는 이해를 가진 자 사이의 **이해 조정**을 목적으로 하는 재정 등（쌍방을 명의인으로 하는 것에 한함）·행정지도 | 제외 | 제외 |
| **현장 조치** | 공중위생·환경보전·방역·보안 등의 **사상이 발생한 현장**에서 경찰관 등이 하는 처분·행정지도 | 제외 | 제외 |
| **정보 수집** | 보고·물건 제출을 명하는 처분 등 **정보 수집을 직접 목적**으로 하는 처분·행정지도 | 제외 | 제외 |
| **불복신청의 재결** | 심사청구 등에 대한 **재결·결정** | 제외 | — |
| **의견 진술 절차 내부** | 청문·변명의 기회 부여 절차 안에서 하는 처분·행정지도 | 제외 | 제외 |

## 3조 3항 — 지방공공단체에 관한 제외 (최중요)

| 대상 | 적용 제외의 범위 |
|------|------------------|
| **처분** | **근거 규정이 조례·규칙에 있는 것에 한해** 제외 → **법률에 근거한 처분은 적용된다** |
| **행정지도** | **한정 없이 전부 제외** |
| **신고** | **근거 규정이 조례·규칙에 있는 것에 한해** 제외 |
| **명령등을 정하는 행위** | **한정 없이 전부 제외** |

즉 **지자체가 하는 행정지도와 지자체가 정하는 명령등에는 행정수속법이 일절 적용되지 않는다.**

대신 **46조**가 지방공공단체에 **행정수속조례** 제정의 **노력의무**를 지운다.

## 4조 — 국가기관 등에 대한 처분의 제외

**국가기관·지방공공단체의 기관 등을 명의인으로 하는 처분**으로서 그들이 **고유의 자격**에서 상대방이 되는 것은 적용 제외된다(4조 1항). 「행정 내부의 문제」이기 때문이다.

반대로 **지자체가 사업자로서 일반 사인과 같은 자격**으로 허가를 신청하는 경우에는 **적용된다**.

## 意見公募手続의 별도 제외

**39조 4항** — 다음 命令等에는 의견공모절차가 불요하다.
- 공익상 **긴급**하게 정할 필요가 있어 절차를 밟기 곤란한 때
- 납부해야 할 **금전의 산정 기준**을 정하는 것
- **다른 행정기관이 이미 의견공모절차를 거친** 命令等과 실질적으로 동일한 것
- 법률의 制定·改廃에 따라 **당연히 필요하게 되는 규정 정비**에 그치는 것 등

## 💡 수험 팁

- **지자체의 행정지도는 전부 적용 제외.** 「조례에 근거하지 않은 행정지도라면 적용된다」는 지문은 **오답**. 가장 잘 나오는 함정이다.
- **법률에 근거한 처분은 지자체가 해도 행정수속법이 적용**된다. 「지자체의 처분에는 일절 적용되지 않는다」는 지문도 **오답**.
- **공무원에 대한 처분은 제외**된다. 「공무원의 징계처분에도 청문 절차가 필요하다」는 지문은 **오답**（다만 국가공무원법이 별도의 절차를 둔다）.
- **외국인의 출입국·귀화는 제외**된다. → [マクリーン事件](헌법/マクリーン事件.md)에서 절차 논점이 나오지 않는 이유다.
- **시험·검정 결과에 대한 처분은 「처분」만 제외**되고 행정지도는 열거되어 있지 않다. 호마다 제외 범위가 다르다는 점을 의식한다.
- **긴급한 경우에는 의견공모절차를 생략할 수 있다.** → [命令等の制定](용어/命令等の制定.md)

## 🎯 요점·예시

- **요점**: 행정수속법은 모든 행정에 적용되는 것이 아니다. 재판·형사·수용시설처럼 성질상 다른 룰이 필요한 분야와, 지방자치를 존중해야 하는 분야는 빼 두었다.
- **예시**: A현이 조례에 근거해 A에게 시정을 권고했다고 하자. 이것은 **지자체의 행정지도**이므로 행정수속법이 적용되지 않고, A현이 스스로 만든 **행정수속조례**에 따르게 된다. 반면 A현 지사가 **법률**에 근거해 A의 영업허가를 취소한다면, 이때는 행정수속법의 **청문 절차**가 그대로 요구된다.
