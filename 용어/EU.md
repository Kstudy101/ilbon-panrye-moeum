# EU

| 항목 | 내용 |
|------|------|
| 읽기 | いーゆー（유럽연합） |
| 과목 | 일반지식（국제정치） |
| 한줄 정의 | **유럽 각국의 정치·경제 통합체**. **1993년 마스트리흐트 조약**（EU조약)으로 발족, 현재 **27개국**（영국은 2020년 이탈, **Brexit**） |
| 통설·판례 | **共通通貨ユーロ**는 EU 전 가맹국이 도입한 것이 아니다 — **일부 가맹국은 미도입**（영국은 이탈 전에도 미도입, 덴마크·스웨덴 등도 미도입） |

## 발족과 연혁

| 연도 | 사건 |
|:----:|------|
| **1952년** | **ECSC**（유럽석탄철강공동체) 발족 — 통합의 시초 |
| **1958년** | **EEC**（유럽경제공동체) 발족 |
| **1967년** | **EC**（유럽공동체)로 통합 |
| **1993년** | **마스트리흐트 조약** 발효 → **EU** 발족 |
| **1999년** | **ユーロ**（단일통화) 도입（계산상 통화로 도입, 2002년 지폐·주화 유통 개시） |
| **2009년** | **리스본 조약** 발효 — EU의 기본 구조 정비（**EU 대통령**·**외교안보 상급대표** 신설） |
| **2020년** | **영국이 EU 이탈**（Brexit） |

## 주요 기관

| 기관 | 역할 |
|------|------|
| **欧州理事会**（European Council） | 가맹국 정상들로 구성, EU의 **정치적 방향성**을 결정 |
| **欧州連合理事会**（각료이사회） | 가맹국 각료로 구성, **입법·정책 결정** |
| **欧州委員会**（European Commission） | EU의 **행정부**에 해당, **법안 제출권**을 독점 |
| **欧州議会**（European Parliament） | 가맹국 국민의 **직접선거**로 선출, **입법·예산 심의** |
| **欧州司法裁判所**（ECJ） | EU법의 해석·적용에 관한 재판 |

## ユーロ圏

**EU 가맹국 = 유로 사용국이 아니다**（최빈출 함정). **유로존（ユーロ圏）은 EU 가맹국 중 유로를 도입한 일부 국가에 한정**된다. **덴마크·스웨덴**은 EU 가맹국이면서도 유로를 도입하지 않았다（영국도 이탈 전까지 미도입).

## 域内自由移動 — 4대 자유

**物・サービス・資本・人**의 **역내 자유이동**이 EU 통합의 핵심 원리다. **シェンゲン協定**에 가입한 국가 사이에서는 **국경 검사 없이** 이동할 수 있다（단, EU 가맹국 = 셍겐협정 가입국이 아니다 — 아일랜드는 EU 가맹국이나 셍겐협정 미가입 등의 예외 존재).

## 💡 수험 팁

- **EU 가맹국 ≠ 유로 도입국.** 덴마크·스웨덴 등 미도입국이 있다는 점이 최빈출.
- **EU 가맹국 ≠ 셍겐협정 가입국**도 마찬가지로 일치하지 않는다.
- **마스트리흐트 조약(1993년)으로 EU가 발족**했다는 연도를 정확히 기억한다.
- **영국의 EU 이탈(Brexit)은 2020년**이다.
- **欧州委員会가 법안제출권을 독점**한다 — 유럽의회는 직접선거로 뽑히지만 법안 제출권은 없다는 점이 특이하다.
- 관련: [国際連合](용어/国際連合.md) · [G7サミット](용어/G7サミット.md) · [国際貿易](용어/国際貿易.md)

## 🎯 요점·예시

- **요점**: EU는 유럽 여러 나라가 정치·경제적으로 하나처럼 움직이기 위해 만든 연합체다. 다만 「EU에 속해 있다」와 「유로를 쓴다」는 서로 다른 이야기다.
- **예시**: 덴마크는 EU 가맹국이지만 자국 통화(크로네)를 계속 쓰고 있어 유로존에는 속하지 않는다. 반면 영국은 유로를 쓴 적도 없었지만, 2020년에는 아예 EU 자체에서 탈퇴했다.
