# 地方自治法の概要

| 항목 | 내용 |
|------|------|
| 읽기 | ちほうじちほうのがいよう（지방자치법의 개요） |
| 과목 | 행정법（지방자치） |
| 한줄 정의 | **憲法 92조**의 「지방자치의 본지」를 구체화한 법률. **団体自治**와 **住民自治**의 두 원리를 실현한다 |
| 통설·판례 | **住民自治**란 주민이 스스로·자기 책임으로 지역 사무를 처리하는 것, **団体自治**란 국가로부터 독립한 단체가 스스로 사무를 처리하는 것. 판례는 「지방자치의 본지」를 이 **양 요소의 결합**으로 이해한다 |

## 憲法 92조 — 지방자치의 본지

「지방공공단체의 조직 및 운영에 관한 사항은, **지방자치의 본지에 기해** 법률로 정한다」.

| 요소 | 내용 | 구체화 |
|------|------|--------|
| **団体自治** | 국가로부터 **독립한 법인격**을 가진 단체가 자기의 사무를 자기의 기관으로 처리 | [条例](용어/条例.md) 제정권, 자주재정권 |
| **住民自治** | 지역 주민이 **스스로의 의사**로 지역의 정치를 행함 | [直接請求](용어/直接請求.md), 長·議員의 直接公選（憲法 93조 2항） |

## 憲法상의 근거 조문

| 조문 | 내용 |
|------|------|
| **92조** | 지방자치의 본지 |
| **93조** | **1항** — 지방공공단체에 의회를 설치 / **2항** — **長·議員 그 밖의 吏員은 주민이 직접 선거** |
| **94조** | 지방공공단체는 **재산의 관리·사무의 처리·행정의 집행권**을 가지며 **법률의 범위 내에서 조례를 제정**할 수 있다 |
| **95조** | 특정 지방공공단체에만 적용되는 특별법은 **그 지방공공단체의 주민투표**에서 과반수의 동의가 필요 |

## 지방자치법의 목적 (1조)

「지방공공단체의 **구역, 조직 및 운영**에 관한 사항의 대강을 정하고, 아울러 국가와 지방공공단체 사이의 **기본적 관계**를 확립함으로써, 지방공공단체에 있어서의 **민주적이고 능률적인 행정의 확보**를 도모함과 동시에 지방공공단체의 **건전한 발달**을 보장하는 것을 목적으로 한다」.

## 국가와 지방의 관계 — 1999년 지방분권일괄법

**1999년(平成11년) 지방분권일괄법**으로 종래의 **機関委任事務**가 전면 폐지되고, **自治事務**와 **法定受託事務**의 2종으로 재편되었다. → [国の関与の手続き](용어/国の関与の手続き.md)

| 구분 | 내용 |
|------|------|
| **自治事務** | 지방공공단체가 처리하는 사무 중 **법정수탁사무 이외**의 것 |
| **法定受託事務** | 국가·도도부현이 본래 해야 할 사무이지만 **법률·정령**에 의해 지방공공단체가 처리하도록 정한 것 |

이 재편으로 **국가와 지방은 원칙적으로 「상하·주종」관계에서 「대등·협력」관계**로 전환되었다는 것이 지방자치법 총론의 핵심 서사다.

## 💡 수험 팁

- **団体自治 = 국가로부터의 독립 / 住民自治 = 주민의 자기결정.** 두 축을 먼저 세운다.
- **憲法 93조 2항 — 長과 議員은 모두 주민의 직접선거**로 뽑는다（**二元代表制**）. 국회의 議院内閣制와 대비된다.
- **1999년 지방분권일괄법으로 기관위임사무가 폐지**되었다는 연혁은 최빈출.
- **95조의 주민투표는 「특정 지방공공단체에만 적용되는 특별법」에 한정**된다. 일반법에는 적용되지 않는다.

## 🎯 요점·예시

- **요점**: 지방자치법은 「국가와 다른 독립된 단체로서 지역을 운영한다」는 것(단체자치)과 「그 운영을 주민이 직접 결정한다」는 것(주민자치) 두 가지를 뼈대로 지방공공단체의 조직과 운영을 정한 법이다.
- **예시**: A시가 조례를 만들어 독자적인 정책을 펴는 것은 **단체자치**의 발현이고, A시의 주민들이 시장·시의원을 직접 뽑거나 조례 제정을 직접 청구하는 것은 **주민자치**의 발현이다. 둘이 합쳐져야 「지방자치의 본지」가 완성된다.
