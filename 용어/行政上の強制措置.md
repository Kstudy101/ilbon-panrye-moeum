# 行政上の強制措置

| 항목 | 내용 |
|------|------|
| 읽기 | ぎょうせいじょうのきょうせいそち（행정상의 강제조치） |
| 과목 | 행정법（실효성 확보） |
| 한줄 정의 | 행정상의 의무 이행을 확보하기 위한 수단의 총칭. **[강제집행](용어/行政上の強制執行.md)·[즉시강제](용어/即時強制.md)·[행정벌](용어/行政罰.md)**과 그 밖의 새로운 수단들 |
| 통설·판례 | **모든 강제수단에는 법률의 근거가 필요**하다. 조례를 근거로 **대집행을 할 수는 없다**（行政代執行法 1조·2조 참조） |

## 전체 지도

| 대분류 | 종류 | 의무의 존재 | 성질 |
|--------|------|:-----------:|------|
| **[行政上の強制執行](용어/行政上の強制執行.md)** | **代執行 / 執行罰 / 直接強制 / 強制徴収** | **필요**（선행 의무 있음） | 장래를 향한 **의무 실현** |
| **[即時強制](용어/即時強制.md)** | 강제격리, 위험물 폐기, 泥酔者 보호 | **불요**（의무를 명할 여유가 없음） | 즉시의 **사실행위** |
| **[行政罰](용어/行政罰.md)** | **行政刑罰 / 秩序罰(過料)** | 필요 | 과거의 위반에 대한 **제재** |
| **その他의 수단** | **公表 / 給付拒否 / 課徴金 / 加算税 / 許認可の停止·取消し** | 유형에 따라 | 간접적 강제 |

## 강제집행 vs 즉시강제 — 최빈출 대비

| | **[強制執行](용어/行政上の強制執行.md)** | **[即時強制](용어/即時強制.md)** |
|---|---|---|
| **선행 의무** | **있다**（명령 → 불이행 → 강제） | **없다** |
| 전형 | 철거명령 → 代執行 | 소방법의 파괴소방, 감염증의 강제입원 |
| 법률의 근거 | 필요 | 필요 |

「먼저 하라고 시켰는가」가 유일한 구별점이다.

## 새로운 실효성 확보 수단

| 수단 | 내용 | 주의점 |
|------|------|--------|
| **公表** | 위반 사실을 공표해 사회적 제재를 가함 | **제재 목적의 공표에는 법률·조례의 근거가 필요**하다는 것이 통설. 정보 제공 목적이면 근거 불요 |
| **給付拒否** | 수도·가스 등의 공급을 거부 | **행정지도 관철 목적의 급수 거부는 위법**(最決平1.11.8 武蔵野マンション事件) → [行政契約](용어/行政契約.md) |
| **課徴金** | 부당이득 박탈·억지를 위한 금전 부과（独禁法 등） | 형벌과의 **병과가 二重処罰(憲法 39조)에 해당하지 않는가**가 논의되나 판례는 **합헌** |
| **加算税** | 신고 누락 등에 부과하는 세（過少申告加算税·重加算税） | **최判昭45.9.11** — 加算税와 형벌의 병과는 **憲法 39조에 위반하지 않는다** |
| **許認可의 정지·취소** | 위반자에 대한 영업정지·허가 취소 | 그 자체가 [不利益処分](용어/不利益処分.md) → 행정수속법의 청문·변명 절차 |

## 조례와 강제수단

| 수단 | 조례를 근거로 할 수 있는가 |
|------|:--------------------------:|
| **代執行** | **✕** — 「법률」에 의한 명령이 필요(行政代執行法 2조는 「법률(법률의 위임에 기한 명령, 규칙 및 조례를 포함한다)」이라 하여 **의무 부과는 조례로도 가능**하지만, **대집행 절차 자체는 행정대집행법이 일반법**) |
| **直接強制·執行罰** | **✕** — 개별 **법률**의 근거가 필요 |
| **強制徴収** | **✕** — 법률의 근거가 필요 |
| **過料**（질서벌） | **○** — 地自法 14조 3항에 근거해 조례로 5만 엔 이하의 과료를 정할 수 있다 |
| **行政刑罰** | **○** — 地自法 14조 3항에 근거해 조례로 2년 이하의 구금·100만 엔 이하의 벌금 등을 정할 수 있다 |

## 💡 수험 팁

- **강제집행 = 의무 있음 / 즉시강제 = 의무 없음.** 이 한 줄이 모든 문제의 출발점이다.
- **직접강제와 집행벌은 개별 법률의 근거가 필요**하고, 현행법상 예가 매우 적다. **집행벌의 유일한 현행 예는 砂防法 36조**다.
- **加算税와 형벌의 병과는 합헌**(最判昭45.9.11). 「이중처벌 금지에 반한다」는 지문은 **오답**.
- **제재로서의 公表에는 법률·조례의 근거가 필요**하다는 것이 통설이다.
- **조례로 벌칙(행정형벌·과료)은 정할 수 있지만 직접강제·강제징수는 정할 수 없다.** → [条例](용어/条例.md)
- 관련: [行政上の強制執行](용어/行政上の強制執行.md) · [即時強制](용어/即時強制.md) · [行政罰](용어/行政罰.md) · [条例](용어/条例.md)

## 🎯 요점·예시

- **요점**: 행정이 「하라」고 했는데 안 하면 어떻게 할 것인가에 대한 답이 강제조치다. 크게 **직접 실현시키는 길(강제집행)**, **명령 없이 곧바로 실력을 쓰는 길(즉시강제)**, **벌을 주어 겁을 주는 길(행정벌)** 세 갈래다.
- **예시**: A가 무허가 건축물을 지었다고 하자. 시는 ① 철거를 명하고 안 따르면 **대집행**으로 대신 헐고 비용을 청구하거나, ② **벌금**을 물리거나, ③ A의 이름을 **공표**할 수 있다. 반면 건물이 당장 무너져 행인이 다칠 상황이라면 명령을 기다리지 않고 **즉시강제**로 통행을 차단한다.
