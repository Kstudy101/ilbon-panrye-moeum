# リサイクル・廃棄物

| 항목 | 내용 |
|------|------|
| 읽기 | りさいくる・はいきぶつ（재활용·폐기물） |
| 과목 | 일반지식（환경） |
| 한줄 정의 | 폐기물 처리·재활용을 규율하는 법체계. **循環型社会形成推進基本法**을 정점으로 개별 리사이클법이 정비되어 있다 |
| 한국 비교 | [환경법제](한국비교/환경법제.md) |

## 법체계의 구조

```
環境基本法 (환경 정책 전반의 기본법)
   ↓
循環型社会形成推進基本法 (2000년 제정, 순환형 사회의 기본이념)
   ↓
① 廃棄物処理法 (폐기물의 적정 처리)
② 資源有効利用促進法 (리사이클 촉진 전반)
③ 개별 리사이클법 (용기포장·가전·건설·식품·자동차 등)
```

## 循環型社会形成推進基本法 — 3R + α

**「発生抑制(Reduce)·再使用(Reuse)·再生利用(Recycle)」**（**3R**）의 우선순위를 명시.

| 우선순위 | 원칙 |
|:---:|------|
| **① 발생억제**（Reduce） | 애초에 폐기물을 만들지 않음 |
| **② 재사용**（Reuse） | 그대로 다시 사용 |
| **③ 재생이용**（Recycle） | 원료로 재활용 |
| **④ 열회수**（Thermal Recycle） | 소각열의 이용 |
| **⑤ 적정처분** | 위 방법이 불가능한 것을 최종적으로 처분 |

**「Recycle이 최우선이 아니라 Reduce가 최우선」**이라는 우선순위가 최빈출이다.

## 개별 리사이클법 一覧

| 법률 | 대상 |
|------|------|
| **容器包装リサイクル法**（1995년） | 유리병·페트병·종이·플라스틱 용기포장 |
| **家電リサイクル法**（1998년） | **에어컨·TV·냉장고(냉동고)·세탁기(건조기)의 4품목** — 소비자가 재활용 비용을 부담 |
| **食品リサイクル法**（2000년） | 식품 관련 사업자의 재생이용 등 |
| **建設リサイクル法**（2000년） | 건설공사에서 발생하는 특정건설자재폐기물 |
| **自動車リサイクル法**（2002년, 2005년 전면시행） | 사용후 자동차의 재자원화. **소유자가 리사이클 요금을 부담**（원칙 신차 구입 시 예납） |
| **小型家電リサイクル法**（2013년） | 소형가전（휴대전화 등)에서 **레어메탈** 등을 회수 |
| **プラスチック資源循環促進法**（2022년 시행） | 플라스틱 제품의 설계부터 폐기까지 전 과정의 자원순환 촉진 — **최신 법률** |

## 家電リサイクル法의 구조

**대상 4품목**（에어컨·TV·냉장고·세탁기)에 대해, **소비자가 인수업자에게 인도 시 재활용요금을 지불**하고, **소매점(판매점)이 인수·인도 의무를 지며**, **제조업자가 재상품화 의무**를 진다는 **역할 분담**이 특징이다.

## 廃棄物処理法상의 폐기물 분류

| 분류 | 내용 |
|------|------|
| **一般廃棄物** | 가정 쓰레기 등（**시정촌**이 처리 책임） |
| **産業廃棄物** | 사업활동에 수반해 발생하는 폐기물（20종, **배출사업자**가 처리 책임, **都道府県**이 규제·감독） |
| **特別管理廃棄物** | 폭발성·감염성 등 특히 유해한 폐기물（일반·산업폐기물 각각에 「特別管理」 구분이 있음） |

**일반폐기물 = 시정촌 처리, 산업폐기물 = 배출사업자 처리(도도부현이 규제)**라는 역할 분담이 최빈출이다.

## 💡 수험 팁

- **3R의 우선순위는 Reduce > Reuse > Recycle.** 「재활용이 가장 우선」이라는 지문은 **오답**.
- **가전리사이클법의 대상 4품목 — 에어컨·TV·냉장고(냉동고)·세탁기(건조기)**를 정확히 외운다. **전자레인지·PC 등은 별도의 법(소형가전리사이클법 등)**으로 규율된다.
- **일반폐기물은 시정촌, 산업폐기물은 배출사업자(도도부현 규제)**라는 처리 책임의 주체가 다르다.
- **순환형사회형성추진기본법은 2000년 제정**이라는 연혁을 기억한다.
- **플라스틱자원순환촉진법은 2022년 시행**된 최신 법률이다.
- 관련: [地球環境保護条約](용어/地球環境保護条約.md) · [公害問題](용어/公害問題.md)

## 🎯 요점·예시

- **요점**: 쓰레기 문제는 「일단 버릴 것을 어떻게 재활용할까」보다 「애초에 쓰레기를 덜 만드는 것」이 먼저라는 원칙(3R) 아래, 물건 종류별로 세세한 리사이클법이 만들어져 있다.
- **예시**: A가 오래된 냉장고를 버리려 한다면 일반 쓰레기로 내놓을 수 없다. **가전리사이클법**에 따라 소매점에 인도하면서 **재활용요금을 지불**해야 하고, 소매점은 이를 제조업자에게 넘겨 재상품화 처리가 이루어진다.
