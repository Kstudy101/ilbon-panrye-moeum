# 親子関係

| 항목 | 내용 |
|------|------|
| 읽기 | おやこかんけい（친자관계） |
| 과목 | 민법（친족） |
| 한줄 정의 | **実子（嫡出子·非嫡出子）**와 **養子**로 구성되는 친자관계 규율. **2022년(令和4년) 개정으로 嫡出推定 제도가 대폭 개정**（2024년 시행） |
| 통설·판례 | **嫡出否認의 訴え**의 제소권자가 **父뿐이던 것에서 母·子에게도 확대**된 것이 최신 개정의 핵심 |

## 嫡出子와 非嫡出子

| 구분 | 내용 |
|------|------|
| **嫡出子** | **혼인 중에 포태**된 자（**772조**의 추정을 받는 자） |
| **非嫡出子**（婚外子） | 혼인 외에서 출생한 자 — **父와의 친자관계는 認知**（779조)로 발생 |

**최大決平25.9.4** — 비적출자의 **법정상속분을 적출자의 2분의 1**로 하던 구 900조 4호 단서를 **憲法 14조（평등원칙)에 위반**한다고 판단 → **2013년 개정으로 이 차별 규정은 삭제**되었다（이제 **적출자·비적출자의 상속분은 동일**).

## 嫡出推定 — 2022년 개정 (2024년 4월 시행) 최빈출

| | **개정 전** | **개정 후**（772조） |
|---|---|---|
| 추정 기준 | **혼인 성립일부터 200일 경과 후, 혼인해소일부터 300일 이내**에 출생한 子는 婚姻中에 포태한 것으로 추정 | **혼인 중에 포태한 子**는 夫의 子로 추정（원칙 동일 취지 유지） |
| **재혼 후 출생자의 부성 결정**（최대 함정） | **「전남편의 자」로 추정**되어 **재혼금지기간**（구 733조)이 필요했음 | **「재혼 후의 夫의 子」로 추정**（772조 3항 신설) — **재혼금지기간 자체가 불필요해져 폐지** |
| **嫡出否認의 訴え의 제소권자** | **夫만**（구 774조） | **夫 + 妻 + 子（法定代理人)까지 확대**（**774조**, 2022년 개정） |
| **제소기간** | **夫가 子의 출생을 안 날부터 1년** | **원칙 3년으로 연장**（777조 등） |

**「이혼 후 300일 이내에 출생한 子가 전남편의 子로 추정되어 무호적아동 문제를 낳던 것을 해소」**하기 위한 개정이 2022년 개정의 배경이다 — **재혼했다면 재혼 후의 남편의 子로 추정**하도록 바꾸어, **재혼금지기간이 불필요**해졌다.

## 認知 (779조 이하)

| 항목 | 내용 |
|------|------|
| **任意認知** | 부(또는 모)가 **임의로 인지**（혼외자와의 친자관계 확정) — 母子관계는 **원칙 분만의 사실로 당연 발생**（**認知 불요**, 최判昭37.4.27） |
| **強制認知**（787조） | 子·직계비속·법정대리인이 **인지의 소**를 제기해 재판으로 부자관계를 확정 |
| **胎児認知**（783조） | 태아에 대해서도 인지 가능（모의 승낙 필요） |
| **死後認知** | 부의 사망 후에도 **사망을 안 날부터 3년 이내**라면 인지의 소 제기 가능 |

## 養子縁組

| 종류 | 내용 |
|------|------|
| **普通養子**（792조 이하） | **실친과의 친자관계도 존속**한 채 양친자관계가 추가로 발생（**이중의 친자관계**） |
| **特別養子**（817조의2 이하） | **실친과의 친자관계가 원칙적으로 종료**（**단절형**）— **가정재판소의 심판**이 필요, **양친이 될 자는 원칙 배우자 있는 자（부부 함께）**, **양자의 연령은 원칙 15세 미만**（2019년 개정으로 6세 미만→15세 미만으로 완화） |

**「특별양자는 실친과의 관계가 원칙적으로 끊긴다」**는 점이 보통양자와의 최대 차이이며 최빈출이다.

**未成年者를 養子로 할 때는 가정재판소의 허가가 필요**（798조, 단 자기 또는 배우자의 직계비속을 양자로 하는 경우는 제외）— **미성년자 보호**를 위한 개입.

## 親権

| 항목 | 내용 |
|------|------|
| **친권자** | 원칙 **부모가 공동으로 행사**（818조 3항, 혼인 중), **이혼 시에는 부모 중 일방을 친권자로 지정**（819조） |
| **친권의 내용** | 身上監護権（820조), 財産管理権（824조） |
| **共同親権 논의**（최신 동향） | **2024년(令和6년) 개정으로 이혼 후에도 부모의 협의·심판에 의해 「공동친권」을 선택할 수 있게 되는 개정**이 성립（**시행은 2026년경 예정**）— **종전의 「이혼 후 단독친권 원칙」에서 큰 전환**으로, 최신 개정 동향으로 기억해 둘 만하다 |

## 💡 수험 팁

- **비적출자 상속분 차별은 2013년 개정으로 삭제**되었다（最大決平25.9.4를 계기로).
- **2022년 개정으로 재혼금지기간(구 733조)이 폐지**되고, **적출부인의 소의 제소권자가 母·子로도 확대**되었다는 것이 최신·최빈출 개정 포인트다.
- **모자관계는 인지 불요**（분만의 사실로 당연 발생), **부자관계(비적출)는 인지가 필요**.
- **특별양자는 실친과의 관계가 원칙 단절**된다 — 보통양자와의 최대 차이.
- **특별양자의 대상 연령이 2019년 개정으로 15세 미만으로 확대**되었다.

## 🎯 요점·예시

- **요점**: 부모자식 관계는 혼인 중 태어난 아이(적출자)에게는 자동으로 추정되고, 혼인 외의 아이는 「인지」를 거쳐야 아버지와의 관계가 인정된다. 2022년 개정으로 이혼 직후 재혼해 낳은 아이가 전남편 자식으로 잘못 추정되는 문제를 없앴다.
- **예시**: A(여성)가 이혼 후 200일 만에 재혼했는데, 재혼 후 100일 만에 아이를 낳았다고 하자. 개정 전이라면 이혼 후 300일 이내라서 **전남편의 자녀로 추정**되어 혼란이 생겼겠지만, 2022년 개정 후에는 **재혼한 현재 남편의 자녀로 추정**된다(772조 3항).
