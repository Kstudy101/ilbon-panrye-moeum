# 地方公共団体の執行機関

| 항목 | 내용 |
|------|------|
| 읽기 | ちほうこうきょうだんたいのしっこうきかん（지방공공단체의 집행기관） |
| 과목 | 행정법（지방자치） |
| 한줄 정의 | 지방자치법상의 **「執行機関」**은 [行政機関](용어/行政機関.md) 총론의 「실력행사기관」과 달리 **長과 각종 행정위원회**를 가리킨다. 지방자치법 특유의 용법 |
| 통설·판례 | 執行機関은 **多元主義**를 취한다 — **長에게 모든 권한을 집중시키지 않고** 분야별로 **독립된 행정위원회**를 병존시킨다 |
| 한국 비교 | [지방자치법](한국비교/지방자치법.md) |

## 「執行機関」이라는 말의 함정 — 재확인

| 문맥 | 의미 |
|------|------|
| [행정법 총론](용어/行政機関.md) | **警察官·徴税職員** 등 실력행사기관 |
| **지방자치법** | **長 및 각종 행정위원회** — 즉 **[行政庁](용어/行政機関.md)**에 해당 |

지방자치법 138조의2 — 「보통지방공공단체의 집행기관은 …… 당해 보통지방공공단체의 조례·예산 그 밖의 의회의 의결에 기한 사무 및 법령·규칙 그 밖의 규정에 기한 자기의 권한에 속하는 사무를 **성실히 관리하고 집행할 의무**를 진다」.

## 長

| 항목 | 내용 |
|------|------|
| **명칭** | 都道府県지사, 市町村長 |
| **선출** | **주민의 직접선거**（憲法 93조 2항） |
| **임기** | **4년** |
| **지위** | 지방공공단체를 **대표**하고 **사무를 총괄**（147조） |
| **겸직 금지** | 국회의원, 지방의회 의원, 지자체의 상근직원 등과 **겸직 불가** |
| **피선거권** | 都道府県지사는 **만 30세 이상**, 市町村長은 **만 25세 이상** |

## 다원주의 — 각종 행정위원회

**長에게 권한이 집중되면 정치적 중립성이 훼손될 우려**가 있는 분야(교육, 선거, 노동, 인사 등)는 **長으로부터 독립한 합의제 행정위원회**가 담당한다.

| 위원회 | 소관 | 설치 |
|--------|------|------|
| **教育委員会** | 교육 사무 | 都道府県·市町村 **필수** |
| **選挙管理委員会** | 선거 사무 | 都道府県·市町村 **필수** |
| **人事委員会 / 公平委員会** | 직원의 인사 | 규모에 따라 인사위원회 또는 공평위원회 |
| **監査委員** | 재무·사무의 감사 | **필수**（→ [住民監査請求](용어/住民監査請求.md)） |
| **公安委員会** | 경찰 사무 | 都道府県 |
| **労働委員会** | 노동쟁의 조정 | 都道府県 |
| **農業委員会** | 농지 사무 | 市町村（설치는 원칙 필수, 규모에 따라 예외） |
| **収用委員会** | 토지수용의 재결 | 都道府県 |

**모두 「長으로부터 독립」**해 있다는 것이 공통점이다. 다만 **예산 편성권은 長에게 전속**하므로(149조 2호), 행정위원회도 예산에 관해서는 長의 의견을 거쳐야 한다.

## 長의 권한 — 149조

| # | 내용 |
|:-:|------|
| 1 | 의회의 **의결에 부칠 사건**의 안건 제출 |
| 2 | **예산의 조정·집행** |
| 3 | 지방세의 부과징수, 분담금·사용료·수수료의 징수 |
| 4 | 결산을 의회의 인정에 부치는 것 |
| 5 | 회계의 감독 |
| 6 | 재산의 취득·관리·처분 |
| 7 | 공공시설의 설치·관리·폐지 |
| 8 | **証書 및 회계 장부의 작성** |
| 9 | 그 밖에 지방공공단체의 사무의 집행 |

## 附属機関

**138조의4 3항** — 지방공공단체는 **법률 또는 조례**에 의해 **자문기관(심의회 등)**을 설치할 수 있다. 국가의 [8조기관](용어/国の行政組織.md)에 대응하는 개념이다.

## 💡 수험 팁

- **지방자치법의 「執行機関」은 長과 행정위원회.** 총론의 「즉시강제를 하는 경찰관」과는 다르다는 점을 문맥으로 판단한다.
- **필수 설치 위원회**（교육위원회·선거관리위원회·감사위원 등）와 **임의·조건부 설치 위원회**를 구별해 두면 정오 판단이 쉬워진다.
- **예산 편성권은 長에게 전속**한다(149조 2호). 행정위원회가 독자적으로 예산을 편성할 수는 없다.
- **副知事·副市町村長의 선임에는 의회의 동의**가 필요하다.
- **부속기관은 법률 또는 조례**에 의한다. → 국가의 [審議会](용어/国の行政組織.md)에 대응.

## 🎯 요점·예시

- **요점**: 지방자치법에서 「집행기관」은 실제로 일을 집행하는 「기관장급」 조직들 — 시장·지사와 각종 위원회를 가리킨다. 정치색을 타면 곤란한 분야(교육·선거·경찰 등)는 시장의 지휘를 받지 않는 별도 위원회가 맡는다.
- **예시**: A시의 시장이 마음에 들지 않는 학교장을 인사에서 배제하려 해도, 학교 인사는 **市長이 아니라 教育委員会**가 관장하므로 시장이 직접 개입할 수 없다. 이런 「권한의 분산」이 지방자치법의 다원주의다.
