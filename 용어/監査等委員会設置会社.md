# 監査等委員会設置会社

| 항목 | 내용 |
|------|------|
| 읽기 | かんさとういいんかいせっちがいしゃ（감사등위원회설치회사） |
| 과목 | 회사법（기관설계） |
| 한줄 정의 | **2014년(平成26년) 개정으로 신설**된 기관설계. **감사역을 두지 않고**, 이사회 내의 **監査等委員会**（이사로 구성)가 감사를 담당한다（2조 11호의2, 399조의2 이하） |
| 통설·판례 | **[監査役(会)설치회사](용어/監査役その他.md)와 [指名委員会等설치회사](용어/指名委員会等設置会社.md)의 중간형**으로 설계되어, **감사역회설치회사보다 도입 부담이 적으면서도 사외이사 활용을 촉진**하는 것이 입법 목적 |

## 도입 배경 — 왜 신설했는가

**감사역회설치회사**는 사외이사 도입이 의무가 아니었고, **지명위원회등설치회사**는 지명·보수까지 위원회에 넘겨야 해 **경영진의 저항이 커 도입이 저조**했다. 이 사이의 간극을 메우기 위해 **2014년 개정으로 감사등위원회설치회사가 신설**되었다.

## 監査等委員会의 구성

| 항목 | 내용 |
|------|------|
| **구성원** | **이사**（監査等委員인 이사）로 구성. **3인 이상**, **과반수는 사외이사**（331조 6항） |
| **선임** | **주주총회**에서 **監査等委員인 이사와 그 외의 이사를 구별해 선임**（329조 2항) — **감사등위원인 이사는 다른 이사와 별도의 의안으로 선임** |
| **임기** | **감사등위원인 이사는 2년**（단축 불가), **그 외의 이사는 1년**（332조 3항 등） — **감사등위원의 독립성 확보를 위해 임기를 더 길게** |
| **해임** | 감사등위원인 이사의 해임에는 주주총회의 **특별결의**가 필요（보통의 이사 해임은 보통결의） |

## 監査役(会)설치회사와의 차이 — 최빈출

| | **監査役(会)설치회사** | **監査等委員会설치회사** |
|---|---|---|
| 감사 담당자의 지위 | **이사가 아닌 별도의 감사역** | **이사**（감사등위원인 이사） |
| 감사역의 의결권 | 이사회에서 **의견진술권만**（의결권 없음） | 감사등위원인 이사는 이사회의 **의결권을 가짐** |
| 감사역회의 필수 설치 | 大会社인 공개회사는 원칙 필수 | 감사등위원회설치회사를 선택하면 감사역 불요 |

**감사등위원은 「감사만 하는 사람」이 아니라 「이사회에서 표결까지 하는 이사」**라는 점이 감사역과의 결정적 차이다.

## 業務執行의 위임 — 감독형 이사회로의 접근

**감사등위원회설치회사는 이사회 결의로 業務執行의 결정을 이사에게 대폭 위임**할 수 있다(399조의13 5·6항) — **이사의 과반수가 사외이사인 경우**, 또는 **정관에 정함이 있는 경우**에 한해, [362조 4항](용어/取締役・取締役会.md)에 해당하는 중요업무집행결정까지도 위임 가능.

**감사역회설치회사보다 「의사결정의 기동성」을 높일 수 있다**는 점이 실무상 채택 유인이 된다.

## 지명·보수위원회의 부재

**指名委員会等설치회사와 달리, 감사등위원회설치회사에는 지명위원회·보수위원회가 없다.** 이사의 선임·보수는 **통상의 주주총회 절차**（이사회가 원안을 작성）에 따른다. 다만 **감사등위원회는 이사의 선임·보수에 관해 주주총회에서 의견을 진술할 권리**를 가진다(342조의2, 361조 6항) — **위원회가 직접 결정하지는 않지만 견제 기능**은 있다.

## 3종 기관설계 총정리

| | **監査役(会)설치회사** | **監査等委員会설치회사** | **指名委員会等설치회사** |
|---|---|---|---|
| 감사자의 지위 | 이사 아님 | **이사** | **이사** |
| 지명·보수위원회 | 없음 | **없음** | **있음**（직접 결정） |
| 사외이사 의무 | 원칙 불요（**공개대회사는 2021년 개정으로 의무화**） | **감사등위원회 과반수** | **각 위원회 과반수** |
| 도입 부담 | 상대적으로 낮음 | **중간** | 상대적으로 높음 |

**2021년(令和3년) 개정**으로 **감사역회설치회사인 공개회사 중 대회사(유가증권보고서 제출회사)에도 사외이사 1인 이상 설치가 의무화**되었다(327조의2) — 최신 개정 포인트로 기억해 둔다.

## 💡 수험 팁

- **2014년 개정으로 신설**되었다는 연혁이 최빈출.
- **감사등위원은 「이사」이며 이사회에서 의결권을 가진다.** 감사역과의 결정적 차이.
- **감사등위원인 이사의 임기는 2년(단축 불가), 다른 이사는 1년(단축 가능)** — 임기가 뒤집혀 있지 않은지 확인하는 문제가 나온다.
- **감사등위원인 이사와 그 외 이사는 선임 의안이 구별**된다.
- **감사등위원회설치회사에는 지명·보수위원회가 없다.** 「감사등위원회설치회사도 보수위원회가 개인별 보수를 정한다」는 지문은 **오답** — 그것은 지명위원회등설치회사의 특징.
- **2021년 개정으로 감사역회설치 공개대회사에 사외이사 설치가 의무화**되었다는 최신 지식도 함께 챙긴다.

## 🎯 요점·예시

- **요점**: 감사역 대신 「감사도 하고 이사회에서 투표도 하는 이사들의 위원회」를 두는 절충형 지배구조다. 지명위원회등설치회사만큼 부담이 크지 않으면서도 사외이사를 활용해 감사의 실효성을 높일 수 있다.
- **예시**: A회사가 감사역회설치회사에서 감사등위원회설치회사로 전환했다고 하자. 종전에 「의견만 말할 수 있던」 감사역과 달리, 새로 선임된 감사등위원(사외이사가 과반)은 **이사회에서 직접 표결에 참여**해 위법·부당한 업무집행 안건을 부결시킬 수 있게 된다.
