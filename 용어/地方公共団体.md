# 地方公共団体

| 항목 | 내용 |
|------|------|
| 읽기 | ちほうこうきょうだんたい（지방공공단체） |
| 과목 | 행정법（지방자치） |
| 한줄 정의 | **地方自治法 1조의3**이 정하는 **普通地方公共団体**（都道府県·市町村）와 **特別地方公共団体**（特別区·地方公共団体の組合·財産区）의 총칭 |
| 통설·판례 | **特別区는 특별지방공공단체**이며 「기초적인 지방공공단체」로서의 성격은 **1974년 개정으로 강화**되었다（**最大判昭38.3.27**은 당시 특별구를 憲法 93조의 「지방공공단체」가 아니라고 판시했으나, 그 후 특별구의 자치권이 확충되어 현재는 사정이 다르다） |
| 한국 비교 | [지방자치법](한국비교/지방자치법.md) |

## 전체 지도

| 대분류 | 종류 | 성격 |
|--------|------|------|
| **普通地方公共団体** | **都道府県** | **광역**의 지방공공단체 |
| | **市町村** | **기초**적인 지방공공단체 |
| **特別地方公共団体** | **特別区**（도쿄 23구） | 기초적 지방공공단체에 준하는 성격（1974년 개정으로 강화） |
| | **地方公共団体の組合** | **一部事務組合**（사무의 일부를 공동처리）, **広域連合**（광역행정을 위해 설치） |
| | **財産区** | 시정촌의 일부 구역이 산림·용수 등 재산을 소유·관리 |

## 都道府県과 市町村의 관계

**地自法 2조 5항** — 도도부현은 시정촌을 **포괄하는 광역**의 지방공공단체로서, **광역에 걸친 사무, 시정촌의 연락조정에 관한 사무, 규모·성질상 시정촌이 처리하는 것이 적당하지 않다고 인정되는 사무**를 처리한다.

**도도부현과 시정촌은 상하관계가 아니라 대등한 지방공공단체**다. 다만 광역사무의 배분상 역할이 다를 뿐이다.

## 特別区 — 최빈출

| 항목 | 내용 |
|------|------|
| **성격** | **특별지방공공단체**（보통지방공공단체가 아니다） |
| **범위** | 현재는 **도쿄도의 23구**만 해당 |
| **자치권** | **1974년 개정으로 「기초적인 지방공공단체」로서의 지위가 확립** — 원칙적으로 시정촌과 같은 사무를 처리 |
| **특례** | 上下水道, 소방 등 **일부 사무는 도쿄도가 일체적으로 처리**（大都市地域における特別区設置法상의 특례도 존재） |
| **재정조정** | **都区財政調整制度** — 도가 특별구세의 일부를 징수해 각 구에 재배분 |

**「도쿄도 23구는 보통지방공공단체다」는 지문은 오답**의 정석이다.

**大都市地域における特別区設置法(2012년)** — 정령지정도시 등을 폐지하고 특별구를 설치할 수 있게 한 법률로, **오사카도 구상**의 근거법으로 알려져 있다.

## 地方公共団体の組合

| | **一部事務組合** | **広域連合** |
|---|---|---|
| 목적 | 사무의 **일부**를 공동 처리 | **광역**에 걸친 행정 수요에 대응 |
| **국가·도도부현으로부터의 직접 권한 이양** | **불가** | **가능**（地自法 291조의2） |
| **직접청구·주민투표** | 없음 | **있음**（광역연합의 장·의원 해직청구 등） |
| 예 | 쓰레기 처리조합, 소방조합 | 후기고령자의료광역연합 |

## 財産区

시정촌 합병 등으로 **구 마을의 재산(산림·온천·용수 등)이 새 시정촌 전체가 아니라 원래의 구역만을 위해 관리**되어야 하는 경우에 설치된다. **법인격을 가지지만 독자의 의회·장은 없고**, 관리기관으로 財産区管理会 등을 둔다.

## 💡 수험 팁

- **特別区는 특별지방공공단체.** 「보통지방공공단체」라는 지문은 **오답**.
- **1974년 개정으로 특별구의 자치권이 강화**되었다는 연혁을 기억한다. 예전 최대판(最大判昭38.3.27)의 「특별구는 헌법상의 지방공공단체가 아니다」라는 판시는 **당시의 특수한 지위를 전제**로 한 것으로, 현재 상황과 그대로 등치할 수 없다는 점에 주의한다.
- **一部事務組合은 권한 이양을 직접 받을 수 없지만 広域連合은 가능**하다.
- **広域連合에만 직접청구·주민투표 제도**가 있다.
- **財産区는 법인격은 있지만 독자의 의회·장은 없다.**

## 🎯 요점·예시

- **요점**: 우리가 흔히 「지자체」라고 부르는 것 중에는 도도부현·시정촌 같은 「보통」의 것과, 도쿄 23구처럼 조금 특수한 지위를 가진 「특별」한 것이 있다.
- **예시**: 도쿄도 신주쿠구는 특별구로서 대체로 시(市)와 같은 일을 하지만, **상하수도 사업만은 도쿄도가 23구 전체를 묶어 운영**한다. 이런 특수성 때문에 특별구는 시정촌과 나란히 놓이면서도 법적으로는 「특별지방공공단체」로 분류된다.
