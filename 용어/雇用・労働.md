# 雇用・労働

| 항목 | 내용 |
|------|------|
| 읽기 | こよう・ろうどう（고용·노동） |
| 과목 | 일반지식（사회） |
| 한줄 정의 | **労働基準法·労働組合法·労働関係調整法**（노동3법)을 중심으로 하는 고용·노동 관계 법제. **헌법 27·28조**가 이념적 기초 |
| 통설·판례 | **労働基準法은 「강행법규」**로, 이를 밑도는 근로계약 조항은 **그 부분만 무효**가 되고 노동기준법의 기준이 대신 적용된다(**13조**) |
| 한국 비교 | [고용과 노동](한국비교/고용과%20노동.md) |

## 노동3권과 노동3법

| 헌법 | 권리 | 근거법 |
|------|------|--------|
| **28조** | **団結権**（노동조합 결성） | **労働組合法** |
| | **団体交渉権** | 労働組合法 |
| | **団体行動権**（쟁의권） | 労働組合法, 労働関係調整法 |
| **27조** | **勤労의 権利·義務**, 근로조건의 법정 | **労働基準法** |

## 労働基準法의 핵심 규정

| 항목 | 내용 |
|------|------|
| **均等待遇**（3조） | 국적·신조·사회적 신분을 이유로 한 차별 금지 |
| **男女同一賃金**（4조） | 성별을 이유로 한 임금 차별 금지 |
| **강제노동의 금지**（5조） | — |
| **労働時間**（32조） | **1일 8시간, 1주 40시간**이 원칙（법정노동시간） |
| **時間外·休日労働**（36조） | **36協定**（사용자와 과반수노조 또는 과반수대표자의 서면협정)을 체결·신고하면 예외적으로 가능 |
| **割増賃金**（37조） | 시간외·휴일·심야 노동에는 **할증임금** 지급 의무 |
| **年次有給休暇**（39조） | 6개월 계속근무 + 8할 이상 출근 시 **10일**부터 발생, 근속연수에 따라 증가 |
| **解雇의 制限** | **해고예고**（20조, 원칙 30일 전 예고 또는 예고수당) — **해고권 남용 법리**（労働契約法 16조로 명문화）는 **객관적으로 합리적인 이유 + 사회통념상 상당성**을 요구 |

## 非正規雇用의 규제

| 형태 | 근거법 |
|------|--------|
| **파견노동** | **労働者派遣法** |
| **유기고용**（계약직） | **労働契約法**（**5년 초과 시 무기전환 신청권**, 이른바 **無期転換ルール**, 18조） |
| **파트타임·유기고용노동자** | **パートタイム・有期雇用労働法** — **정규직과의 불합리한 대우 격차 금지**（균형·균등대우） |

**「무기전환룰」**은 유기계약이 **통산 5년을 초과**하면 노동자가 신청해 **무기고용으로 전환**할 수 있게 하는 제도로, **2013년 노동계약법 개정으로 도입**되었다.

## 男女雇用機会均等法

**1985년 제정** — 채용·배치·승진 등에서의 **성차별 금지**, **セクシュアルハラスメント 방지 조치 의무** 등을 규정. **1997년 개정으로 벌칙 강화·차별 금지 규정 정비**가 이루어졌다.

## 최저임금제도

**最低賃金法**에 근거해 **都道府県별 지역별 최저임금**과 **산업별 최저임금**이 설정되며, **매년 개정**된다. **최저임금 미만의 임금 약정은 그 부분이 무효**가 되고 최저임금이 적용된다는 점이 [労働基準法 13조](용어/雇用・労働.md)와 같은 강행적 구조다.

## 💡 수험 팁

- **노동3권(단결·단체교섭·단체행동)은 憲法 28조**가 근거다. → [労働基本権](용어/労働基本権.md)과 연결.
- **법정노동시간은 1일 8시간·1주 40시간**이며, 초과에는 **36협정**이 필요하다.
- **무기전환룰은 유기계약 통산 5년 초과**가 요건이다. **2013년 도입**.
- **최저임금 미만의 약정은 그 부분만 무효**가 되고 최저임금이 대신 적용된다 — 노동기준법 13조와 같은 구조.
- 관련: [労働基本権](용어/労働基本権.md) · [公務員](용어/公務員.md) · [社会保障制度](용어/社会保障制度.md)

## 🎯 요점·예시

- **요점**: 노동법은 사용자와 노동자 사이의 힘의 불균형을 바로잡기 위해 최소한의 근로조건을 강행적으로 정해 놓았다. 계약으로 이보다 나쁜 조건을 정해도 그 부분은 무효가 되고 법이 정한 기준이 대신 적용된다.
- **예시**: A가 회사와 「시간외 수당 없음」이라는 계약을 맺었다고 하자. 이 약정은 노동기준법 37조에 반해 **무효**이고, A는 법이 정한 **할증임금**을 청구할 수 있다.
