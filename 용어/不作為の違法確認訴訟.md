# 不作為の違法確認訴訟

| 항목 | 내용 |
|------|------|
| 읽기 | ふさくいのいほうかくにんそしょう（부작위의 위법확인소송） |
| 과목 | 행정법（행정구제） |
| 한줄 정의 | **3조 5항** — 행정청이 **법령에 기한 신청**에 대해 **상당한 기간 내에 어떠한 처분·재결도 하지 않는 것**의 위법 확인을 구하는 항고소송 |
| 통설·판례 | **원고적격은 「처분·재결에 대해 신청을 한 자」에 한정**된다(**37조**). **출소기간의 제한이 없다** |
| 한국 비교 | [행정소송의 유형과 소송요건](한국비교/행정소송의%20유형과%20소송요건.md) |

## 요건

| 요건 | 내용 |
|------|------|
| **① 법령에 기한 신청** | 법령상의 **신청권**이 있어야 한다. **[처분등의 요구](용어/処分等の求め.md)(行手法 36조의3)처럼 신청권이 없는 신출은 대상 밖** |
| **② 신청을 실제로 했을** 것 | 신청 자체가 없으면 부작위도 없다 |
| **③ 상당한 기간의 경과** | [標準処理期間](용어/申請に対する処分.md)이 유력한 판단 자료 |
| **④ 아무런 처분·재결도 없을** 것 | **거부처분이 있으면 부작위가 아니다** → **[취소소송](용어/取消訴訟.md)**의 영역 |

**원고적격(37조)** — 「不作為の違法確認의 소는 **처분 또는 재결에 대해 신청을 한 자**에 한해 제기할 수 있다」.

**신청이 적법할 필요는 없다.** 신청이 형식상 부적법하더라도 행정청은 **보정을 요구하거나 거부처분을 해야** 하므로(行手法 7조), 방치하면 여전히 부작위다.

## 판결의 한계 — 이 소송의 약점

**판결은 「부작위가 위법함」을 확인할 뿐**이고, **「어떤 처분을 하라」고 명할 수는 없다.**

판결 후 행정청이 **거부처분**을 하면 그것으로 부작위 상태는 해소된다. 원고는 다시 **취소소송**을 내야 한다.

**그래서 실무에서는 [申請型義務付け訴訟](용어/義務付け訴訟.md)과 병합해 제기**한다.

**37조의3 3항 1호** — 부작위형(신청형) 의무부여소송은 **부작위의 위법확인소송을 병합하여 제기하여야 한다**(**필요적 병합**).

| 상황 | 병합해야 할 소송 |
|------|------------------|
| **답이 없다**（부작위） | 義務付け訴訟 + **不作為の違法確認訴訟** |
| **거부당했다** | 義務付け訴訟 + **[取消訴訟](용어/取消訴訟.md) 또는 無効等確認訴訟** |

## 준용되는 규정 (38조)

| 준용 | 내용 |
|:----:|------|
| **○** | **23조**（행정청의 소송참가）, **24조**（직권증거조사）, **33조**（**구속력**）, 35조（소송비용） |
| **✕** | **14조（출소기간）** — 부작위가 계속되는 한 언제든 제소 가능 |
| **✕** | **25조 이하（집행정지）** — 멈출 처분이 없다 |
| **✕** | **32조（대세효）** — 취소판결이 아니므로 |

**33조(구속력)가 준용**되므로, 판결 확정 후 행정청은 **신속히 무언가 처분을 해야 할 의무**를 진다.

## 위법성 판단의 기준시

**판결시(구두변론 종결시)**다. 「지금 시점에 부작위가 계속되고 있는가」를 묻는 소송이기 때문이다. [취소소송의 처분시설](용어/本案審理.md)과 다르다.

## [審査請求](용어/審査請求の概要.md)의 부작위 불복과의 대비

| | **不作為の違法確認訴訟** | **부작위에 대한 [審査請求](용어/審査請求の概要.md)** |
|---|---|---|
| 판단 기관 | 법원 | 행정청 |
| 판단의 범위 | **위법만** | **위법 + 부당** |
| 결론 | 위법 확인만 | **일정한 처분을 하도록 명하거나 스스로 처분**（49조 3항） |
| 기간 제한 | 없음 | 없음 |

**심사청구 쪽이 더 강력한 결론을 낼 수 있다**는 점이 흥미롭다.

## 💡 수험 팁

- **「법령에 기한 신청」이 전제**다. 신청권이 없는 요구를 방치해도 이 소송은 낼 수 없다.
- **원고적격은 「신청을 한 자」에 한정**된다(37조).
- **거부처분이 있으면 부작위가 아니다.** 소송 도중에 거부처분이 나오면 **[소의 이익](용어/狭義の訴えの利益.md)이 소멸**하므로 취소소송으로 갈아타야 한다.
- **출소기간의 제한이 없다.**
- **판결로는 「어떤 처분을 하라」고 명할 수 없다.** 그래서 **의무부여소송과 병합**한다.
- **부작위형 의무부여소송에는 부작위위법확인소송의 병합이 필수**다(37조의3 3항 1호).
- **기준시는 판결시**다.

## 🎯 요점·예시

- **요점**: 행정이 신청을 받아 놓고 답을 주지 않을 때 「답을 안 주는 것 자체가 위법」이라고 확인받는 소송이다. 다만 **「허가해 주라」까지는 명할 수 없어** 단독으로는 힘이 약하다.
- **예시**: A가 허가를 신청하고 1년이 지나도 답이 없다고 하자. A가 이 소송만 내서 이기면 행정청은 답을 해야 하지만, **「불허가」라고 답해도 판결은 이행된 것**이 된다. 그래서 A는 처음부터 **「허가를 하라」는 의무부여소송을 함께** 내야 실질적인 구제를 받는다.
