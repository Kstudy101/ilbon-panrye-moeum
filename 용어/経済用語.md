# 経済用語

| 항목 | 내용 |
|------|------|
| 읽기 | けいざいようご（경제용어） |
| 과목 | 일반지식（경제） |
| 한줄 정의 | 행정서사 시험 일반지식에서 반복 출제되는 기초 경제지표·개념 모음 — **GDP, 인플레이션·디플레이션, 금융정책의 수단** 등 |

## 경제지표

| 지표 | 내용 |
|------|------|
| **GDP**（国内総生産） | **일정 기간에 국내에서 새로 생산된 재화·서비스의 부가가치 합계**. **속인주의가 아니라 속지주의**적 개념 — 외국인이 일본 국내에서 생산한 것도 GDP에 포함 |
| **GNI**（国民総所得, 구 GNP） | **자국민(속인주의)이 벌어들인 소득의 합계** — 해외에서 자국민이 번 소득도 포함, 국내의 외국인 소득은 제외 |
| **物価指数** | **CPI**（消費者物価指数）— 가계가 구입하는 재화·서비스의 가격 변동. **PPI**（企業物価指数）— 기업 간 거래 가격 |
| **失業率** | 노동력 인구 중 실업자의 비율 |

**「GDP는 속지주의, GNI는 속인주의」**라는 대비가 최빈출이다.

## 인플레이션 vs 디플레이션

| | **インフレーション**（물가 상승) | **デフレーション**（물가 하락） |
|---|---|---|
| 화폐가치 | **하락** | **상승** |
| 일반적 원인 | 수요 초과, 통화량 과잉 공급 | 수요 부족, 통화량 부족 |
| **デフレスパイラル** | — | **물가 하락 → 기업 수익 악화 → 임금·고용 감소 → 소비 위축 → 다시 물가 하락**의 악순환 |

**日本은 1990年代 이후 장기간 デフレ 경향**（이른바 「잃어버린 20년」)이 지속되어, **일본은행이 「물가안정목표(2%)」를 내세운 금융완화정책**을 추진해 왔다는 것이 일본 경제사의 핵심 서사다. → [戦後の日本の経済史](용어/戦後の日本の経済史.md)

## 金融政策의 수단

| 수단 | 내용 |
|------|------|
| **公開市場操作**（オペレーション） | 중앙은행이 국채 등을 매매해 시중의 통화량을 조절. **買いオペ**（매입→통화 공급 증가) / **売りオペ**（매각→통화 흡수） |
| **政策金利**의 조정 | 中央銀行이 시중은행에 대한 대출금리 등을 조정（단기금리 유도） |
| **預金準備率操作** | 시중은행이 중앙은행에 예치해야 할 준비금의 비율을 조정（현재 일본에서는 거의 활용되지 않음) |
| **量的緩和**（QE） | 정책금리가 거의 0%에 이른 상황에서 **중앙은행이 자산을 대량 매입**해 시중에 자금을 공급하는 비전통적 정책 |
| **마이너스金利政策** | **2016년 일본은행이 도입**（**日銀당좌예금의 일부에 마이너스 금리 적용**） |

## 재정정책 vs 금융정책 — 재확인

→ [財政の機能](용어/財政の機能.md)에서 이미 다룬 대비. **재정정책 = 정부(국회)가 담당, 금융정책 = 일본은행이 담당**한다는 역할 분담을 기억한다.

## 円高·円安

| | **円高**（엔고） | **円安**（엔저） |
|---|---|---|
| 엔의 가치 | **상승**（외화로 더 많은 것을 살 수 있음） | **하락** |
| 수출기업에의 영향 | **불리**（가격경쟁력 저하） | **유리**（가격경쟁력 상승） |
| 수입물가 | **하락** | **상승** |

**「엔고 = 엔의 가치가 오름 = 1달러를 사는 데 더 적은 엔이 필요」**라는 방향성을 헷갈리지 않도록 주의한다.

## 💡 수험 팁

- **GDP는 속지주의, GNI(GNP)는 속인주의.** 개념의 정의를 정확히 구별한다.
- **디플레스파이럴의 악순환 구조**（물가하락→수익악화→임금감소→소비위축→물가재하락)를 순서대로 이해해 둔다.
- **마이너스금리정책은 2016년 일본은행이 도입**했다는 연혁을 기억한다.
- **엔고=엔 가치 상승=수출기업 불리, 엔저=엔 가치 하락=수출기업 유리**라는 방향을 혼동하지 않는다.

## 🎯 요점·예시

- **요점**: 경제지표와 금융정책의 기본 개념들이다. GDP는 「그 나라 안에서」 생산된 것, GNI는 「그 나라 국민이」 번 것이라는 차이를 기억하고, 물가가 계속 떨어지는 디플레이션이 왜 위험한지를 이해해야 한다.
- **예시**: 일본에서 일하는 외국인 노동자가 만든 부가가치는 **일본의 GDP에는 포함**되지만, 그 노동자가 본국으로 송금한 소득은 **일본의 GNI에는 포함되지 않는다**（본국의 GNI에 포함).
