# 行政主体

| 항목 | 내용 |
|------|------|
| 읽기 | ぎょうせいしゅたい（행정주체） |
| 과목 | 행정법（총론·행정조직） |
| 한줄 정의 | 행정을 행하는 **권리·의무가 최종적으로 귀속하는 법인격**. 国·地方公共団体가 대표이고, 独立行政法人·公共組合 등도 포함된다 |
| 통설·판례 | 행정주체는 **법인격**을 가지고, 그 손발인 **[行政機関](용어/行政機関.md)**은 법인격을 갖지 않는다. 소송·배상의 상대방은 원칙적으로 **행정주체** |

## 개념

행정을 실제로 움직이는 것은 大臣이나 市長 같은 사람이지만, **권리·의무가 최종적으로 귀속하는 것은 「국가」나 「○○市」라는 법인격**이다. 이 법인격을 **행정주체**라 한다.

- **행정주체** = 법인격 있음 = 권리·의무의 귀속점 → **国, 東京都, ○○市**
- **[行政機関](용어/行政機関.md)** = 법인격 없음 = 행정주체를 위해 행위하는 지위 → **国土交通大臣, 東京都知事, ○○市長**
- **行政客体** = 행정권 행사의 상대방 → **국민·주민·사업자**

## 행정주체의 종류

| 종류 | 내용 | 예 |
|------|------|-----|
| **国** | 시원적 행정주체 | 日本国 |
| **普通地方公共団体** | 地自法 1조의3 | **都道府県·市町村** |
| **特別地方公共団体** | 地自法 1조의3 | **特別区**(도쿄 23구), **地方公共団体の組合**(一部事務組合·広域連合), **財産区** |
| **独立行政法人** | 국가 사무 중 일정 사무를 담당하도록 설립 | 国民生活センター, 造幣局, 都市再生機構 |
| **特殊法人·認可法人** | 개별법으로 설립 | 日本放送協会(NHK), 日本銀行 |
| **公共組合** | 조합원으로 구성되는 **사단**형 행정주체 | **土地区画整理組合, 土地改良区, 健康保険組合** |
| **営造物法人** | 인적·물적 시설이 법인화된 것 | **国立大学法人** |

**財産区**는 시정촌의 일부 구역이 산림·용수 등 재산을 소유·관리하는 경우에 인정되는 특별지방공공단체다. **広域連合**은 도도부현·시정촌이 광역 사무를 처리하려고 설립하며, **국가·도도부현으로부터 직접 권한 이양을 받을 수 있다**는 점이 一部事務組合과 다르다.

## 公共組合 — 사인이면서 행정주체

**土地区画整理組合**처럼 **조합원(사인)의 모임인데도 행정주체**가 되는 경우가 있다. 조합이 행하는 **換地処分**은 그 자체가 **행정처분**이며 항고소송의 대상이 된다.

이처럼 **행정주체 = 국가·지자체만**이라고 외우면 함정에 빠진다.

## 💡 수험 팁

- **「행정주체는 국가와 지방공공단체뿐」은 오답.** 独立行政法人·公共組合·営造物法人도 행정주체다.
- **特別区는 특별지방공공단체**다. 「도쿄 23구는 보통지방공공단체」라는 지문은 **오답**. → [地方公共団体](용어/地方公共団体.md)
- **취소소송의 피고는 「처분을 한 행정청이 소속하는 행정주체」**다(行訴法 11조 1항). **2004년 개정으로 「행정청 피고」에서 「행정주체 피고」로 바뀌었다.** 「피고는 처분청」이라는 지문은 **개정 전 지식으로 오답**. → [取消訴訟](용어/取消訴訟.md)
- **국가배상의 배상책임자도 행정주체**다. 공무원 개인은 피해자에게 직접 책임지지 않는다(最判昭30.4.19). → [国家賠償法の概要](용어/国家賠償法の概要.md)
- **一部事務組合과 広域連合의 차이**: 광역연합만 **국가·도도부현에 권한 이양을 요청**할 수 있고 **직접청구** 제도가 있다.

## 🎯 요점·예시

- **요점**: 행정 일을 하는 사람(장관·시장)과 그 결과를 떠안는 주체(국가·시)는 다르다. 후자, 즉 **책임과 권리가 최종적으로 쌓이는 법인격**이 행정주체다.
- **예시**: A가 ○○市 시장의 영업허가 취소에 불복해 소송을 낸다고 하자. 실제로 처분을 한 사람은 시장이지만 **피고는 「○○市」**다. 시장은 시라는 법인격의 손발일 뿐, 스스로 재산을 가진 주체가 아니기 때문이다.
