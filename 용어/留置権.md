# 留置権

| 항목 | 내용 |
|------|------|
| 읽기 | りゅうちけん（유치권） |
| 과목 | 민법（담보물권） |
| 한줄 정의 | **民法 295조** — 타인의 물건을 점유하는 자가 **그 물건에 관해 생긴 채권**을 가질 때, 변제를 받을 때까지 그 물건을 **유치**할 수 있는 권리. **법정담보물권** |
| 통설·판례 | 유치권은 **우선변제적 효력이 없고**, 단지 **인도를 거부**함으로써 **사실상 변제를 압박**하는 효력에 그친다 |
| 한국 비교 | [담보물권](한국비교/담보물권.md) |

## 성립요건 (295조)

| # | 요건 |
|:-:|------|
| ① | **타인의 물건**을 점유할 것 |
| ② | **그 물건에 관해 생긴 채권**（**牽連性**）을 가질 것 |
| ③ | 채권이 **변제기**에 있을 것 |
| ④ | 점유가 **불법행위로 시작된 것이 아닐** 것（295조 2항） |

**②의 견련성**이 핵심 요건이다 — **[상사유치권](용어/商事担保.md)（견련성 불요)과의 결정적 차이**다.

## 견련성이 인정되는 대표 예

| 사례 | 견련성 인정 여부 |
|------|:-----------------:|
| **수리업자가 수리비를 못 받고 목적물을 유치**（수리대금채권 ↔ 그 물건） | **○** |
| **매매목적물의 하자로 인한 손해배상채권 ↔ 그 목적물** | **○**（하자와 관련된 채권이므로） |
| **건물의 임차인이 지출한 필요비·유익비상환청구권 ↔ 건물** | **○** |
| **이중매매에서 등기를 갖추지 못한 매수인이 목적물을 유치**（매매대금반환청구권 ↔ 목적물）를 주장 | **✕**（**最判昭43.11.21** — 부동산이 이중양도되어 제1매수인이 소유권을 상실한 경우, 매도인에 대한 손해배상채권과 목적물 사이에는 **견련성이 없다**고 판단） |

**「그 물건 자체로부터 생긴 손해」인지, 아니면 「그 물건을 잃었다는 것 자체로 인한 손해」인지**로 견련성 유무가 갈린다.

## 유치권의 효력

| 효력 | 내용 |
|------|------|
| **留置的効力** | 변제를 받을 때까지 **인도 거부** — 우선변제적 효력은 **없음** |
| **不可分性**（296조） | 채권 전부의 변제를 받을 때까지 **목적물 전부**에 대해 유치권을 행사 |
| **果実収取権**（297조） | 유치물로부터 생기는 **과실을 수취해 채권의 변제에 충당**할 수 있음 |
| **善管注意義務**（298조） | 유치권자는 **선량한 관리자의 주의**로 유치물을 점유해야 함 — 위반 시 **소멸청구**의 대상 |
| **競売権**（民事執行法) | 우선변제권은 없으나, **형식적 경매**로 환가할 수 있음（다만 경매대금에서 「우선」변제를 받는 것은 아니고 일반채권자와 같은 지위） |

## 소멸사유

| 사유 | 내용 |
|------|------|
| **298조 위반** | 선관주의의무 위반, **채무자의 승낙 없는 사용·대여·담보제공** → **소유자가 소멸을 청구**할 수 있음 |
| **299조 위반**（부적절한 대체담보 거부 등) | 채무자가 **상당한 담보를 제공**하고 유치권 소멸을 청구할 수 있음（301조） |
| **점유의 상실** | 유치권은 점유를 요건으로 하므로 **점유를 잃으면 원칙 소멸**（302조） |

## 유치권과 경매절차 — 실무상의 문제

**부동산 경매절차에서 유치권을 주장하는 자가 나타나면 매수인은 그 부담을 인수**해야 한다（유치권은 경매로 소멸하지 않는 「인수주의」）는 점에서, **경매의 원활한 진행을 저해하는 요소**로 실무상 자주 문제된다（이른바 **「유치권 남용」 문제**）.

## 💡 수험 팁

- **유치권 성립에는 「견련성」이 필수**다. 이 점이 **[商事留置権](용어/商事担保.md)（견련성 불요)과의 결정적 차이**다.
- **이중매매에서 손해배상채권과 목적물 사이에는 견련성이 부정**된다(最判昭43.11.21).
- **유치권에는 우선변제적 효력이 없다** — 단지 인도를 거부할 뿐이다. 「질권처럼 우선변제를 받는다」는 지문은 **오답**.
- **불법행위로 점유를 시작한 경우에는 유치권이 성립하지 않는다**（295조 2항）.
- **선관주의의무 위반, 무단 사용·대여는 소멸청구의 사유**가 된다.
- 관련: [商事担保](용어/商事担保.md) · [質権](용어/質権.md) · [同時履行の抗弁](용어/同時履行の抗弁.md)

## 🎯 요점·예시

- **요점**: 유치권은 「돈을 받을 때까지 물건을 돌려주지 않을 권리」다. 다만 아무 채권이나 되는 것이 아니라, **그 물건 자체와 관련해서 생긴 빚**이어야 한다.
- **예시**: A가 시계 수리를 맡겼는데 수리비를 내지 않으면, 수리업자 B는 수리비를 받을 때까지 **시계를 돌려주지 않을 권리(유치권)**가 있다. 하지만 시계를 팔아서 그 대금으로 먼저 돈을 회수할 권리(우선변제권)는 없다 — 그저 「돌려주지 않는 것」으로 A를 압박할 뿐이다.
