# 国際貿易

| 항목 | 내용 |
|------|------|
| 읽기 | こくさいぼうえき（국제무역） |
| 과목 | 일반지식（경제） |
| 한줄 정의 | 국가 간 재화·서비스의 거래를 규율하는 국제 체제. **GATT → WTO**의 다자간 자유무역체제와, **FTA·EPA** 등 지역·양자 협정이 병존 |

## GATT에서 WTO로

| | **GATT**（관세무역일반협정） | **WTO**（世界貿易機関） |
|---|---|---|
| 발족 | **1947년**（**잠정적 협정**으로 출발） | **1995년**（**정식 국제기구**） |
| 대상 | 원칙 **物品貿易**（재화） | **物品 + サービス貿易(GATS) + 지적재산권(TRIPS)**까지 확대 |
| 분쟁해결 | 약한 구속력（**전원합의제**로 사실상 거부권 존재) | **강한 구속력**（**紛争解決機関(DSB)**, 패널·상소기구, **역콘센서스 방식**으로 채택이 용이） |

**「GATT는 잠정협정, WTO는 정식 국제기구」**라는 지위의 차이가 최빈출이다.

## GATT의 3원칙

| 원칙 | 내용 |
|------|------|
| **自由**（관세·수량제한의 철폐） | 무역장벽의 축소 |
| **無差別**（**最恵国待遇** + **内国民待遇**） | **最恵国待遇**: 한 가맹국에 부여한 유리한 대우는 **다른 모든 가맹국에도 동등하게** 부여. **内国民待遇**: 수입품을 **국내산과 동등하게** 취급 |
| **多角**（다자간 교섭） | 다수국 간의 **라운드**를 통한 교섭（**우루과이 라운드**로 WTO 발족에 이름） |

## FTA·EPA — 지역·양자간 협정

| | **FTA**（自由貿易協定） | **EPA**（経済連携協定） |
|---|---|---|
| 범위 | **관세 철폐·무역장벽 제거**가 중심 | FTA + **투자·인적 이동·지적재산권** 등 **폭넓은 경제연계** |
| 일본의 특징 | — | **일본은 「EPA」라는 명칭을 주로 사용**（FTA보다 넓은 개념으로 추진） |

**일본이 체결한 대표적 협정**

| 협정 | 내용 |
|------|------|
| **TPP11**（CPTPP） | **환태평양 경제연계협정** — 미국 이탈 후 나머지 11개국이 재구성（**2018년 발효**） |
| **日EU・EPA** | 2019년 발효 |
| **RCEP**（지역적 포괄적 경제연계협정） | 일본·중국·한국·아세안·호주·뉴질랜드 등 **15개국** 참가（**2022년 발효**）— **일중·일한 최초의 경제연계협정**이라는 점에서 의의 |
| **日米貿易協定** | 2020년 발효 |

**RCEP는 「일본이 중국·한국과 처음으로 체결한 경제연계협정」**이라는 점이 자주 출제된다.

## 世界貿易機関(WTO)의 분쟁해결

**紛争解決機関(DSB)**의 **패널（1심)·상소기구（2심)**를 거치는 준사법적 절차. **「역콘센서스 방식」**（패널·상소 보고서는 **전원이 반대하지 않는 한 자동 채택**)을 채택해, **GATT 시대(전원합의로만 채택 가능해 사실상 무력화되기 쉬웠음)보다 훨씬 강한 구속력**을 갖는다.

## 💡 수험 팁

- **GATT(1947, 잠정협정) → WTO(1995, 정식 국제기구)**라는 이행 과정과 연도를 정확히 기억한다.
- **최혜국대우와 내국민대우**의 차이 — **최혜국대우는 「다른 나라 사이의」 평등**, **내국민대우는 「자국산과 수입품 사이의」 평등**.
- **일본은 FTA보다 넓은 「EPA」라는 틀을 주로 사용**한다.
- **RCEP는 일본·중국·한국이 참가하는 최초의 경제연계협정**이라는 점이 최빈출.
- **WTO의 분쟁해결은 역콘센서스 방식으로 구속력이 강화**되었다.

## 🎯 요점·예시

- **요점**: 세계 무역의 규칙은 GATT라는 임시 협정에서 시작해 WTO라는 정식 기구로 발전했다. 최근에는 여러 나라가 개별적으로 관세와 그 이상을 없애는 EPA·FTA 같은 협정도 활발히 맺고 있다.
- **예시**: 일본이 EU와 EPA를 체결하면 양측의 관세가 대폭 낮아진다. 나아가 RCEP처럼 **중국·한국을 포함하는 광역 협정**이 발효되면서, 일본은 이 두 나라와는 처음으로 정식 경제연계협정 관계를 맺게 되었다.
