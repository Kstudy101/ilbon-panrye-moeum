# 機関設計

| 항목 | 내용 |
|------|------|
| 읽기 | きかんせっけい（기관설계） |
| 과목 | 회사법（기관） |
| 한줄 정의 | 주식회사가 어떤 기관을 두어야 하는가·둘 수 있는가에 관한 회사법상의 조합 규율(326조~328조) |
| 통설·판례 | **주주총회와 이사는 모든 주식회사에 필수**. 그 위에 [공개회사](公開会社.md)인지, 대회사인지에 따라 이사회·감사·감사역회·회계감사인이 강제된다 |

## 개념

회사법은 **정관자치**를 넓게 인정하여 회사가 기관 구성을 상당히 자유롭게 고를 수 있게 했지만, **주주와 채권자의 이해가 커지는 회사일수록 감독기구를 강제**하는 구조를 취한다. 규율의 뼈대는 326조~328조에 있다.

**회사법 326조**
- **1항**: 「주식회사에는 **1인 또는 2인 이상의 이사**를 두어야 한다」 → 이사는 모든 주식회사에 **필수**.
- **2항**: 정관의 정함에 의해 **이사회·회계참여·감사·감사역회·회계감사인·감사등위원회·지명위원회등**을 둘 수 있다 → 그 외 기관은 원칙적으로 **임의**.

**주주총회**는 326조가 언급하지 않지만 회사법상 당연히 모든 주식회사에 존재하는 필요기관이다. 다만 **이사회설치회사에서는 주주총회의 권한이 「회사법에 규정하는 사항 및 정관으로 정한 사항」으로 축소**되고(295조 2항), **이사회를 두지 않는 회사에서는 주주총회가 일체의 사항을 결의할 수 있는 만능기관**이 된다(295조 1항). 이 대비가 최빈출이다.

### 판단의 전제가 되는 두 축

- **[공개회사](公開会社.md)인가** — 발행주식의 전부 또는 일부에 양도제한을 두지 않은 회사(2조 5호).
- **대회사(大会社)인가** — 최종 사업연도의 대차대조표상 **자본금 5억엔 이상** 또는 **부채 총액 200억엔 이상**인 회사(2조 6호). ※ 「또는」이지 「그리고」가 아니다.

### 기관설계의 규칙표

| 조문 | 규칙 |
|------|------|
| 326조 1항 | **모든 주식회사에 이사 필수**(＋주주총회) |
| **327조 1항** | **① 공개회사 ② 감사역회설치회사 ③ 감사등위원회설치회사 ④ 지명위원회등설치회사**는 **이사회를 두어야 한다** |
| **327조 2항** | **이사회설치회사**(감사등위원회설치회사·지명위원회등설치회사 제외)는 **감사를 두어야 한다**. **단, 공개회사가 아닌 회계참여설치회사는 예외** |
| 327조 3항 | **회계감사인설치회사**(감사등위원회설치회사·지명위원회등설치회사 제외)는 **감사를 두어야 한다** |
| 327조 4항 | **감사등위원회설치회사·지명위원회등설치회사는 감사를 두어서는 안 된다** |
| 327조 5항 | **감사등위원회설치회사·지명위원회등설치회사는 회계감사인을 두어야 한다** |
| 327조의2 | **공개회사이면서 대회사인 감사역회설치회사**로서 유가증권보고서 제출회사는 **사외이사를 두어야 한다** |
| **328조 1항** | **대회사 + 공개회사**(감사등·지명위원회등설치회사 제외) → **감사역회 및 회계감사인**을 두어야 한다 |
| **328조 2항** | **대회사 + 비공개회사**(감사등·지명위원회등설치회사 제외) → **회계감사인**을 두어야 한다 (감사역회는 불요) |

### 유형별 정리

| 회사 유형 | 이사회 | 감사 | 감사역회 | 회계감사인 |
|-----------|--------|------|----------|------------|
| 비공개·비대회사 | 임의 | 임의(이사회를 두면 원칙 필요) | 임의 | 임의 |
| **공개**·비대회사 | **필수** | **필수**(원칙) | 임의 | 임의 |
| 비공개·**대회사** | 임의 | 이사회를 두면 필요 / 회계감사인설치회사이므로 **필요** | 임의 | **필수** |
| **공개 + 대회사** | **필수** | 감사역회의 구성원으로 **필요** | **필수** | **필수** |

※ 감사등위원회설치회사·지명위원회등설치회사는 감사를 둘 수 없고 회계감사인이 필수라는 별도의 축을 이룬다.

### 기관의 최저 인원

| 기관 | 인원 |
|------|------|
| 이사(이사회 비설치회사) | **1인 이상**(326조 1항) |
| **이사회설치회사의 이사** | **3인 이상**(331조 5항) |
| **감사역회** | **감사 3인 이상, 그중 과반수는 사외감사**(335조 3항) |
| **지명위원회등의 각 위원회** | **위원 3인 이상, 그 과반수는 사외이사**(400조 1항·3항) |
| **감사등위원회** | **감사등위원인 이사 3인 이상, 그 과반수는 사외이사**(331조 6항) |

## 💡 수험 팁

- 출발점은 **「주주총회 + 이사」는 어떤 주식회사에도 반드시 있다**. 여기서 조건을 하나씩 얹어 간다.
- **공개회사 → 이사회 필수**(327조 1항 1호). **이사회 필수 → 이사 3인 이상**(331조 5항). 이 연쇄를 반사적으로.
- **이사회설치회사 → 감사 필수. 단 「비공개회사 + 회계참여설치회사」는 예외**(327조 2항 단서). 이 단서가 함정 지문의 단골이다.
- **대회사 판정은 「자본금 5억엔 이상」 또는 「부채 200억엔 이상」**(2조 6호). **「그리고」로 바꿔 놓은 지문은 오답.** 또 판정 기준은 **최종 사업연도의 대차대조표**다.
- **대회사인데 비공개회사면 회계감사인만 필수, 감사역회는 불요**(328조 2항). 「모든 대회사는 감사역회를 두어야 한다」는 지문은 **오답**.
- **감사등위원회설치회사·지명위원회등설치회사에는 감사를 둘 수 없다**(327조 4항). 「둘 수 있다」는 지문은 오답. 반대로 **회계감사인은 반드시 둔다**(327조 5항).
- **주주총회 권한의 축소**: 이사회 **비**설치회사 = 만능기관(295조 1항) / 이사회설치회사 = 법정사항·정관사항만(295조 2항). 방향을 뒤집은 지문 주의.
- 회계참여(会計参与)는 **어떤 회사도 임의**로 둘 수 있고, 자격은 **공인회계사·감사법인·세리사·세리사법인**에 한정된다(333조 1항).
