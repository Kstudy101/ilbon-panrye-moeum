# 会社設立

| 항목 | 내용 |
|------|------|
| 읽기 | かいしゃせつりつ（회사설립） |
| 과목 | 회사법（설립） |
| 한줄 정의 | 주식회사의 설립은 **[発起設立](용어/発起設立.md)**과 **[募集設立](용어/募集設立.md)**의 2가지 방법으로 이루어지며, **정관 작성 → 출자 이행 → 기관 구성 → 설립등기**의 순서를 밟는다 |
| 통설·판례 | 설립등기에 의해 회사는 **법인격을 취득**한다(49조). 정관은 **공증인의 인증**을 받아야 효력이 발생한다(30조) |

## 설립의 흐름

```
① 発起人이 정관 작성
   ↓
② 공증인의 정관 인증 (30조)
   ↓
③-A [発起設立] 발기인이 설립 시 발행주식 전부를 인수
③-B [募集設立] 발기인 인수분 외에 주주를 모집
   ↓
④ 출자의 이행 (금전 납입 또는 현물출자의 급부)
   ↓
⑤ 기관의 구성 (설립시 이사 등의 선임)
   ↓ (모집설립의 경우 창립총회)
⑥ 설립등기 → 법인격 취득 (49조)
```

## 정관의 기재사항

| 종류 | 내용 |
|------|------|
| **絶対的記載事項** | **목적, 상호, 본점 소재지, 설립 시 출자되는 재산의 가액(최저액), 발기인의 성명·주소** 등（27조） — **결여하면 정관 전체가 무효** |
| **相対的記載事項** | 정관에 기재하지 않으면 **효력이 생기지 않는** 사항. **[変態設立事項](용어/変態設立事項.md)**（현물출자, 재산인수, 발기인 보수, 설립비용）가 대표 |
| **任意的記載事項** | 정관에 기재하지 않아도 유효하지만 명확화를 위해 기재（주주총회 소집시기 등） |

## 정관의 인증 (30조)

정관은 **공증인의 인증**을 받아야 비로소 효력이 생긴다. **원시정관**（설립 시 최초의 정관）에만 인증이 필요하고, **그 후의 변경에는 인증이 불요**하다（주주총회의 특별결의로 충분）.

## 출자의 이행 — 発起設立과 募集設立의 차이

| | **発起設立** | **募集設立** |
|---|---|---|
| 출자 이행의 확인 | **발기인 스스로** 은행 등에 **보관증명서**를 요구할 필요 없이 **잔고증명**으로 족함（간이화） | **은행 등의 보관증명서**가 필요（64조） — 더 엄격 |
| 이유 | 발기인끼리의 관계이므로 남용 우려가 적음 | 불특정 다수의 인수인이 관여하므로 **엄격한 확인**이 필요 |

## 설립 중의 회사와 발기인조합

**설립 중의 회사**（設立中の会社）— 정관 작성부터 설립등기까지의 과도적 단계에서, 발기인이 취득한 권리의무가 **설립 후의 회사에 당연히 승계**된다고 설명하는 이론구성（**同一性説**）. 발기인이 설립을 위해 취득한 재산은 **설립등기와 동시에 특별한 이전행위 없이도 회사에 귀속**한다고 이해된다.

## 설립의 무효 — 設立無効의 訴え

| 항목 | 내용 |
|------|------|
| **주장 방법** | **설립무효의 소**로만 주장 가능（828조 1항 1호) — **소송 이외의 방법으로 무효를 주장할 수 없다**（법적 안정성） |
| **제소권자** | **주주·이사·감사 등**（828조 2항 1호） |
| **제소기간** | 회사 성립일로부터 **2년 이내** |
| **판결의 효력** | **대세효**（838조）, **장래효**（839조, 소급하지 않음） |

## 発起人의 책임

| 상황 | 책임 |
|------|------|
| **회사가 성립한 경우** | 임무해태로 회사에 손해를 끼쳤으면 **손해배상책임**（53조 1항） |
| **회사가 성립하지 않은 경우** | 발기인이 한 행위에 대해 **연대책임**（56조）. 지출한 비용도 발기인이 부담 |

## 💡 수험 팁

- **정관은 공증인의 인증을 받아야 효력이 생긴다**(30조). **원시정관에만** 필요하다.
- **모집설립에만 은행 등의 보관증명서가 필요**하다(64조). 발기설립은 잔고증명으로 족하다.
- **설립의 무효는 반드시 「설립무효의 소」**로만 주장할 수 있다. 「누구든지 언제든 무효를 주장할 수 있다」는 지문은 **오답**.
- **제소기간은 2년 이내.**
- **설립무효 판결은 소급하지 않는다**（장래효). 「무효판결이 확정되면 설립 시로 소급해 무효가 된다」는 지문은 **오답**.

## 🎯 요점·예시

- **요점**: 회사를 세우는 데는 정해진 절차가 있다 — 정관을 만들어 공증받고, 돈을 모아 내고, 임원을 정한 뒤 등기하면 비로소 법인이 된다. 발기인끼리만 돈을 대는 「발기설립」과, 외부에서도 주주를 모으는 「모집설립」 두 갈래로 나뉜다.
- **예시**: A와 B가 발기인이 되어 회사를 세우려 한다고 하자. 둘이서만 자본금을 전부 낸다면 **발기설립**이고, 부족한 자본을 외부 투자자 C·D에게서도 모은다면 **모집설립**이다. 모집설립 쪽은 낯선 사람의 돈이 걸려 있어 **은행의 보관증명서** 같은 더 엄격한 확인 절차를 거친다.
