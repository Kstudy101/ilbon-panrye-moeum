# 個人情報

| 항목 | 내용 |
|------|------|
| 읽기 | こじんじょうほう（개인정보） |
| 과목 | 일반지식（개인정보보호） |
| 한줄 정의 | **생존하는 개인**에 관한 정보로서 ① 성명·생년월일 등의 기술 등에 의해 특정 개인을 식별할 수 있는 것, 또는 ② **개인식별부호(個人識別符号)**가 포함된 것（개인정보보호법 2조 1항） |
| 통설·판례 | 최고재는 학번·성명·주소·전화번호와 같은 **비닉성이 낮은 단순 식별정보**도 프라이버시로서 법적 보호의 대상이라고 본다（[江沢民講演会事件](헌법/江沢民講演会事件.md)） |

## 개념

개인정보보호법(個人情報の保護に関する法律) 2조 1항은 「個人情報」를 **「생존하는 개인에 관한 정보」**로서 다음 두 유형 중 하나에 해당하는 것으로 정의한다.

- **1호형(식별형)** — 그 정보에 포함된 **성명·생년월일 기타 기술 등**에 의해 특정 개인을 식별할 수 있는 것. 괄호로 **「다른 정보와 용이하게 대조할 수 있고, 그에 의해 특정 개인을 식별할 수 있게 되는 것」**을 포함한다고 규정한다 → 이것이 **용이조합성(容易照合性)** 요건이다. 그 자체로는 개인을 알 수 없는 사원번호·고객번호라도, 사업자가 성명 대조표를 가지고 있어 쉽게 맞춰볼 수 있다면 개인정보가 된다.
- **2호형(부호형)** — **개인식별부호**가 포함된 것. 개인식별부호는 2조 2항이 정의하며, ① 지문·장문·DNA·얼굴·홍채·성문·보행 태양·손가락 정맥 등 **신체적 특징을 컴퓨터용으로 변환한 부호**, ② 여권번호·기초연금번호·운전면허증번호·주민표코드·**마이넘버(개인번호)**·각종 보험증 번호 등 **개인마다 다르게 할당된 부호**의 두 계열이다(구체적 항목은 정령·규칙 위임).

가장 큰 함정은 **「생존하는」**이라는 문언이다. **사망자에 관한 정보는 개인정보에 해당하지 않는다.** 다만 사망자의 정보가 동시에 유족 등 생존 개인을 식별할 수 있는 정보(예: 「A의 상속인 B」, 유전성 질환의 병력)인 때에는, **그 생존자의 개인정보로서** 법의 적용을 받는다. 또한 법인 그 자체의 정보도 개인정보가 아니지만, 법인 임직원 개인의 성명·직위는 개인정보다.

현행법은 **2021년(令和3년) 디지털사회형성정비법에 의한 개정법**으로, 종래 따로 있던 민간부문법·행정기관개인정보보호법·독립행정법인등개인정보보호법을 **1개의 법률로 통합(관민 일원화)**하고 감독을 **개인정보보호위원회(個人情報保護委員会)**로 일원화했다. 민간사업자·국가 행정기관 등에 대해서는 **2022년 4월 1일**, 지방공공단체·지방독립행정법인에 대해서는 **2023년 4월 1일** 시행되었다. **이 개정으로 조문 번호가 대폭 바뀌었으므로**(예: 제3자 제공 제한이 구법 23조 → 현행 **27조**), 구법 조문 번호로 쓰인 지문은 그 자체가 함정이 될 수 있다.

### 個人情報 ⊃ 個人データ ⊃ 保有個人データ

시험에서 가장 자주 나오는 포함관계다. 세 개는 **범위가 좁아질수록 사업자의 의무가 무거워지는** 3중 동심원 구조다.

```
┌──────────────────────────────────────────────────────┐
│  個人情報（2조 1항）                                 │
│   생존하는 개인 + 특정 개인 식별 가능 / 개인식별부호 │
│                                                      │
│   ┌────────────────────────────────────────────┐     │
│   │  個人データ（16조 3항）                    │     │
│   │   개인정보데이터베이스등을 구성하는        │     │
│   │   개인정보                                 │     │
│   │                                            │     │
│   │   ┌──────────────────────────────────┐     │     │
│   │   │  保有個人データ（16조 4항）      │     │     │
│   │   │   개시·정정·추가·삭제·이용정지·  │     │     │
│   │   │   소거·제3자제공정지 권한 보유   │     │     │
│   │   └──────────────────────────────────┘     │     │
│   └────────────────────────────────────────────┘     │
└──────────────────────────────────────────────────────┘
```

| 층위 | 근거 | 정의 | 그 층위에서 비로소 붙는 주된 의무 |
|------|------|------|-----------------------------------|
| 個人情報 | 2조 1항 | 생존 개인 + 식별 가능 / 개인식별부호 포함 | 이용목적 특정(17조), 목적외 이용 금지(18조), **부적정 이용 금지(19조)**, 적정 취득(20조), 이용목적 통지·공표(21조) |
| 個人データ | 16조 3항 | **개인정보데이터베이스등을 구성하는** 개인정보 | 데이터 내용의 정확성 확보(22조), **안전관리조치(23조)**, 종업자 감독(24조), 위탁처 감독(25조), **누설등 보고·본인 통지(26조)**, **제3자 제공 제한(27~31조)** |
| 保有個人データ | 16조 4항 | 개인데이터 중 사업자가 **개시·정정·이용정지 등을 할 권한을 가진** 것 | 사항의 공표 등(32조), **본인의 개시청구권(33조)·정정등 청구권(34조)·이용정지등 청구권(35조)** |

즉 **본인의 청구권(33~35조)은 「보유개인데이터」에만** 발생하고, **안전관리조치·제3자 제공 제한은 「개인데이터」에** 붙으며, 데이터베이스화되지 않은 산발적 메모 단계의 정보에는 **「개인정보」 단계의 의무만** 붙는다. 자세한 내용은 [個人データ](용어/個人データ.md)·[保有個人データ](용어/保有個人データ.md) 참조.

## 💡 수험 팁

- **「사망자의 정보도 개인정보다」는 오답.** 조문의 첫 단어가 「生存する」다. 단, **유족을 식별할 수 있으면 그 유족의 개인정보**가 된다는 2단계 논리까지 세트로 외운다.
- **대비: 개인식별부호 O ↔ X.** 여권번호·기초연금번호·운전면허증번호·주민표코드·마이넘버·지문·얼굴인식데이터는 **개인식별부호에 해당**. 반면 **휴대전화번호·메일주소·신용카드번호는 개인식별부호가 아니다**(다만 성명 등과 함께 있거나 용이조합성이 있으면 「개인정보」에는 해당할 수 있다). 이 둘을 바꿔치기한 지문이 단골.
- **용이조합성(容易照合性)**이 결정적이다. 「사원번호만으로는 개인정보가 아니다」는 지문은 오답 — 사업자 내부에 대조표가 있으면 개인정보다.
- **포함관계 3단은 무조건 암기**: 個人情報 ⊃ 個人データ ⊃ 保有個人データ. **개시·정정·이용정지 청구권은 「보유개인데이터」에만**, **안전관리조치·제3자 제공 제한은 「개인데이터」에만** 붙는다.
- **2022년 4월 관민 일원화로 조문 번호가 바뀌었다.** 제3자 제공 제한은 구법 23조 → **현행 27조**, 정의 규정 일부는 구법 2조 → **현행 16조**. 구법 번호를 쓴 지문·해설서에 속지 말 것.
- 「개인정보취급사업자」에는 **취급 건수 요건이 없다**. 2015년 개정으로 「5,000명분 이하 제외」 규정이 폐지되어, 개인정보데이터베이스등을 사업에 이용하면 **소규모 사업자·NPO도 모두 해당**한다(16조 2항).

## 🎯 요점·예시

- **요점**: 살아 있는 사람에 관한 정보로서, 이름·생년월일 등으로 누구인지 알 수 있거나 지문·여권번호 같은 개인식별부호가 들어 있는 것이다. 죽은 사람의 정보는 원칙적으로 해당하지 않는다는 점이 최대 함정이다.
- **예시**: 대학이 강연회 참가자 A의 학번·성명·주소·전화번호 명단을 본인 동의 없이 경찰에 넘긴 사안에서, 최고재는 이런 단순한 식별정보도 법적 보호의 대상이라며 불법행위를 인정했다(江沢民講演会事件). 또 사원번호 자체로는 누군지 몰라도 회사에 성명 대조표가 있어 쉽게 맞춰볼 수 있으면 그것도 개인정보가 된다.
