# 取締役・取締役会

| 항목 | 내용 |
|------|------|
| 읽기 | とりしまりやく・とりしまりやくかい（이사·이사회） |
| 과목 | 회사법（기관） |
| 한줄 정의 | 이사는 회사의 업무집행·의사결정을 담당하는 기관. 이사회설치회사는 **이사 3인 이상**으로 구성되는 **합의체(이사회)**가 **업무집행의 의사결정**을 한다 |
| 통설·판례 | 이사는 회사에 대해 **선관주의의무**(민법 644조 준용, 330조)와 **충실의무**(355조)를 진다. **経営判断の原則**（최判平22.7.15 등）으로 재량이 폭넓게 인정된다 |
| 한국 비교 | [회사의 기관과 계산](한국비교/회사의%20기관과%20계산.md) |

## 이사의 의무

| 의무 | 근거 | 내용 |
|------|------|------|
| **善管注意義務** | 330조（民法 644조 준용) | 「선량한 관리자의 주의」로 직무 수행 |
| **忠実義務** | **355조** | 법령·정관·주주총회 결의를 준수하고 회사를 위해 충실히 직무 수행（**선관주의의무와 동질**이라는 것이 통설·판례 — 最大判昭45.6.24） |
| **競業避止義務** | **356조 1항 1호** | 자기 또는 제3자를 위해 회사의 사업부류에 속하는 거래를 하려면 **이사회(또는 주주총회)의 승인**이 필요 |
| **利益相反取引의 규제** | **356조 1항 2·3호** | 이사와 회사 사이의 거래(직접거래)·회사가 이사의 채무를 보증하는 등(간접거래)에도 **승인**이 필요 |

**経営判断の原則** — 이사의 경영판단이 **① 판단 당시 합리적인 정보 수집·검토를 거쳤고, ② 판단 과정·내용에 현저한 불합리가 없다면**, 결과적으로 손해가 발생해도 **선관주의의무 위반이 되지 않는다**는 법리(**最判平22.7.15 아파마쇼핑事件** 등이 대표적으로 원용된다).

## 이사회의 권한 (362조)

| 권한 | 내용 |
|------|------|
| **업무집행의 결정** | 중요한 업무집행은 **이사회 결의**가 필요（중요재산의 처분·양수, 다액의 차재, 지배인의 선임·해임 등, 362조 4항) — **개별 이사에게 위임 불가** |
| **이사의 직무집행 감독** | — |
| **대표이사의 선정·해직** | 이사회설치회사에서는 이사회가 선정（362조 2항 3호） |

**362조 4항의 열거 사항은 「중요한 업무집행」으로서 개별 이사에게 위임할 수 없다**（**대표이사에게도 위임 불가**）는 점이 최빈출이다.

## 대표이사

| 항목 | 내용 |
|------|------|
| **권한** | 회사의 업무에 관한 **일체의 재판상·재판외의 행위**를 할 권한（349조 4항） |
| **권한 제한의 대항력** | 대표이사의 권한에 가한 제한은 **선의의 제3자에게 대항할 수 없다**（349조 5항） — [지배인](용어/支配人.md)의 21조 3항과 유사 |
| **表見代表取締役** | 사장·부사장 그 밖에 **회사를 대표할 권한이 있다고 인정될 명칭**을 붙인 이사의 행위에 대해, 회사는 **선의의 제3자**에 대해 책임을 진다（354조） → [지배인](용어/支配人.md)의 **표현지배인(24조)**과 같은 구조 |

## 이사의 회사에 대한 책임 — 423조

| 항목 | 내용 |
|------|------|
| **요건** | 임무해태로 회사에 **손해**를 끼쳤을 것 |
| **책임의 성질** | **과실책임**（다만 이익상반거래에서는 **임무해태가 추정**되는 등 입증책임이 조정되는 경우 있음, 423조 3항） |
| **책임의 면제** | **총주주의 동의**가 있으면 전액 면제（424조）. **주주총회의 결의**로 일정 한도까지 일부 면제 가능（425조, 요건 엄격） |

## [株主代表訴訟](용어/株主) — 847조

주주가 회사를 대신해 이사의 책임을 추궁하는 소송.

| 요건 | 내용 |
|------|------|
| **제소권자** | **6개월 전부터 계속 보유**한 주주（단독주주권. 비공개회사는 보유기간 요건 없음） |
| **절차** | 먼저 **회사에 대해 제소를 청구** → **60일 이내에 회사가 제소하지 않으면** 주주가 직접 제소 가능 |
| **긴급한 경우** | 60일을 기다리면 **회복할 수 없는 손해**가 생길 우려가 있으면 곧바로 제소 가능 |
| **소가**（訴訟の目的の価額） | **재산권상의 청구가 아닌 것**으로 간주（847조의4） — **소액의 정액 인지대**로 제기 가능 |
| **패소 시** | 원고 주주에게 **악의가 없는 한 회사에 대한 손해배상책임 없음**（852조） |

## 지명위원회등설치회사·감사등위원회설치회사와의 관계

**이사회설치회사가 원칙형**이며, [指名委員会等設置会社](용어/指名委員会等設置会社.md)·[監査等委員会設置会社](용어/監査等委員会設置会社.md)는 **감독·집행의 분리 정도가 다른 별도의 기관설계**다. → 각 항목 참조.

## 💡 수험 팁

- **362조 4항의 중요업무는 이사회 전결 사항으로, 대표이사에게도 위임할 수 없다.** 최빈출.
- **표현대표이사(354조)와 표현지배인(商法 24조)은 같은 「외관법리」**로 세트로 이해한다.
- **이사의 책임은 총주주의 동의로만 전액 면제**된다(424조). 「이사회 결의로 전액 면제할 수 있다」는 지문은 **오답**.
- **주주대표소송은 먼저 회사에 제소를 청구하고 60일을 기다려야** 하는 것이 원칙이다.
- **경영판단의 원칙 — 판단 과정의 합리성**을 보는 것이지 **결과의 당부를 사후적으로 재단하지 않는다**는 취지를 기억한다.

## 🎯 요점·예시

- **요점**: 이사회는 회사의 중요한 결정을 내리는 합의체이고, 대표이사가 실제로 회사를 대표해 행동한다. 이사는 회사를 위해 신중하고 성실하게 일할 의무를 지며, 이를 어겨 손해를 끼치면 주주가 대신 소송을 걸 수도 있다.
- **예시**: A회사의 대표이사 B가 이사회 결의 없이 회사의 중요 부동산을 처분했다고 하자. 이 처분은 **362조 4항 위반**으로 회사 내부적으로 문제가 되지만, **거래 상대방이 선의였다면 그 거래 자체는 유효**할 수 있다(349조 5항). 회사가 B의 책임을 묻지 않으면, 6개월 이상 주식을 보유한 주주 C가 **주주대표소송**으로 B의 책임을 추궁할 수 있다.
