## 개념

**물권(物権)**은 특정한 물건을 **직접·배타적으로 지배**하는 권리다. 여기서 「물건」이란 **유체물**을 말한다(**85조**).

### 물권과 채권의 대비

| 항목 | **물권** | **채권** |
|------|---------|---------|
| 성질 | **절대권**（모든 사람에게 주장 가능） | **상대권**（특정한 채무자에게만 주장 가능） |
| 객체 | **물건**（유체물） | 사람의 **행위**（급부） |
| 지배의 모습 | **직접지배** — 타인의 행위를 거치지 않는다 | 채무자의 행위를 **거쳐야** 목적을 달성 |
| **배타성** | **있음** — 동일 물건에 양립할 수 없는 물권은 하나만 | **없음** — 같은 내용의 채권이 여럿 성립 가능（이중매매도 채권으로서는 모두 유효） |
| 창설의 자유 | **없음 — 물권법정주의**（175조） | **있음 — 계약자유의 원칙** |
| 우선적 효력 | **물권은 채권에 우선**（매매는 임대차를 깨뜨린다） | — |
| 공시 | **필요**（[対抗要件主義](용어/対抗要件主義.md) — 등기·인도） | 원칙적으로 불요 |

### 물권법정주의 — 175조

> **물권**은, 이 법률 **그 밖의 법률**에 정하는 것 외에는, **창설할 수 없다**.

당사자가 마음대로 새로운 물권을 만들어 내면 **공시가 불가능해져 거래의 안전을 해치기** 때문이다. 취지는 ① 봉건적 토지지배관계의 부활 방지, ② **공시의 확보**에 있다.

「그 밖의 법률」의 예로는 **광업권·채석권**(광업법·채석법) 등이 있다.

**관습법상의 물권** — 175조를 문언대로 읽으면 관습법상의 물권은 인정될 수 없다. 그러나 판례는 **온천의 이용권(湯口権)**을 토지 소유권과 별개의 독립한 물권으로 인정하는 관습이 성립한 지역에서 이를 **관습법상의 물권**으로 승인했다(**大判昭15.9.18 鷹の湯事件**). ****譲渡担保**（양도담보）**·유수이용권 등도 같은 맥락에서 판례·학설상 물권으로 다루어진다. 즉 **175조는 실질적으로 완화되어 운용**된다.

### 일물일권주의(一物一権主義)

**하나의 물건 위에는 양립할 수 없는 물권이 하나만 성립**한다는 원칙. ① 물건의 **일부**나 ② **집합물** 위에는 원칙적으로 하나의 물권이 성립하지 않는다. 다만 판례는 **종류·소재 장소·양적 범위가 특정되면 집합물 전체를 하나의 물건으로 보아 **譲渡担保**의 목적으로 삼을 수 있다**고 하여 예외를 인정한다.

### 물권의 종류

| 분류 | | 물권 | 조문 |
|------|---|------|------|
| **점유권** | | **占有権** — 사실상의 지배 그 자체를 보호 | 180조~ |
| **본권** | **소유권** | **所有権** — 전면적 지배권 | 206조~ |
| | **용익물권** | **地上権**（지상권） | 265조~ |
| | | **永小作権**（영소작권） | 270조~ |
| | | **地役権**（지역권） | 280조~ |
| | | **入会権**（입회권） | 263조·294조 |
| | **담보물권** | **留置権**（유치권） — 법정담보물권 | 295조~ |
| | | **先取特権**（선취특권） — 법정담보물권 | 303조~ |
| | | **質権**（질권） — 약정담보물권 | 342조~ |
| | | **[抵当権](용어/抵当権.md)**（저당권） — 약정담보물권 | 369조~ |

민법이 정하는 물권은 **점유권 + 본권 9개 = 10종**이다. 여기에 **관습법상의 물권**(**譲渡担保**·온천권 등)이 더해진다.

### 물권의 효력

1. **우선적 효력** — ① **물권 상호 간**: 먼저 공시를 갖춘 물권이 우선. ② **물권과 채권 간**: **물권이 우선**한다(다만 부동산임차권은 借地借家法 등에 의해 물권화되어 예외가 많다).
2. **물권적 청구권** — 물권의 원만한 지배 상태가 방해받으면 그 회복을 청구할 수 있다. → [物権的請求権](용어/物権的請求権.md)

### 물권변동 — 176조(의사주의)

> 물권의 설정 및 이전은, **당사자의 의사표시만으로** 그 효력이 생긴다.

일본법은 **의사주의**를 채택하여, 매매계약이 성립하면 **그 순간 소유권이 이전**된다(특정물의 경우. 특단의 약정이 없는 한 계약 시). 등기·인도는 **효력요건이 아니라 대항요건**이다(177조·178조). 상세는 **[対抗要件主義](용어/対抗要件主義.md)** 참조.

## 💡 수험 팁

- **물권 ↔ 채권의 대비표**를 통째로. 특히 **① 배타성의 유무 ② 창설 자유의 유무 ③ 물권이 채권에 우선**의 세 가지가 출제의 중심이다.
- **175조의 문언은 「이 법률 그 밖의 법률에 정하는 것 외에는」**이다. **「관습법」이 문언에 들어 있지 않다**는 점을 정확히 기억한다. 그럼에도 **판례가 관습법상의 물권을 인정**한다는 이중 구조가 출제 포인트.
- **민법상의 물권은 10종**（점유권 + 소유권 + 용익 4 + 담보 4）. **유치권·선취특권은 법정담보물권**, **질권·저당권은 약정담보물권**이라는 짝을 함께 외운다.
- **176조는 의사주의**다. 「부동산 물권변동은 등기를 하여야 효력이 생긴다」는 지문은 **오답**(그것은 한국·독일의 형식주의). 일본에서 등기는 **대항요건**일 뿐이다.
- **이중매매도 채권으로서는 둘 다 유효**하다. 배타성이 없기 때문이다. 우열은 **등기(177조)**로 정해진다. 「이중매매의 두 번째 계약은 무효」라는 지문은 **오답**.
- **일물일권주의의 예외 — 집합물 양도담보**. 「종류·소재 장소·양적 범위가 특정되면」이라는 요건을 함께 기억한다.

## 🎯 요점·예시

- **요점**: 물건을 남의 도움 없이 직접, 그리고 나 혼자만 지배할 수 있는 권리로, 누구에게나 「이건 내 것」이라고 주장할 수 있다. 다만 아무 물권이나 마음대로 만들 수는 없고 법이 정한 것만 인정되며(물권법정주의), 일본에서는 계약을 맺는 순간 소유권이 넘어가고 등기는 제3자에게 내세우기 위한 표지일 뿐이다.
- **예시**: A가 자기 토지를 B에게 팔면 특약이 없는 한 **계약을 맺은 그 순간** 소유권은 B에게 넘어간다. 그런데 A가 같은 토지를 C에게도 팔았다면 B·C 두 매매계약은 채권으로서 **모두 유효**하고, 최종적으로 **먼저 등기를 마친 쪽**이 소유권을 확보한다(177조). 한편 A와 B가 「이 토지에 새로운 종류의 지배권을 창설한다」고 약정해도 법에 없는 물권이므로 효력이 없다(175조).
