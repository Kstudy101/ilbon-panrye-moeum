# 行政行為の分類

| 항목 | 내용 |
|------|------|
| 읽기 | ぎょうせいこういのぶんるい（행정행위의 분류） |
| 과목 | 행정법（행정작용） |
| 한줄 정의 | 행정행위를 **法律行為的**(의사표시를 요소로 함)과 **準法律行為的**(판단·인식의 표시)으로 나누고, 전자를 다시 **命令的行為 / 形成的行為**로 나누는 강학상 분류 |
| 통설·판례 | **법령상의 명칭과 강학상의 개념은 일치하지 않는다.** 「河川占用許可」는 강학상 **特許**, 「農地法 3조의 許可」는 강학상 **認可**, 「発明の特許」는 강학상 **確認** |
| 한국 비교 | [행정행위의 분류와 재량](한국비교/행정행위의%20분류와%20재량.md) |

## 전체 분류표

| 대분류 | 중분류 | 종류 | 내용 | 예 |
|--------|--------|------|------|-----|
| **法律行為的** | **命令的行為** | **下命·禁止** | 작위·부작위 의무를 부과 | 조세부과, 위법건축물 철거명령, 영업정지 |
| | | **許可** | **일반적 금지를 해제** | 운전면허, 음식점영업허가, 의사면허, 건축허가 |
| | | **免除** | 작위의무를 해제 | 취학의무 면제, 납세 유예 |
| | **形成的行為** | **特許** | 특정인에게 **새로운 권리·능력을 설정** | 도로점용허가, 공유수면매립면허, 광업허가, **귀화허가**, 공무원 임명 |
| | | **認可** | 제3자의 **법률행위를 보충해 효력을 완성** | 農地法 3조의 허가, 공공요금 인가, 법인 정관 변경 인가 |
| | | **代理** | 제3자가 해야 할 행위를 행정청이 대신 | 토지수용위원회의 재결, 감독청에 의한 임원 임명 |
| **準法律行為的** | | **確認** | 특정 사실·법률관계의 **존부를 공적으로 확정** | **建築確認**, 당선인 결정, 恩給裁定, **発明の特許** |
| | | **公証** | 특정 사실·법률관계의 존재를 **공적으로 증명** | 선거인명부 등록, 부동산등기, 각종 증명서 교부, 운전면허증 교부 |
| | | **通知** | 특정 사항을 **알림** | 납세 독촉, **代執行의 戒告** |
| | | **受理** | 타인의 행위를 **유효한 행위로 수령** | 각종 신청·신고의 수리 |

## 許可 · 特許 · 認可 — 최빈출 3형제

| | **許可** | **特許** | **認可** |
|---|---|---|---|
| 본질 | **금지의 해제** | **권리의 설정** | **효력의 보충·완성** |
| 원래 상태 | 누구나 가진 자유가 금지되어 있음 | 원래 그런 권리는 없음 | 당사자 간 계약은 이미 존재 |
| 재량 | 원칙 **기속적**（요건 충족하면 허가해야） | 원칙 **재량적** | 대상은 제3자의 **법률행위** |
| 무허가·무인가 행위의 효력 | **원칙 유효**（단 처벌·시정명령의 대상） | 무효 | **무효** |
| 예 | 운전면허, 음식점 영업허가 | 도로점용허가, 귀화허가 | 農地法 3조 허가 |

**무허가 영업으로 한 매매계약은 사법상 유효**하다는 것이 결정적 차이다. 반면 **農地法 3조의 허가(강학상 인가)를 받지 않은 농지 매매는 소유권이 이전되지 않는다.**

## 법령상의 명칭과 강학상 개념의 어긋남 — 함정 모음

| 법령상의 명칭 | 강학상의 성질 |
|---------------|---------------|
| **河川占用許可 · 道路占用許可** | **特許**（새로운 사용권 설정） |
| **公有水面埋立免許** | **特許** |
| **農地法 3조의 許可** | **認可**（매매계약의 효력을 완성） |
| **発明の特許** | **確認**（발명이 요건을 갖추었음을 확정） |
| **建築確認** | **確認** |
| **帰化許可** | **特許**（국적이라는 지위를 창설） |
| **運転免許証の交付** | **公証**（면허 자체는 許可） |

## 附款을 붙일 수 있는가

**법률행위적 행정행위에는 [附款](용어/行政行為の附款.md)을 붙일 수 있지만, 준법률행위적 행정행위에는 붙일 수 없다**는 것이 통설이다. 준법률행위적 행정행위의 효과는 **법이 직접 정한 것**이지 행정청의 의사에 의한 것이 아니기 때문이다.

## 💡 수험 팁

- **「許可 = 금지의 해제 / 特許 = 권리의 설정 / 認可 = 효력의 보충」**을 한 줄로 외운다.
- **무허가 행위는 유효, 무인가 행위는 무효.** 이 대비가 가장 자주 나온다.
- **「発明の特許는 강학상 特許」는 오답.** **確認**이다. 이름에 「特許」가 들어 있어 함정으로 최적이다.
- **「農地法 3조의 許可는 강학상 許可」는 오답.** **認可**다.
- **建築確認도 「確認」**이다. 다만 처분성은 인정되어 항고소송의 대상이 된다.
- **준법률행위적 행정행위에는 부관을 붙일 수 없다.** → [行政行為の附款](용어/行政行為の附款.md)

## 🎯 요점·예시

- **요점**: 행정행위를 「원래 자유였던 것을 풀어 주는가(허가)」, 「없던 권리를 새로 만들어 주는가(특허)」, 「이미 있는 계약에 도장을 찍어 완성시키는가(인가)」로 나누는 것이 핵심이다.
- **예시**: A가 무면허로 운전하면 처벌은 받지만, A가 운전해서 배달한 물건의 매매계약 자체는 유효하다(**허가**). 반면 A가 농지를 B에게 팔면서 農地法 3조의 허가를 받지 않으면, 돈을 다 주고받았어도 **소유권은 넘어가지 않는다**(**인가**).
