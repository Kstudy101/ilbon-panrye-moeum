# 公務員

| 항목 | 내용 |
|------|------|
| 읽기 | こうむいん（공무원） |
| 과목 | 행정법（행정조직）·헌법 |
| 한줄 정의 | 국가·지방공공단체의 사무를 담당하는 자. 憲法 15조는 **선정·파면을 국민 고유의 권리**로 하고 **「전체의 봉사자」**임을 선언한다 |
| 통설·판례 | 옛 **[特別権力関係](용어/特別権力関係.md)論은 부정**되었고 인권 제한에는 **법률의 근거**가 필요하다. 다만 **노동기본권·정치활동의 제한은 합헌**(全農林警職法事件·猿払事件) |

## 개념

- **憲法 15조 1항** — 공무원을 선정·파면하는 것은 **국민 고유의 권리**.
- **憲法 15조 2항** — 「모든 공무원은 **전체의 봉사자**이며 일부의 봉사자가 아니다」.
- 근거법: **国家公務員法·地方公務員法**.

| 구분 | 내용 |
|------|------|
| **一般職** | 특별직 이외의 모든 공무원. **국공법·지공법이 전면 적용** |
| **特別職** | 内閣総理大臣·国務大臣·裁判官·国会議員·防衛省 직원, 지자체의 長·議員 등. **원칙적으로 국공법·지공법 적용 제외** |

## 공무원 관계의 법적 성질

과거에는 **[特別権力関係](용어/特別権力関係.md)**로 파악해 법률의 근거 없이도 포괄적인 인권 제한이 가능하다고 보았다. 현재는 이 이론이 **부정**되고, 공무원의 인권 제한에도 **법률의 근거와 합리성**이 요구된다.

## 관련 판례

| 판례 | 인용 | 결론 |
|------|------|------|
| **全農林警職法事件** | 最大判昭48.4.25 | 공무원의 **쟁의행위 일률 금지는 합헌**. ① 지위의 특수성과 직무의 공공성, ② 근무조건 법정주의, ③ **대상조치**(人事院 勧告)의 존재 |
| **猿払事件** | 最大判昭49.11.6 | 국가공무원의 **정치적 행위 금지는 합헌**. 「행정의 중립적 운영과 그에 대한 국민의 신뢰」를 보호법익으로 함 |
| **堀越事件** | 最判平24.12.7 | 관리직이 아닌 직원이 **직무와 무관하게 휴일에 사적으로** 한 배포는 「정치적 행위」에 **해당하지 않는다** → 무죄. 猿払의 판단틀을 **한정 해석**으로 조정 |
| 공무원 개인의 배상책임 | 最判昭30.4.19 | 국가배상법 1조의 경우 **공무원 개인은 피해자에게 직접 책임을 지지 않는다** |
| 外国人의 관리직 승진 | 最大判平17.1.26（東京都管理職試験事件） | **[当然の法理](용어/当然の法理.md)** — 공권력 행사·공적 의사형성에 관여하는 직에는 일본 국적이 필요. 승진시험 수험 거부는 **합헌** |

## 分限処分 vs 懲戒処分 — 최빈출 대비

| | **分限処分** | **懲戒処分** |
|---|---|---|
| 성질 | **공무 능률 유지**를 위한 조치（제재 아님） | **의무 위반에 대한 제재** |
| 종류 | **免職·降任·休職·降給** | **免職·停職·減給·戒告** |
| 사유 | 근무실적 불량, 심신 고장, 직제 폐지 등 | 법령 위반, 직무상 의무 위반, 전체의 봉사자로서 부적합한 비행 |

**둘 다 「免職」이 있다**는 점이 함정이다. **降任·休職·降給은 분한**, **停職·減給·戒告는 징계**로 갈라 외운다.

## 💡 수험 팁

- **「전체의 봉사자」(15조 2항)**가 노동기본권·정치활동 제한을 정당화하는 논거로 쓰인다. → [労働基本権](용어/労働基本権.md)
- **全農林警職法事件의 3논거(지위의 특수성·근무조건 법정주의·대상조치)**는 그대로 출제된다. 특히 **人事院 勧告 = 대상조치**.
- **堀越事件은 猿払을 판례 변경한 것이 아니다.** 「猿払의 판단틀을 유지하면서 구성요건을 한정 해석했다」가 정확한 이해다.
- **분한 = 降任·休職·降給 / 징계 = 停職·減給·戒告.** 「戒告은 분한처분」이라는 지문은 **오답**.
- **공무원 개인은 피해자에게 직접 책임지지 않는다**(最判昭30.4.19). 다만 **고의·중과실이 있으면 국가가 구상**할 수 있다(国賠法 1조 2항). → [公務員の不法行為](용어/公務員の不法行為.md)

## 🎯 요점·예시

- **요점**: 공무원도 국민이므로 인권을 갖지만, 「전체의 봉사자」라는 지위 때문에 파업이나 정치활동에는 일반인보다 강한 제한이 걸린다. 대신 급여를 정치적으로 깎지 못하도록 인사원 권고 같은 보완 장치가 마련되어 있다.
- **예시**: 공무원 A가 파업에 참가했다면 처벌 대상이 된다. 반면 관리직이 아닌 공무원 B가 **쉬는 날에 사복으로 정당 홍보물을 배포**한 정도라면, 직무와의 관련성이 없어 처벌되지 않을 수 있다(堀越事件).
