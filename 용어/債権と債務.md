# 債権と債務

| 항목 | 내용 |
|------|------|
| 읽기 | さいけんとさいむ（채권과 채무） |
| 과목 | 민법（채권총론） |
| 한줄 정의 | **債権**은 특정인(債権者)이 다른 특정인(債務者)에게 **일정한 행위(급부)를 청구**할 수 있는 권리, **債務**는 그 대응하는 의무. **物権과 달리 특정인 사이에서만 효력**을 갖는 상대권 |
| 통설·판례 | 채권은 **급부의 내용에 따라 与える債務·なす債務** 등으로 분류되며, 이행불능·이행지체 등 [債務不履行](용어/債務不履行.md)의 논의가 채권법의 중심 |
| 한국 비교 | [채권의 효력과 책임재산의 보전](한국비교/채권의%20효력과%20책임재산의%20보전.md) |

## 물권과의 대비 — 채권법 총론의 출발점

| | **物権** | **債権** |
|---|---|---|
| 효력이 미치는 상대 | **누구에게나**（절대권） | **특정한 채무자에게만**（상대권） |
| 종류의 자유 | **物権法定主義**（175조, 법이 정한 종류만） | **契約自由의 原則**（내용을 자유롭게 정할 수 있음） |
| 배타성 | **하나의 물건에 하나의 물권**（一物一権主義） | **같은 내용의 채권이 여러 개 병존 가능** |

## 채권의 목적 — 급부의 분류

| 분류 | 내용 |
|------|------|
| **与える債務** | 물건의 인도·소유권 이전 등 「주는」 급부 |
| **なす債務** | 노무의 제공 등 「하는」 급부 — **작위채무·부작위채무** |
| **特定物債権** | **구체적으로 특정된 물건**의 인도를 목적（예: 「이 그림」) |
| **種類債権**（不特定物債権） | **종류·수량으로만 정해진** 물건의 인도（예: 「쌀 10kg」) — **401조**, 이행에 필요한 행위를 다하면（또는 채권자 동의로 물건을 지정하면) **특정**되어 이후 특정물채권과 같이 취급 |
| **金銭債権** | 금전의 지급을 목적. **이행불능이 관념상 없음**（**「金は借りたら返せ」**의 원칙, 419조 — 손해배상액은 원칙 법정이율） |
| **選択債権**（406조 이하） | **여러 급부 중 선택**에 의해 정해짐. 선택권은 **원칙 채무자**에게 있음 |

**특정물채권의 채무자는 「善良한 管理者의 注意」로 보존해야 한다**（400조, **善管注意義務**）.

## 채권자대위권·채권자취소권과의 위치 관계

채권은 원칙적으로 **채무자의 자유로운 재산 관리에 개입하지 않는다**（**私的自治의 존중**）. 다만 채무자의 **책임재산이 위태로워지면** 예외적으로 채권자가 개입할 수 있다 — → [債権者代位権](용어/債権者代位権.md), [詐害行為取消権](용어/詐害行為取消権.md).

## 💡 수험 팁

- **채권은 상대권, 물권은 절대권**이라는 기본 축을 먼저 세운다.
- **특정물채권 = 선관주의의무, 종류채권 = 특정 전까지는 같은 종류의 다른 물건으로 이행 가능**（**種類物은 특정되기 전에는 「멸실」이 관념상 없음** — 조달의무가 남음）.
- **금전채권에는 이행불능이 관념상 없다**（**419조**의 특칙 — 손해배상은 원칙 법정이율에 의함, 채권자는 손해의 증명 불요）.
- **선택채권의 선택권은 원칙 채무자**에게 있다（406조）.

## 🎯 요점·예시

- **요점**: 채권은 「특정한 상대방에게만 무언가를 요구할 수 있는 권리」다. 누구에게나 주장할 수 있는 물권과 달리, 채권은 그 계약이나 사건의 상대방에게만 효력이 있다.
- **예시**: A가 B에게 그림 한 점을 팔기로 계약했다면, A는 B에게만 대금을 청구할 수 있고, B는 A에게만 그림 인도를 청구할 수 있다. 만약 A가 실수로 같은 그림을 C에게도 팔았다면, B와 C 모두 A에 대한 채권을 갖지만 **그림 자체(물권)는 하나뿐**이므로 결국 등기·인도를 먼저 받은 쪽만 소유권을 얻는다.
