# 指名委員会等設置会社

| 항목 | 내용 |
|------|------|
| 읽기 | しめいいいんかいとうせっちがいしゃ（지명위원회등설치회사） |
| 과목 | 회사법（기관설계） |
| 한줄 정의 | **이사회 내에 지명·감사·보수의 3위원회**를 두고, **집행역**이 업무집행을 담당하는 **감독과 집행이 완전히 분리된** 기관설계（2조 12호, 400조 이하） |
| 통설·판례 | **각 위원회는 3인 이상**으로 구성되고 **과반수가 사외이사**여야 한다（400조 3항） — **미국형 지배구조**를 계수 |
| 한국 비교 | [회사의 기관과 계산](한국비교/회사의%20기관과%20계산.md) |

## 도입 배경

**2002년 상법 개정으로 「위원회등설치회사」로 도입**되었고, **2005년 会社法에서 「委員会設置会社」**, **2014년 개정으로 「指名委員会等設置会社」**로 명칭이 변경되면서 **[監査等委員会設置会社](용어/監査等委員会設置会社.md)가 새로 신설**되어 3종의 기관설계가 병존하게 되었다.

## 3위원회

| 위원회 | 권한 |
|--------|------|
| **指名委員会** | 주주총회에 제출하는 **이사 선임·해임 의안의 내용을 결정** |
| **監査委員会** | 집행역·이사의 직무집행을 감사, 회계감사인의 선임 의안 결정 |
| **報酬委員会** | **집행역·이사 개인별 보수의 내용을 결정** |

**각 위원회는 이사 3인 이상**으로 구성되고, **그 과반수는 사외이사**여야 한다(400조 3항). **위원은 이사회 결의**로 선임한다.

## 執行役 — 業務執行機関

| 항목 | 내용 |
|------|------|
| **직무** | 이사회로부터 위임받은 사항의 결정 + **업무집행**（418조） |
| **대표집행역** | 집행역 중에서 **이사회가 선정**（420조）. 회사를 대표 |
| **이사와의 겸임** | **가능**（집행역이 동시에 이사인 경우가 실무상 많음） |
| **임기** | **1년**（선임 후 최초 정시총회 종결까지） — **이사의 원칙 임기(2년)보다 짧음** |

**「이사회는 감독, 집행역은 집행」로 완전히 역할이 분리**된다는 것이 이 기관설계의 핵심 사상이다. **이사회는 원칙적으로 업무집행을 하지 않는다** — 業務執行의 대부분을 **집행역에게 대폭 위임**할 수 있다(**416조 4항, 362조 4항에 대응하는 규정이 완화**되어 있음).

## 監査役를 두지 않는다 — 최빈출

**指名委員会等設置会社에는 監査役을 둘 수 없다**（327조 4항）. **監査委員会가 감사 기능을 대신**하기 때문이다.

| | **감사역설치회사** | **지명위원회등설치회사** |
|---|---|---|
| 감사 담당 | **감사역**（이사가 아님） | **감사위원회**（이사로 구성） |
| 감사역의 존재 | **필수**（원칙） | **둘 수 없음** |

## 3종 기관설계의 대비

| | **監査役（会）설치회사** | **監査等委員会설치회사** | **指名委員会等설치회사** |
|---|---|---|---|
| 감사 담당 | 감사역 | 감사등위원（이사） | 감사위원회（이사） |
| 집행 담당 | 대표이사 | 대표이사 | **집행역** |
| 지명·보수의 결정 | 주주총회（관례상 이사회가 원안 작성） | 주주총회（이사회가 원안） | **지명·보수위원회가 결정** |
| 사외 요건 | 감사역회의 과반수 | 감사등위원회의 과반수 | **3위원회 각각의 과반수** |

**지명위원회등설치회사가 사외이사 관여의 정도가 가장 강하다**는 점이 특징이다 — **이사·집행역의 인사·보수까지 사외이사가 과반인 위원회가 결정**하기 때문이다.

## 💡 수험 팁

- **감사역을 둘 수 없다**(327조 4항). 「지명위원회등설치회사도 감사역을 둘 수 있다」는 지문은 **오답**.
- **각 위원회는 3인 이상, 과반수가 사외이사**다.
- **집행역의 임기는 1년**으로 이사보다 짧다.
- **보수위원회가 개인별 보수를 직접 결정**한다는 점이 다른 기관설계와의 최대 차이 — 감사역설치회사·감사등위원회설치회사는 **주주총회가 총액을 정하고 배분은 이사회 등에 위임**하는 것이 일반적이나, 지명위원회등설치회사는 **위원회가 개인별로 직접 결정**한다.
- **2014년 개정으로 감사등위원회설치회사가 신설**되면서 명칭이 「委員会設置会社」에서 「指名委員会等設置会社」로 바뀌었다는 연혁을 기억한다.

## 🎯 요점·예시

- **요점**: 이 기관설계는 「결정·감독하는 사람(이사회·3위원회)」과 「실제로 회사를 운영하는 사람(집행역)」을 확실히 나눈다. 특히 이사의 인사와 보수까지 사외이사가 절반 넘게 참여하는 위원회가 정하게 해, 경영진이 스스로 자기 보수를 정하는 이해상충을 막는다.
- **예시**: A회사(지명위원회등설치회사)의 사장이 자기 보수를 올리고 싶어도, **보수위원회**(과반수가 사외이사)가 동의하지 않으면 마음대로 정할 수 없다. 감사역이 따로 없는 대신, **감사위원회**(역시 이사로 구성)가 그 역할을 대신한다.
