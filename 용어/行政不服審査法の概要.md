# 行政不服審査法の概要

| 항목 | 내용 |
|------|------|
| 읽기 | ぎょうせいふふくしんさほうのがいよう（행정불복심사법의 개요） |
| 과목 | 행정법（행정불복심사） |
| 한줄 정의 | 처분·부작위에 대해 **행정기관에** 불복을 신청하는 절차의 일반법. **간이신속·공정한 절차**로 국민의 권리이익 구제와 행정의 적정 운영 확보를 도모한다 |
| 통설·판례 | **2014년(平成26년) 전면 개정, 2016년 4월 1일 시행.** 異議申立て를 폐지해 **審査請求에 일원화**하고 **審理員**과 **行政不服審査会**를 신설했다 |
| 한국 비교 | [행정불복심사(행정심판)](한국비교/행정불복심사(행정심판).md) |

## 목적

**1조 1항** — 「이 법률은 행정청의 위법 또는 부당한 처분 그 밖의 공권력 행사에 해당하는 행위에 관해 **국민이 간이신속하고 공정한 절차 아래에서 광범위하게 행정청에 대한 불복신청을 할 수 있게 함으로써, 국민의 권리 이익의 구제를 도모함과 동시에 행정의 적정한 운영을 확보**함을 목적으로 한다」.

**1조 2항** — 「행정청의 처분 그 밖의 공권력 행사에 해당하는 행위에 관한 불복신청에 대하여는, **다른 법률에 특별한 정함이 있는 경우를 제외하고** 이 법률이 정하는 바에 의한다」（**일반법성**）.

## 2014년 개정의 5대 포인트

| 개정 전 | 개정 후 |
|---------|---------|
| **異議申立て / 審査請求 / 再審査請求**의 3종 | **審査請求에 일원화** + **[再調査の請求](용어/再調査の請求.md)** + **[再審査請求](용어/再審査請求.md)**（둘 다 개별법에 정함이 있을 때만） |
| 심리의 공정성 담보 장치 없음 | **[審理員](용어/審査請求の審理.md)** 신설 — 처분에 관여하지 않은 직원이 심리 |
| 제3자 관여 없음 | **[行政不服審査会](용어/審査請求の裁決.md)**에의 자문 신설 |
| 심사청구 기간 **60일** | **3개월**로 연장 |
| 열람 대상이 좁음 | **제출서류 등의 열람 + 사본 교부 청구**까지 확대 |

## 行政事件訴訟과의 대비 — 최빈출

| | **行政不服審査**（행정에의 불복） | **[行政事件訴訟](용어/行政事件訴訟法の概要.md)**（법원에의 소송） |
|---|---|---|
| 판단기관 | **행정청**（審査庁） | **법원** |
| 심사의 범위 | **위법 + 부당** | **위법만** |
| 절차 | **서면심리 원칙**, 간이신속·무료 | 구두변론 원칙, 인지대 필요 |
| **불이익변경** | **금지**（48조） | 소송물의 범위 내 |
| 집행정지 | **직권 가능**（처분청·상급청인 경우） | **신청에 의해서만** |
| 사정재결·[사정판결](용어/事情判決.md) | **있음**（45조 3항） | 있음（31조） |
| 심리원·심사회 | **있음** | 없음 |

**「부당」까지 심사할 수 있다**는 것이 행정불복심사의 최대 강점이다. 재량의 범위 안에 있어 위법은 아니지만 **타당하지 않은** 처분도 취소할 수 있다.

## 자유선택주의 (審査請求前置主義의 원칙적 폐지)

**行政事件訴訟法 8조 1항** — 처분의 취소소송은 **심사청구를 할 수 있는 경우에도 곧바로 제기할 수 있다**（**자유선택주의**）. 다만 **법률에 심사청구를 거쳐야 한다는 정함이 있을 때**는 예외（**심사청구전치주의**）.

2014년 개정에 맞춘 정비법으로 **불복신청 전치를 요구하는 법률이 대폭 축소**되었다. 현재 전치가 남아 있는 대표 예는 **국세·지방세, 노동보험, 국민연금·후생연금, 공무원의 신분에 관한 처분** 등이다.

## 대상 — 처분과 부작위

| | 근거 | 내용 |
|---|------|------|
| **처분에 대한 심사청구** | **2조** | 「행정청의 처분에 불복이 있는 자」 |
| **부작위에 대한 심사청구** | **3조** | 「법령에 기한 **신청**에 대해 상당한 기간이 경과했는데도 처분이 없는 경우, **그 신청을 한 자**」 |

**부작위에 대한 심사청구는 「신청을 한 자」만** 할 수 있고 **기간 제한이 없다**.

## 💡 수험 팁

- **개정 시행일은 2016년(平成28년) 4월 1일.** 「이의신청은 여전히 존재한다」는 지문은 **오답**.
- **행정불복심사는 「부당」까지 심사**한다. 「위법성만 심사한다」는 지문은 **오답**.
- **심사청구 기간은 3개월(주관적)·1년(객관적)**. 개정 전의 「60일」은 **오답**.
- **불이익변경은 금지**된다(48조). 심사청구를 했더니 더 무거운 처분이 되는 일은 없다.
- **자유선택주의가 원칙**이다. 「반드시 심사청구를 거쳐야 취소소송을 낼 수 있다」는 지문은 **오답**.
- **부작위에 대한 심사청구에는 기간 제한이 없다.**

## 🎯 요점·예시

- **요점**: 법원에 가기 전에 **행정 내부에서 먼저 다시 봐 달라**고 하는 제도다. 돈이 들지 않고 빠르며, 무엇보다 **「위법은 아니지만 부당하다」는 주장도 통한다**는 점이 소송과 다르다.
- **예시**: A가 영업정지 30일 처분을 받았다고 하자. 법령 위반은 사실이라 소송으로는 이기기 어렵지만, 같은 정도의 위반에 보통 15일이 내려졌다면 A는 심사청구에서 **「30일은 부당하게 무겁다」**고 주장해 처분을 줄일 수 있다.
