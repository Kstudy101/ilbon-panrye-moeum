# 京都府学連事件

| 항목 | 내용 |
|------|------|
| 인용 | **最大判昭44.12.24**（최고재 대법정 1969.12.24） |
| 사건번호 | 昭和40年(あ)第1187号 |
| 사건명 | 公務執行妨害、傷害被告事件 |
| 판례집 | 刑集23巻12号1625頁 |
| 재판장 | 石田和外（전원일치） |
| 결론 | 상고기각. 촬영은 적법 → 공무집행방해 성립 |
| 과목 | 헌법（행복추구권·초상 / 표현의 자유·공안조례） |

## 사안

1962.6.21 교토부 학생자치회연합(府学連) 주최 데모. 교토시 공안조례상 **조건부가 허가**(4열 종대, 차도 동측단 진행 등)를 받은 행진이었다.

허가조건 위반으로 보이는 대열 붕괴·도로 중앙 진행이 발생하자, 시찰·채증 중이던 부경 순경이 **보도에서 선두 집단을 사진 촬영**. 피고인(당시 입명관대 법학부생)이 항의한 뒤 깃대로 순경 하악을 찔러 전치 약 1주 상해를 입혔다.

기소: 공무집행방해·상해. 항변: 무단 촬영은 위헌·위법 직무이므로 공무집행방해가 성립하지 않는다.

## 쟁점

1. 승낙 없이 용모·자태를 촬영당하지 않을 자유가 헌법상 인정되는가.
2. 본인 동의·영장 없는 경찰 촬영이 허용되는 요건은 무엇인가.
3. 本件 촬영은 적법한가(→ 공무집행방해의 전제).
4. 교토시 공안조례(집회·집단행진·집단시위)는 헌법 21조에 위반하는가.

## 판시

### 1. 촬영되지 않을 자유（헌법 13조）

헌법 13조는 국민의 사생활상 자유를 국가권력에 대해서도 보호한다.  
그 하나로, **누구든지 승낙 없이 함부로 그 용모·자태를 촬영당하지 않을 자유**를 가진다.

「이를 초상권이라 부를지는 별론」이지만, 경찰관이 **정당한 이유 없이** 개인의 용모 등을 촬영하는 것은 13조 취지에 반하여 허용되지 않는다.

### 2. 경찰 촬영이 허용되는 경우（13조·35조）

이 자유도 공공의 복지상 상당한 제한을 받는다. 범죄수사는 경찰에 주어진 국가작용이다(경찰법 2조 1항).

본인 동의·법관 영장이 없어도 허용되는 경우:

1. **현행범적 상황** — 현재 범죄가 행해지거나, 행해진 뒤 얼마 되지 않았다고 인정될 것
2. **증거보전의 필요성·긴급성**
3. **상당성** — 일반적으로 허용되는 한도를 넘지 않는 상당한 방법으로 촬영할 것

이 경우 범인뿐 아니라 **제외할 수 없는 제3자의 용모**가 찍혀도 헌법 13조·35조에 위반하지 않는다.

### 3. 本件 적용

허가조건 위반이라는 범죄가 현재 행해지고 있다고 인정되는 상황에서, 증거보전을 위해 보도에서 촬영한 것이므로 **3요건을 충족 → 적법한 직무집행**. 공무집행방해 성립. 상고기각.

### 4. 공안조례

昭和29年 京都市条例第10号(집회·집단행진 및 집단시위에 관한 조례)는 **헌법 21조에 위반하지 않는다**.

## 시험 포인트

- 구조: **자유를 인정하면서, 本件 촬영은 적법**으로 결론 낸다. 「초상권을 인정 = 촬영 위법」이 아니다.
- 판결은 「초상권」이라는 말을 정면으로 쓰지 않고 **「촬영되지 않을 자유」**로 구성한다.
- 3요건은 수험상 암기 세트. 다만 후속 **最決平20.4.15**(平成19(あ)839)는, 본 판결이 「현행범적 상황 이외는 일절 불허」라는 취지까지 판시한 것은 **아니라고** 한다(도로·점포 내 비디오 촬영 적법).
- 별도 축: 공안조례 합헌(표현의 자유·21조).
