# 법령의 표기와 해석기법

| 항목 | 내용 |
|------|------|
| 대응 | [みなす](용어/みなす.md) · [推定する](용어/推定する.md) · [善意・悪意](용어/善意・悪意.md) · [条文上の表記](용어/条文上の表記.md) · [法の適用・解釈](용어/法の適用・解釈.md) · [法の名称](용어/法の名称.md) |
| 인용 | 민법 제15조·제197조, 상법 제1조 |
| 과목 | 기초법학 |
| 결론 | **「간주하다(みなす)」와 「추정하다(推定する)」의 구별, 「선의·악의」의 용법이 한국 법령 문언에 그대로 이식**되어 있다 — 이는 **근대 한국 법제가 일본을 매개로 한자어 법률용어 체계를 계수**했기 때문이다. **「간주 = 반증으로 못 뒤집음 / 추정 = 반증으로 뒤집힘」이라는 구별, 「선의·악의는 도덕과 무관하게 「앎·모름」을 가리킨다」는 정의가 완전히 같은 문언으로 통용**된다. 법령의 명칭 체계（법률·시행령·시행규칙）도 일본의 법률·정령·성령과 **같은 위계 구조를 갖되 명칭만 다르다** |

## 한국의 법리

### 간주와 추정 — 문언까지 동일하다

**한국 법령도 「간주한다」와 「추정한다」를 [みなす](용어/みなす.md)·[推定する](용어/推定する.md)와 정확히 같은 방식으로 구별**해 쓴다.

| | 간주（=일본의 みなす） | 추정（=일본의 推定する） |
|---|---|---|
| 효과 | **반증으로 뒤집히지 않음**（법이 정한 별도 절차로만 다툼） | **반증으로 뒤집힘** |
| 성질 | 법정의제（擬制） | 입증책임의 전환 |
| 대표 조문 | **민법 제28조**（실종선고 → 사망한 것으로 **본다**） | **민법 제197조 1항**（점유자는 소유의 의사로 점유한 것으로 **추정**한다） |

**「~한 것으로 본다」는 표현이 한국의 「간주」에 해당**하며, **일본어의 「みなす」와 완전히 같은 법적 효과（반증 불가, 별도 절차로만 다툼）**를 갖는다. **한국 민법 제28조의 실종선고**는 일본 민법 31조의 「사망한 것으로 간주한다」와 **동일한 논리 구조**를 갖는다 — 실종선고를 다투려면 반증이 아니라 **「실종선고의 취소」라는 별도 절차**를 거쳐야 한다는 점까지 같다.

**추정도 마찬가지다.** 한국 민법 **제197조 1항**은 「점유자는 소유의 의사로 선의, 평온 및 공연하게 점유한 것으로 **추정**한다」고 하여, **다투는 쪽이 반증을 대야 하는 입증책임 전환**의 구조를 그대로 쓴다. **일본 민법 186조 1항과 요건·용어·법적 효과가 완전히 대응**한다（→ [점유권과 점유보호청구권](한국비교/점유권과%20점유보호청구권.md) 참조）.

### 선의·악의 — 정의가 완전히 같다

**[善意・悪意](용어/善意・悪意.md)**의 정의 — **「선의는 어떤 사정을 알지 못하는 것, 악의는 그 사정을 알고 있는 것」**, **「도덕적인 선악과는 무관하다」**는 설명이 **한국 민법학 교과서·판례에서도 문언 그대로 통용**된다. 한국 민법에도 **「선의의 제3자」（제107조 2항 등）**, **「선의취득」（제249조）**, **「선의점유·악의점유」（제197조）** 등 **일본과 완전히 같은 용어·같은 정의**로 조문 전반에 쓰인다.

**「선의만으로 족한 경우」와 「선의·무과실까지 요구하는 경우」가 갈린다는 점도 한국 시험의 단골 함정**이며, 이는 일본 시험과 **완전히 같은 출제 구조**다（예: [의사표시의 흠결과 하자](한국비교/의사표시의%20흠결과%20하자.md)에서 본 대로, 취소의 제3자 보호 요건에서 「선의」만 요구하는지 「선의·무과실」까지 요구하는지가 조문마다 다르다).

### 법령 문언의 표기 규칙 — 접속사·부등호 표현이 대응한다

**[条文上の表記](용어/条文上の表記.md)**가 정리하는 **「및び·並びに」「又は·若しくは」「以上·以下·超える·未満」**의 정형화된 용법도, **한국 법령의 「및·또는·이상·이하·초과·미만」과 완전히 같은 문법 구조**를 갖는다.

| 일본어 | 한국어 | 용법 |
|---|---|---|
| **及び / 並びに** | **및** | 단순 병렬은 「및」한 번, **2단 이상의 병렬 구조**（작은 단위 병렬에 「및」, 그 전체와 다른 것을 다시 묶을 때 「並びに」）로 세분 — 한국 법제처 「알기 쉬운 법령 정비기준」도 같은 구별을 채택 |
| **又は / 若しくは** | **또는 / 혹은** | 단순 선택은 「또는」, **다단 선택 구조**에서 큰 단위에 「또는」, 작은 단위에 「若しくは(혹은)」 — 같은 위계 구조 |
| **以上 / 以下 / 超える / 未満** | **이상 / 이하 / 초과 / 미만** | **「이상·이하」는 그 수를 포함, 「초과·미만」은 포함하지 않는다** — 완전히 같은 정의 |

**이는 한국 법제처가 일본의 법령 입안 기술（法制執務）을 계수해 「법령입안·심사기준」을 마련한 결과**로, **법률용어의 정밀한 구별이라는 발상 자체가 공유**된다.

### 법의 적용과 해석 — 방법론은 이미 정리했다

**[法の適用・解釈](용어/法の適用・解釈.md)**의 「문리해석 → 논리해석」이라는 순서는 [법해석의 방법론](한국비교/법해석의%20방법론.md)에서 이미 정리한 대로 **한일 양국이 완전히 공유**하는 구조다.

### 법의 명칭 — 위계는 같고 명칭만 다르다

**[法の名称](용어/法の名称.md)**이 정리하는 **일본의 법형식 위계（헌법 → 법률 → 정령(政令) → 성령(省令)）**는, **한국의 「헌법 → 법률 → 대통령령(시행령) → 부령(시행규칙)」과 정확히 같은 4단 구조**를 이룬다.

| 일본 | 한국 | 제정 주체 |
|---|---|---|
| **憲法** | **헌법** | — |
| **法律** | **법률** | 국회 |
| **政令**（内閣） | **대통령령**（시행령） | 대통령 |
| **省令**（各省大臣） | **부령**（시행규칙, 총리령·부령） | 국무총리·행정각부 장관 |

**「법령의 약칭과 정식명칭이 다른 경우가 많아 함정으로 쓰인다」는 지적도 한국 시험에 그대로 적용**된다 — 예컨대 한국의 **「공공기관의 정보공개에 관한 법률」（약칭 「정보공개법」）**, **「공공기록물 관리에 관한 법률」（약칭 「기록물관리법」）**처럼, **정식명칭이 길고 실무·시험에서는 약칭으로 통용**되는 구조가 일본의 「行政機関の保有する情報の公開に関する法律」（약칭 「정보공개법」）과 같다.

## 대표 판례

- **한국 — 간주(의제)와 추정의 구별** — 대법원은 「간주규정」에 대해서는 **반증을 허용하지 않고 법에 정한 절차（취소·정정 등）로만 다툴 수 있다**고 하는 반면, **「추정규정」에 대해서는 반대사실의 증명으로 추정이 깨진다**고 일관되게 판시한다. **일본 판례·통설의 구별과 완전히 같은 논리**다.
- **일본 — 선의·무과실의 단계 구별** — [即時取得](용어/即時取得.md)（선의·무과실 요구）와 [心裡留保](용어/心裡留保.md)의 상대방 보호（선의만으로 족한 경우와 무과실까지 요구하는 경우）처럼, **조문마다 요구되는 보호 요건의 「단계」가 다르다는 점이 최빈출 함정**이며, 한국 민법 시험도 같은 구조로 출제된다.

## 일본과의 비교

| 항목 | 일본 | 한국 |
|------|------|------|
| **간주(擬制)** | **みなす.** 반증 불가 | **간주한다 / ~한 것으로 본다.** 반증 불가 — 동일 |
| **추정** | **推定する.** 반증으로 전복 | **추정한다.** 반증으로 전복 — 동일 |
| **선의·악의의 정의** | 앎·모름（도덕과 무관） | **동일** |
| **및び / 並びに** | 단순·다단 병렬의 구별 | **및**（한국 법제처 입안기준도 같은 구별） |
| **又は / 若しくは** | 단순·다단 선택의 구별 | **또는 / 혹은** — 동일 구조 |
| **以上·以下·超える·未満** | 포함/불포함 구별 | **이상·이하·초과·미만** — 완전 동일 |
| **해석 방법론** | 문리해석 → 논리해석 | **동일**（→ [법해석의 방법론](한국비교/법해석의%20방법론.md)） |
| **법형식의 위계** | 헌법 → 법률 → 정령 → 성령 | **헌법 → 법률 → 대통령령 → 부령** — 같은 4단 구조 |
| 약칭과 정식명칭의 괴리 | 흔함（정보공개법 등） | **동일한 현상** |

**정리** — **이 단원도 앞선 [법해석의 방법론](한국비교/법해석의%20방법론.md)·[법원과 법의 효력](한국비교/법원과%20법의%20효력.md)과 마찬가지로, 한국 지식이 문언 수준까지 그대로 통하는 완전 대응 영역**이다. **간주/추정의 구별, 선의·악의의 정의, 및/또는의 다단 구조, 이상·이하/초과·미만의 경계** 모두 **일본어를 한국어로 그대로 옮기면 되는 수준**이다. **유일하게 주의할 것은 「법형식의 명칭」 자체**다 — **「정령」은 한국의 「대통령령」, 「성령」은 「부령」**에 대응한다는 **명칭 자체의 1:1 치환**만 정확히 해 두면 된다.
